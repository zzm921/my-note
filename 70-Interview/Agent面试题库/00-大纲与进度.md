# Agent 工程面试题库 · 大纲与进度

> 目标：面向「AI Agent 开发」岗位，把面试考点拆成 12 个模块，**按模块顺序推进、每日 3 题**（1 概念 + 1 原理 + 1 实操/设计），
> 不做随机发散。一轮 32 天覆盖全部 96 题；之后进入追问变体与压力测试轮。
>
> 出题规则由服务器定时任务执行：读本文件定进度 → 按模块内题号顺序出题 → 追加到对应模块文件 → 推送摘要。

## 使用方式

1. 收到推送先**自己答**（心里默答或写下来），再看「答案要点」
2. 对照「追问」自测深度——面试官通常会在这个位置继续挖
3. 看「易错点」，多数人卡在这里
4. 每模块结束后回看该模块的「出题记录」表，做一次自测
