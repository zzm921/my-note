# 强化学习

## 卡片：强化学习与其他学习的区别
**定义**：强化学习研究智能体（Agent）如何通过与环境的交互，学习一套能最大化长期累积奖励的决策策略，是一类以「试错 + 奖励」为核心的学习范式。
**与其他学习的对比**：

| 维度 | 监督学习 | 无监督学习 | 强化学习 |
|---|---|---|---|
| 数据形式 | (x, y) 输入输出对 | 只有 x | 状态、动作、奖励的序列 |
| 反馈信号 | 每个样本有正确答案 y | 无标签，靠内在结构 | 只有奖励信号，没有标准答案 |
| 决策方式 | 一次独立预测 | 一次建模 | 一连串连续决策，当前决策影响未来 |
| 反馈时机 | 立即知道对错 | 无 | 延迟奖励，可能最后一步才知道输赢 |
| 学习来源 | 从已有数据学 | 从已有数据学 | 自己与环境交互、从试错中学 |
**为什么（设计动机）**：现实问题（下棋、驾驶、行走）本质是一连串决策，监督学习难以处理「一步决策影响后续所有步骤」的耦合；且许多任务没有标准答案，只能给稀疏评价（赢了/输了），所以强化学习把「长远累积回报」作为优化目标，而不是每一步的即时误差。

**直觉**：像「教练只告诉你最后赢了还是输了」——必须从最终结果倒推每一步的好坏。
**实例（机器人行走）**：
- 延迟奖励：机器人每走一步都没有即时反馈，只有到达终点才 +100、掉进坑里才 -100；某一步「抬腿往左」好不好，要等几百步之后才能确定。
- 一连串决策：每步落脚点改变重心，重心决定下一步能否站稳，第 1 步影响第 2 步、第 2 步影响第 3 步……整条路径是串行耦合的决策链，不能像分类那样逐点独立判断。

**常见误区/注意点**：
- 误区一：以为强化学习也需要标签——实际只有标量奖励，奖励不是正确答案。
- 误区二：把每一步独立建模，忽略「决策链」会丢掉延迟奖励的信息；奖励过稀难收敛、过密会被「刷分」。

## 卡片：核心概念（MDP）
**定义**：马尔可夫决策过程（MDP）是描述强化学习问题的标准数学模型，由状态、动作、转移、奖励、折扣因子五要素构成；「马尔可夫」指下一状态只依赖当前状态与当前动作，与更早历史无关。
**公式/伪代码**：
```
MDP 五元组：(S, A, P, R, γ)
  S：状态集合   s ∈ S
  A：动作集合   a ∈ A
  P：转移概率   P(s' | s, a)
  R：奖励函数   R(s, a)
  γ：折扣因子   0 ≤ γ < 1
一个回合：观测状态 s → 选动作 a → 得奖励 R 与新状态 s'，重复直到终止
```
**符号表**：

| 符号 | 含义 |
|---|---|
| S | 所有可能状态的集合（如机器人的所有可能位置） |
| A | 所有可选动作的集合（如 {左, 右}） |
| P(s' \| s, a) | 在 s 执行动作 a 后转移到 s' 的概率 |
| R(s, a) | 在 s 执行动作 a 得到的即时奖励（标量） |
| γ | 折扣因子，决定未来奖励的相对权重 |
| π(s) | 策略：状态 → 动作的映射 |
**为什么（设计动机）**：马尔可夫假设（当前状态已含决策所需的全部信息）大幅简化问题，使「只看当前一步」成为可能；用概率转移 P 描述环境不确定性，并把「目标」形式化为最大化长期累积奖励，使其可被数学求解。

**直觉**：MDP 像一份「完全规则说明书」——状态、动作、转移、得分全部写清；学习就是「在这份说明书里找到最好的玩法」。
**实例（机器人 4 格走廊）**：完整定义如下
- 状态空间 S = {S1, S2, S3, S4}：S1 起点，S4 终点（吸收态，进入即结束回合）。
- 动作空间 A = {左, 右}；确定性转移：「右」S1→S2→S3→S4；「左」S2→S1、S3→S2、S4→S3；在 S1 执行「左」撞墙留在 S1。
- 奖励：从 S3 执行「右」进入 S4 得 +100；在 S1 执行「左」撞墙得 -10；其余普通移动得 0。
- 折扣因子 γ = 0.9；目标：从 S1 出发使期望回报最大。最优策略是「一路向右」，回报 = R(S1,右) + γ·R(S2,右) + γ²·R(S3,右) = 0 + 0.9×0 + 0.81×100 = 81。

**常见误区/注意点**：
- 终点忘记设成吸收态：到终点还能继续拿奖励，会误导学习。
- 把「状态」与「传感器读数」混为一谈：状态是数学抽象，同一读数可能对应不同状态。

## 卡片：回报与折扣因子
**定义**：回报（Return）是从当前时刻开始，未来所有奖励按折扣因子衰减后的加权总和；由于当前决策影响未来所有步骤，优化目标必须是「整个回报」而不是单步奖励。
**公式/伪代码**：
```
回报 Gₜ = Rₜ + γ·Rₜ₊₁ + γ²·Rₜ₊₂ + γ³·Rₜ₊₃ + ...
其中 Rₜ 是第 t 步的即时奖励，γ 是折扣因子（0 ≤ γ < 1）
```
**符号表**：

| 符号 | 含义 |
|---|---|
| Gₜ | 从第 t 步开始的回报（未来奖励的加权和） |
| Rₜ | 第 t 步获得的即时奖励 |
| γ | 折扣因子：越接近 1 越看重长远，越接近 0 越短视 |
| γⁿ | 第 n 步以后的奖励被打的折扣（衰减系数） |
**为什么（设计动机）**：未来不确定、越远越不可靠，近期奖励应比远期更有分量；折扣使无限长任务的回报收敛为有限值，也避免智能体为「很远的巨大奖励」放弃眼前收益。

**直觉**：折扣因子像「复利折现」——今天的 100 元比十年后的 100 元更值钱；γ 小是「今朝有酒今朝醉」，γ 大是「放长线钓大鱼」。
**实例（手算）**：奖励序列 [R₁, R₂, R₃] = [0, 0, 100]（前两步无奖励，第三步到达终点拿 100）
- γ = 0.5 时：G₁ = 0 + 0.5×0 + 0.5²×100 = 0 + 0 + 0.25×100 = 25
- γ = 0.9 时：G₁ = 0 + 0.9×0 + 0.9²×100 = 0 + 0 + 0.81×100 = 81
- 结论：γ 越大，遥远奖励占比越大（25 vs 81）；短平快任务用小 γ，长期规划任务（下棋、自动驾驶）用接近 1 的大 γ。

**常见误区/注意点**：
- 忘记按步数乘 γⁿ：回报是「每一步折扣一次」，不是只对最后一个奖励折一次。
- γ 设为 1：无限长任务下回报可能发散；混淆「回报」与「单步奖励」会短视。

## 卡片：价值函数与贝尔曼方程
**定义**：价值函数是「对未来的量化评估」——Q(s, a) 表示在状态 s 采取动作 a 后，按某种策略继续行动能获得的期望回报；最优策略就是在每个状态选择 Q 值最大的动作。
**公式/伪代码**：
```
Q(s, a) = E[ Gₜ | sₜ = s, aₜ = a ]     （期望回报）
最优策略：π(s) = argmaxₐ Q(s, a)        （选 Q 最大的动作）
贝尔曼方程：Q(s, a) = R(s, a) + γ · maxₐ' Q(s', a')，其中 s' 是执行 a 后的下一个状态
```
**符号表**：

| 符号 | 含义 |
|---|---|
| Q(s, a) | 状态-动作价值：在 s 做 a 后的期望回报 |
| s' | 执行动作 a 后到达的下一个状态 |
| a' | 在下一个状态 s' 中可以选择的动作 |
| maxₐ' Q(s', a') | 在 s' 所有可选动作中 Q 的最大值 |
| γ | 折扣因子 |
**为什么（推导/设计动机）**：Q 回答「在这个状态下做这个动作，长期值多少钱」，有了它就能直接决策：每状态挑 Q 最大的动作；但 Q 的定义是「无限求和」，贝尔曼方程把它拆成「即时奖励 R(s, a) + 下一状态的最好未来价值」，把大问题变成可递推的小问题。

**直觉**：像「站在当下，用最优的未来倒推现在」——今天这一步值多少 = 今天拿到的钱 + 打折后的「明天最好能拿到的钱」。
**实例（手算）**：小格子世界 S1–S2–S3，智能体在 S2，考虑动作「右」；已知 γ = 0.9，R(S2, 右) = 0，以及 Q(S3, a') 的已知表：

| 下一个状态 s' | 可选动作 a' | Q(s', a') |
|---|---|---|
| S3 | 左 | 30 |
| S3 | 右 | 50 |

- maxₐ' Q(S3, a') = max(30, 50) = 50
- Q(S2, 右) = R(S2, 右) + γ × 50 = 0 + 0.9 × 50 = 45
- 同理 Q(S2, 左) = -10 + 0.9×0 = -10（向左撞墙），故 π(S2) = argmax(左=-10, 右=45) = 右。

**常见误区/注意点**：
- 把 Q(s, a) 与即时奖励混淆：Q 是长期期望回报，不是 R(s, a)。
- 贝尔曼方程里的 max 表示「假设之后每一步都选最优」；忘记乘 γ 会高估远期收益。

## 卡片：Q-Learning
**定义**：Q-Learning 是无需环境模型（model-free）的时序差分算法，通过不断用「贝尔曼目标值」修正当前 Q 值，逐步逼近真实期望回报，从而得到最优策略。
**公式/伪代码**：
```
更新规则（对一次经历 (s, a, R, s')）：
    Q(s, a) := Q(s, a) + α·[ R + γ·maxₐ' Q(s', a') − Q(s, a) ]
伪代码：
初始化 Q 表为 0
重复（每回合，从状态 s 开始）：
  按 ε-greedy 选动作 a，执行后得奖励 R 和 s'
  Q(s, a) ← Q(s, a) + α·( R + γ·maxₐ'Q(s',a') − Q(s, a) )
  s ← s'，直到到达终止状态
```
**符号表**：

| 符号 | 含义 |
|---|---|
| Q(s, a) | 当前估计的状态-动作价值 |
| α | 学习率（0 < α ≤ 1），控制每次更新步长 |
| R | 本次动作得到的即时奖励 |
| γ | 折扣因子 |
| maxₐ' Q(s', a') | 下一个状态的最优价值（目标中的「未来」部分） |
| R + γ·maxₐ'Q(s',a') | 贝尔曼目标值，更新的「锚点」 |
**为什么（推导/设计动机）**：贝尔曼方程告诉 Q「应该等于多少」，但右侧 Q(s', a') 也是未知估计，只能「边走边改」：每经历一步把当前 Q 向目标值拉近一点；且不需要知道转移概率 P 和环境模型，只凭采样到的 (s, a, R, s') 就能学——这是 model-free 的关键优势。

**直觉**：像「体重管理」——每天把自己往目标体重方向调整一步，日拱一卒，最终逼近目标。
**实例（手算）**：α = 0.1，R = 10，γ = 0.9，maxₐ'Q(s') = 20，当前 Q = 0。
- 目标值 = R + γ·maxQ(s') = 10 + 0.9×20 = 10 + 18 = 28
- 更新：Q ← 0 + 0.1 × (28 − 0) = 0.1 × 28 = 2.8

若每次经历目标值都相同，反复迭代：

| 迭代 | 更新前 Q | 更新计算 | 更新后 Q |
|---|---|---|---|
| 1 | 0 | 0 + 0.1×(28−0) | 2.8 |
| 2 | 2.8 | 2.8 + 0.1×(28−2.8) | 5.32 |
| 3 | 5.32 | 5.32 + 0.1×(28−5.32) | 7.59 |
| 4 | 7.59 | 7.59 + 0.1×(28−7.59) | 9.63 |
| … | … | … | 收敛到 28 |
每次更新后 Q 与目标 28 的差距都缩小为原来的 0.9 倍（递推 Q ← 0.9Q + 2.8），最终收敛于 Q* = 28。

**常见误区/注意点**：
- 把目标值直接赋值给 Q：正确写法是「Q + α×(目标 − Q)」的加权移动，不是一步到位。
- α 过大震荡、过小收敛慢；忘了乘 γ 会高估；早期 max 用的是当前估计，Q 值有偏属正常。

## 卡片：探索与利用
**定义**：强化学习面临「探索（尝试未知动作，发现更好选择）」与「利用（选择已知最优动作，获取当前最大收益）」的权衡；ε-greedy 是最常用的平衡策略。
**公式/伪代码**：
```
ε-greedy：
  以概率 ε：随机均匀选一个动作（探索）
  以概率 1−ε：选 argmaxₐ Q(s, a)（利用）
伪代码：
若 random() < ε：a ← 从动作空间随机选一个
否则：a ← argmaxₐ Q(s, a)
```
**符号表**：

| 符号 | 含义 |
|---|---|
| ε | 探索概率（0 ≤ ε ≤ 1），训练初期调大、后期调小 |
| random() | 均匀分布在 [0, 1) 的随机数 |
| argmaxₐ Q(s, a) | 让 Q 值最大的动作（当前认为最优） |
**为什么（设计动机）**：只利用不探索，Q 表一开始全是 0 或猜测值，「最优动作」很可能是次优的，会被永远卡在局部最优；只探索不利用则一直乱走，从不把学到的知识变现。探索让智能体发现「没走过的好路」。

**直觉**：像下馆子——「利用」是总点招牌菜（保证不踩雷），「探索」是偶尔试新菜（可能发现更好吃的，也可能踩雷）；ε 就是「试新菜的频率」。
**实例（手算）**：设 ε = 0.1
- 单次决策：以 10% 概率随机探索，以 90% 概率选 Q 最大的动作。
- 10 次决策：期望探索次数 = 10 × 0.1 = 1，即平均每 10 次决策有 1 次随机探索、其余 9 次利用。
- 100 次决策：期望探索 = 100 × 0.1 = 10 次。训练后期常把 ε 从 0.1 衰减到 0.01 甚至 0。

**常见误区/注意点**：
- ε 设成 0 是纯利用，可能永远错过更优路径；ε 全程不衰减则永远有 10% 的动作在乱走。
- 探索不是乱走到底：它也是「围绕当前最优附近试探」，ε-greedy 只是最简单的实现之一。

## 卡片：连续状态与 DQN
**定义**：当状态空间连续或巨大（位置坐标、速度都是小数）时，Q 表无法穷举；深度 Q 网络（DQN）用神经网络 Q(s, a; θ) 近似 Q 函数，并配合经验回放与目标网络保证训练稳定。
**为什么需要神经网络近似 Q**：
1. 表格法要求为每个 (s, a) 单独存一个 Q 值，状态连续时组合数无穷多，内存和采样都不可行。
2. 神经网络有泛化能力：相似状态可推出相似动作的 Q 值；输入状态、输出各动作 Q，端到端可微，可用梯度下降训练。

**公式/伪代码（DQN 训练流程）**：
```
初始化主网络 Q(·; θ) 与目标网络 Q(·; θ⁻)（θ⁻ ← θ），初始化经验池 D
重复（每回合，从状态 s 开始）：
  以 ε-greedy 用主网络选动作 a，执行后得奖励 R 和 s'
  把样本 (s, a, R, s') 存入经验池 D
  若 D 中样本足够：
    从 D 随机抽一小批 B
    目标 y = R + γ·maxₐ' Q(s', a'; θ⁻)   ← 用目标网络计算
    损失 L = (1/|B|)·Σ ( y − Q(s, a; θ) )²，对 θ 做梯度下降
  每隔 C 步：θ⁻ ← θ（同步目标网络）
  s ← s'，直到到达终止状态
```
**符号表**：

| 符号 | 含义 |
|---|---|
| θ | 主网络参数 |
| θ⁻ | 目标网络参数（定期从 θ 复制） |
| D | 经验回放池：存放历史样本 (s, a, R, s') |
| B | 每次更新随机抽取的一小批样本 |
| y | 贝尔曼目标值，用目标网络计算，作为回归标签 |
| C | 目标网络同步周期（每 C 步复制一次） |
**为什么（设计动机）**：直接在线更新会让样本高度相关且目标值不断变化，训练易发散；经验回放把样本存池再随机抽取，打乱时间相关性，且一个样本可反复使用、数据利用率更高；若更新 Q 的网络同时又在算目标里的 max Q，目标会「追着自己的影子跑」，所以用固定一段时间的旧网络 θ⁻ 算目标，学习更稳。

**经验回放的作用**：打破相邻样本的时间相关性，使梯度更接近「独立同分布」假设；重复利用历史样本提升数据效率。
**直觉**：DQN 相当于「请了一个评估师」——主网络负责决策和更新，目标网络是「短期固定版本的评估师」，避免评估师一边改答案一边给分。
**常见误区/注意点**：
- 忘记目标网络：直接用主网络算 max Q，目标值震荡；经验池太小则相关性依旧过强。
- 奖励未做缩放/归一化，网络对量级敏感难以收敛；DQN 只能输出离散动作的 Q，连续动作需 DDPG 等算法。

## 卡片：易错点
**定义**：本节汇总强化学习中最常见、最隐蔽的错误，帮助排查「训练不收敛 / 学出怪策略」的根因。
**易错点清单**：

| 易错点 | 详细说明 |
|---|---|
| MDP 建模不清 | 状态、动作、奖励没定义清楚就写代码，如把「传感器读数」直接当状态、漏掉终止状态。 |
| 奖励设计与目标不一致 | 奖励是行为的「指挥棒」：只想惩罚「慢」却写成惩罚「离终点远」，机器人可能原地乱跳逃避惩罚（reward hacking）。 |
| 只利用不探索 | ε = 0 的纯贪心会卡在次优策略，永远发现不了更好的路径。 |
| γ 的选择失当 | γ 太小只看眼前、放弃长远最优；γ 太大在无限长任务下回报发散。 |
| 混淆即时奖励与长期价值 | Q(s, a) 是折扣累积的期望回报，不是 R(s, a)；用单步奖励决策会短视。 |
| 贝尔曼方程忘记 max 与 γ | 目标值必须是「R + γ×下一状态最优 Q」；漏掉 γ 会系统性高估。 |
| 更新公式写成直接赋值 | Q ← 目标值 是「一步到位」，正确写法是 Q ← Q + α×(目标 − Q)。 |
| 训练稳定性三件套缺失 | 大状态空间用 DQN 却不做经验回放、不用目标网络，训练必然震荡。 |
| 验证只看总回报均值 | 不看学习曲线与回报方差，可能把「偶然一次高分」误判为收敛。 |
**总结心法**：调试时按「建模 → 奖励 → 探索 → 更新公式 → 训练稳定性」逐层排查；绝大多数「学不会」的问题都出在这五层之一。
