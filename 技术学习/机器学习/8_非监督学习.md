# 非监督学习

> 非监督学习的数据只包含输入 x，不包含输出 y，算法必须自行发现数据中的结构或模式。
> 两大任务：**聚类**——把相似样本分到一组；**异常检测**——找出与大多数样本差异极大的离群点。

---

## 卡片：K-Means 算法

**定义**：K-Means 是一种划分式聚类算法：给定簇数 K，把 m 个无标签样本分成 K 个簇，使"每个样本到其簇中心的距离平方和"（畸变值 J）最小。

**公式/伪代码**：

```
输入：样本集 {x⁽¹⁾, x⁽²⁾, …, x⁽ᵐ⁾}，簇数 K
1. 随机初始化 K 个簇中心 μ₁, μ₂, …, μ_K
2. 重复直到簇中心不再变化：
   a. 分配步骤（每个样本选最近的中心）：
      c⁽ⁱ⁾ ← argmin_{j=1..K} ||x⁽ⁱ⁾ − μⱼ||²
   b. 更新步骤（中心移到簇内样本的均值）：
      μⱼ ← (1 / |Cⱼ|) · Σ_{i ∈ Cⱼ} x⁽ⁱ⁾

目标函数（畸变函数）：
   J = (1/m) · Σᵢ₌₁ᵐ ||x⁽ⁱ⁾ − μ_{c⁽ⁱ⁾}||²
```

**符号表**：

| 符号 | 含义 |
|---|---|
| x⁽ⁱ⁾ | 第 i 个样本（本卡片中是二维坐标点） |
| m | 样本总数 |
| K | 簇的个数，超参数，需要提前指定 |
| μⱼ | 第 j 个簇的中心（簇内样本的质心） |
| c⁽ⁱ⁾ | 样本 x⁽ⁱ⁾ 被分配到的簇编号（取 1~K 之一） |
| Cⱼ | 属于第 j 个簇的样本集合 |
| \|Cⱼ\| | 第 j 个簇内样本的个数 |
| \|\|·\|\|² | 欧氏距离的平方，即各坐标差的平方和 |
| μ_{c⁽ⁱ⁾} | 样本 x⁽ⁱ⁾ 所在簇的中心 |
| J | 畸变函数，所有样本到各自簇中心距离平方的平均值 |

**为什么（推导/设计动机）**：
1. 直觉目标：簇内紧凑。J 越小，说明每个样本离自己簇的中心越近，聚类越"紧实"。
2. 直接求 J 的全局最优很难，因为 c⁽ⁱ⁾ 是离散分配变量。K-Means 采用**坐标下降**：把 J 看成中心 μ 与分配 c 两个变量的函数，交替优化其中一个。
3. 固定 μ 优化 c：每个样本独立选择离它最近的中心，一步得到闭式解——这是分配步骤。
4. 固定 c 优化 μ：J 对 μⱼ 求导并令导数为 0，解得 μⱼ 恰为簇内样本的均值——这是更新步骤。
5. 两个步骤都保证 J 不增，因此 J 单调下降；但只能保证收敛到**局部**最优而非全局最优——这正是后面"多次随机初始化"的动机。

**直觉**：想象 K 根"磁铁"放在数据中：每根磁铁先吸走离它最近的样本，然后被吸来的样本把磁铁"推"到自己的重心位置，反复几次后磁铁各占一方、不再移动，就收敛了。本质一句话：**先各归其主，再众筹搬家，直到不再折腾。**

**实例（完整手算）**：
数据集：x⁽¹⁾=(1,1)、x⁽²⁾=(2,1)、x⁽³⁾=(1,2)、x⁽⁴⁾=(4,4)、x⁽⁵⁾=(5,4)、x⁽⁶⁾=(4,5)，K=2，初始中心 μ₁=(1,1)、μ₂=(4,4)。

第 1 轮·分配：对每个样本算到两中心的欧氏距离平方：

| 样本 | 到 μ₁=(1,1) | 到 μ₂=(4,4) | 分配 |
|---|---|---|---|
| (1,1) | 0²+0²=0 | 3²+3²=18 | 簇1 |
| (2,1) | 1²+0²=1 | 2²+3²=13 | 簇1 |
| (1,2) | 0²+1²=1 | 3²+2²=13 | 簇1 |
| (4,4) | 3²+3²=18 | 0²+0²=0 | 簇2 |
| (5,4) | 4²+3²=25 | 1²+0²=1 | 簇2 |
| (4,5) | 3²+4²=25 | 0²+1²=1 | 簇2 |

第 1 轮·更新中心：
μ₁ = ((1+2+1)/3, (1+1+2)/3) = (4/3, 4/3) ≈ (1.333, 1.333)
μ₂ = ((4+5+4)/3, (4+4+5)/3) = (13/3, 13/3) ≈ (4.333, 4.333)

第 1 轮结束后的畸变值 J₁（用新中心逐样本计算距离平方）：
- (1,1)：(1−4/3)²+(1−4/3)² = 2/9
- (2,1)：(2−4/3)²+(1−4/3)² = 4/9+1/9 = 5/9
- (1,2)：(1−4/3)²+(2−4/3)² = 1/9+4/9 = 5/9
- (4,4)：(4−13/3)²+(4−13/3)² = 1/9+1/9 = 2/9
- (5,4)：(5−13/3)²+(4−13/3)² = 4/9+1/9 = 5/9
- (4,5)：(4−13/3)²+(5−13/3)² = 1/9+4/9 = 5/9

平方和 = 2/9+5/9+5/9+2/9+5/9+5/9 = 24/9 = 8/3 ≈ 2.667；J₁ = (1/6)·(8/3) = 4/9 ≈ 0.444。

第 2 轮·分配（用新中心 μ₁=(4/3,4/3)、μ₂=(13/3,13/3)）：
- (1,1)：到 μ₁ = 2/9，到 μ₂ = (−10/3)²+(−10/3)² = 100/9+100/9 = 200/9 → 簇1
- (2,1)：到 μ₁ = 5/9，到 μ₂ = (−7/3)²+(−10/3)² = 49/9+100/9 = 149/9 → 簇1
- (1,2)：到 μ₁ = 5/9，到 μ₂ = (−10/3)²+(−7/3)² = 100/9+49/9 = 149/9 → 簇1
- (4,4)：到 μ₁ = (8/3)²+(8/3)² = 64/9+64/9 = 128/9，到 μ₂ = 2/9 → 簇2
- (5,4)：到 μ₁ = (11/3)²+(8/3)² = 121/9+64/9 = 185/9，到 μ₂ = 5/9 → 簇2
- (4,5)：到 μ₁ = (8/3)²+(11/3)² = 64/9+121/9 = 185/9，到 μ₂ = 5/9 → 簇2

分配结果与第 1 轮完全相同，中心不再变化，收敛。J₂ = 4/9 ≈ 0.444。

畸变值全程变化：J₀（初始中心下）= (0+1+1+0+1+1)/6 = 2/3 ≈ 0.667 → J₁（第 1 轮后）= 4/9 ≈ 0.444 → J₂（第 2 轮后）= 4/9（不再下降，收敛）。

J 每轮下降且最终稳定，正是"畸变值单调不增"的直观体现。

**常见误区/注意点**：
- 分配比较时直接用距离平方即可，不必开根号（开根不改变大小顺序）。
- 距离平方受特征量纲影响：身高（厘米级）与体重（千克级）混用时长量级的特征会主导距离，应先标准化各特征。
- K 必须在运行前给定，K-Means 不会自动决定簇数。
- 结果依赖初始中心，不同初始化可能收敛到不同的局部最优。
- 可能出现空簇（某中心更新后没有任何样本归属），需重新初始化或直接删除该簇。
- 分配规则是"距离最近的中心"，不是"距离任意样本最近"。

## 卡片：选择 K 与初始化

**定义**：簇数 K 是超参数、初始中心的选择影响收敛结果；本卡片给出"怎么选初始中心"与"怎么定 K"两类实用做法。

**公式/伪代码**：

```
多次随机初始化：
for t = 1, 2, …, T:
    从训练样本中不放回地随机选 K 个样本作为初始中心
    运行 K-Means 直到收敛，记录畸变值 J_t
取 J* = min(J_1, …, J_T) 对应的一次结果

肘部法则（选 K）：
for K = 1, 2, …, K_max:
    运行 K-Means，记录畸变值 J(K)
画出 J 随 K 变化的曲线，找"拐点"作为最终 K
```

**符号表**：T：随机初始化尝试次数；J_t：第 t 次尝试的畸变值；J*：多次尝试中的最小畸变值；K_max：考察的簇数上限；J(K)：使用 K 个簇时的畸变值。

**为什么（推导/设计动机）**：
1. 随机初始化可能落入局部最优（例如两个初始中心恰好都落在同一真实簇附近）。多做几次、取 J 最小者，相当于用多次抽样逼近全局最优，代价只是 T 倍的运行时间。
2. 肘部法则的原理：K 增加时 J 必然单调下降（簇多了总能贴得更紧），但边际收益递减；曲线从"陡降"转为"平缓"的拐点，说明再加簇已经收益不大。
3. 拐点不存在时（大量真实数据如此），J 曲线无懈可击地单调下降，K 只能交给业务目标决定。

**直觉**：蒙选择题多蒙几遍取最高分；选 K 如同订 T恤——尺码档位是商家决定的经营决策，不是数学公式算出来的。

**实例**：
- 肘部法则：某数据集不同 K 的畸变值：K=1 → J=300；K=2 → J=120；K=3 → J=45；K=4 → J=42；K=5 → J=40。K 从 1 到 3 时 J 骤降（300→45），K=3 之后几乎平缓，拐点在 K=3，故选 K=3。注意：若曲线是 300、280、260、250、240，则无拐点，肘部法则失效。
- 多次初始化：以上一卡片的 6 点数据为例，若初始中心取 μ₁=(1,1)、μ₂=(2,1)，两个中心都落在左下角，K-Means 可能收敛到把数据上下切分的较差解（J 更大）；取 T=100 次运行中的最小 J 即可规避这类情况。
- T恤尺码：K=3（S/M/L）还是 K=5（XS/S/M/L/XL），取决于供应链成本与顾客满意度——档位越多库存压力越大，档位太少顾客买不到合身码。给客户分群做营销同理：K=4 与 K=8 哪个更贴合运营目标就选哪个。K 是业务决策，不只是数学问题。

**常见误区/注意点**：
- 不能为了"J 最小"无限加大 K：K=m 时每个样本自成一簇、J=0，毫无意义。
- 肘部法则在真实数据上常常没有明显拐点，不要强求。
- 随机初始化应**从样本中选**，而不是随机取任意坐标点。
- 多次初始化只缓解、不消除局部最优；T 过大时收益递减。

## 卡片：异常检测问题与思路

**定义**：异常检测（Anomaly Detection）是给定大量"正常"样本，找出与正常模式差异极大的"异常"样本的无监督问题。

**公式/伪代码**：

```
训练阶段（只用正常样本）：
    对每个特征 j：估计均值 μⱼ 与方差 σⱼ²

预测阶段：
    对新样本 x：p(x) = Πⱼ p(xⱼ; μⱼ, σⱼ²)
    若 p(x) < ε → 判定为异常（预警/拦截/检修）
    否则 → 判定为正常
```

**符号表**：x：待判样本；xⱼ：样本的第 j 个特征；μⱼ / σⱼ²：特征 j 在正常样本上的均值与方差；p(x)：样本 x 属于"正常"的估计概率；ε：判定阈值，越小越严格。

**为什么（推导/设计动机）**：
1. 异常样本在现实中极其稀少（万分之一量级），而且**类型未知**——新出现的欺诈手段、新故障模式在训练时根本不存在。
2. 二分类（监督学习）需要两类样本都足够多，且测试时的类别要能被训练时的类别覆盖；异常场景两条都不满足。
3. 换个思路：不学"异常长什么样"，改学"正常长什么样"。只要正常数据多、模式稳定，就能用一个概率模型描述正常，凡是概率极低的都值得怀疑。这让模型天生能发现**从未见过**的异常。

**直觉**：像机场安检——只训练"良民长什么样"，任何不符合通行画像的人都被拦下，不需要事先知道"所有坏人都长什么样"。本质一句话：**给正常建模，让异常自己暴露。**

**实例**：
- 典型场景：信用卡欺诈检测（正常消费 vs 盗刷）、服务器故障预警（正常负载 vs 濒死状态）、飞机引擎监控（正常振动/温度 vs 故障前兆）。
- 与监督学习的对比：

| 维度 | 异常检测（无监督） | 二分类（监督） |
|---|---|---|
| 数据构成 | 大量正常 + 极少量异常 | 正、反两类样本都充足 |
| 学习内容 | 只学"正常"的分布 | 学两类之间的决策边界 |
| 异常类型 | 未知，可能不断演化 | 类别固定，训练时已知 |
| 适用场景 | 欺诈、故障、入侵（罕见且多变） | 垃圾邮件、图像分类（两类常见） |

- 「异常类型未知」实例：某银行训练欺诈分类器时见过的欺诈只有"盗刷"（特征：异地、大额、深夜）。上线后出现新型"钓鱼小额试探"欺诈：金额小、本地、白天，特征全部落在分类器认定的"正常区"，被放行；而异常检测对这批样本算出的 p(x) 因"本地+小额"的组合在正常数据中几乎没出现过而低于 ε，成功预警。分类器守旧，异常检测迎新。

**常见误区/注意点**：
- 异常检测不是"预测异常类别"，它只回答"是否异常"。
- 不要用聚类后"极小簇"直接充当异常检测：那是另一种启发式，与基于概率密度的 p(x)<ε 是不同路线。
- 训练时混入异常样本会污染 μ、σ，让"正常"的定义被带偏。

## 卡片：高斯分布与概率模型

**定义**：假设每个正常特征服从高斯（正态）分布，用均值 μ 与方差 σ² 描述；一个样本的"正常程度"等于各特征高斯概率的乘积 p(x)，p(x) 低于阈值 ε 即判为异常。

**公式/伪代码**：

```
单个特征 x 服从高斯分布：
    p(x; μ, σ²) = (1 / (√(2π)·σ)) · exp(−(x − μ)² / (2σ²))

参数估计（从 m 个正常样本，最大似然估计）：
    μ  = (1/m) · Σᵢ₌₁ᵐ x⁽ⁱ⁾
    σ² = (1/m) · Σᵢ₌₁ᵐ (x⁽ⁱ⁾ − μ)²

多特征联合（假设各特征相互独立，概率相乘）：
    p(x) = Πⱼ₌₁ⁿ p(xⱼ; μⱼ, σⱼ²)

判定规则：
    p(x) < ε → 异常；p(x) ≥ ε → 正常
```

**符号表**：

| 符号 | 含义 |
|---|---|
| x | 单个特征取值（或待判样本） |
| μ | 均值，分布的中心位置 |
| σ² | 方差，分布的离散程度；σ 为标准差 |
| π | 圆周率，√(2π)≈2.507 |
| e | 自然常数 ≈2.718 |
| m | 正常样本个数 |
| x⁽ⁱ⁾ | 第 i 个正常样本的特征值 |
| n | 特征个数 |
| xⱼ | 样本的第 j 个特征 |
| μⱼ, σⱼ² | 特征 j 的均值与方差 |
| ε | 判定阈值（由验证集调出） |

**为什么（推导/设计动机）**：
1. 高斯分布是最自然的"正常"模型：大量测量值围绕一个中心波动、偏离越远越少见，钟形曲线正好描述这种性质；中心极限定理也支持用高斯近似很多叠加效应。
2. μ、σ² 的来历：对正常样本的对数似然 ln L = Σᵢ ln p(x⁽ⁱ⁾) 分别关于 μ、σ² 求导并令导数为 0，解得 μ 为样本均值、σ² 为样本方差。注意这里的 σ² 除以 m（而非 m−1），这是异常检测的惯例，因为只关心对"正常"密度的拟合。
3. 各特征"独立相乘"是朴素假设，计算简单且在特征相关性不强时效果很好；特征强相关时应改用多元高斯或先做特征工程。

**直觉**：钟形曲线——越靠近均值越常见（概率越高），离均值 3 个标准差之外几乎绝迹。正常人群体重围绕均值波动，突然出现"300 公斤"的样本，概率趋近于零，就是异常。

**实例（完整手算）**：
某引擎正常状态的"温度特征"取 5 个样本：12, 14, 12, 14, 13。
- 均值：μ = (12+14+12+14+13)/5 = 65/5 = 13。
- 方差：逐个计算偏差平方：
  (12−13)² = 1；(14−13)² = 1；(12−13)² = 1；(14−13)² = 1；(13−13)² = 0；
  平方和 = 1+1+1+1+0 = 4；σ² = 4/5 = 0.8；σ = √0.8 ≈ 0.894。
- 正常点 x=13（恰为均值）：p(13) = 1/(√(2π)·0.894) ≈ 1/2.241 ≈ 0.446（分布的峰值）。
- 离群点 x=18：先算 (x−μ)² = (18−13)² = 25；
  指数部分 −(x−μ)²/(2σ²) = −25/(2×0.8) = −25/1.6 = −15.625；
  分母 √(2π)·σ ≈ 2.507×0.894 ≈ 2.241；
  p(18) = (1/2.241)·e^(−15.625) ≈ 0.446 × 1.64×10⁻⁷ ≈ **7.3×10⁻⁸**。
- 对比：正常点概率约 0.446，离群点概率约 7.3×10⁻⁸，相差约 600 万倍。若取 ε=0.01，则 p(18)≪ε 判定为异常，p(13)≫ε 判定为正常。

**常见误区/注意点**：
- 特征明显偏斜（如收入、访问量）时直接套高斯会严重失真，先做对数等变换再建模。
- 多特征概率连乘会让数值小到浮点数下溢，实际实现常用对数（把 p 的连乘换成 log p 的累加）。
- 若某特征在所有样本上取值相同（σ=0），公式除以 σ 会崩溃，需给 σ 加极小值或剔除该特征。
- 高斯假设是近似而非事实：特征分布严重非对称时，p(x) 只能算启发式分数，不要把它当真实概率使用。

## 卡片：评估与调优

**定义**：异常检测配合少量标注（正常/异常）来调阈值 ε、选特征，并用精确率/召回率类指标（F1）评估；特征工程是决定成败的关键环节。

**公式/伪代码**：

```
精确率 P = TP / (TP + FP)      召回率 R = TP / (TP + FN)
F1 = 2·P·R / (P + R)

调 ε 的流程：
1. 训练集：只用正常样本，估计 μ、σ²
2. 验证集：含正常+异常，对每个候选 ε 计算 F1
3. 选使 F1 最大的 ε
4. 测试集：正常+异常，用最终 ε 报告指标
```

**符号表**：TP：异常被正确检出的数量；FP：正常被误报的数量；FN：异常被漏报的数量；P：精确率（报出的异常中真异常的比例）；R：召回率（真异常中被报出的比例）；F1：两者的调和平均；ε：判定阈值。

**为什么（推导/设计动机）**：
1. 异常占比极小（如 0.1%）时，模型"全部判正常"的准确率也有 99.9%，准确率完全失去区分度；精确率/召回率分别惩罚"误报"与"漏报"。
2. F1 把精确率与召回率做调和平均，避免调 ε 时顾此失彼（ε 过严则漏报多、R 低；ε 过松则误报多、P 低）。
3. 训练/验证/测试三集分离：训练只学正常分布，验证集专挑 ε，测试集最后做无偏评估，防止用验证集反复调参导致的过拟合。

**直觉**：安检想"抓住所有坏人"（R 高）又不想"拦下所有好人"（P 高），F1 就是两者的平衡杆。本质：**漏掉一个真异常和误报一个正常，代价不同，必须分开算。**

**实例**：
- 调 ε：验证集有 10 个正常、2 个异常。
  - ε=0.1：预测 5 个异常（2 个真 + 3 个误报）→ TP=2, FP=3, FN=0 → P=2/5=0.4, R=1, F1=2×0.4×1/(0.4+1)≈0.571。
  - ε=0.01：预测 3 个异常（2 个真 + 1 个误报）→ TP=2, FP=1, FN=0 → P=2/3≈0.667, R=1, F1=2×(2/3)×1/(2/3+1)=4/5=0.8。
  - ε=0.001：预测 1 个异常（漏掉 1 个真异常）→ TP=1, FP=0, FN=1 → P=1, R=0.5, F1=2×1×0.5/(1+0.5)≈0.667。
  - 选 F1 最大的 ε=0.01。对比：ε=0.01 时准确率=(12−1)/12≈0.917，看起来很高，却掩盖了"把正常用户误报为欺诈"的问题——这正是必须用 F1 的原因。
- 特征选择·对数变换：某特征为"年收入"，训练值 1.5 万、2 万、6 万、10 万、25 万，分布严重右偏（最大值是最小值的 16 倍以上），直接拟合高斯会把均值拉偏、方差撑大，使异常难检出。做 log₁₀ 变换后：4.18、4.30、4.78、5.00、5.40，区间被压缩到约 1.29 倍、分布接近对称，高斯拟合显著改善。
- 组合特征：服务器故障监控中，CPU 使用率 A 与内存使用率 B 单独看都在正常范围，但"死循环"表现为 A 高而 B 低：正常机 A/B≈1.0（标准差约 0.2），故障机 A=0.9、B=0.1，A/B=9.0，比正常均值偏离约 40 个标准差。新增特征 A/B 后，这类故障的 p(x) 骤降、一抓一个准；而只看 A、B 两个原始特征，它们"谁都不极端"，故障被互相掩盖。

**常见误区/注意点**：
- 不用准确率评估：异常样本太少时准确率被"全判正常"主导，永远虚高。
- 训练集不能混入异常样本，否则 μ、σ 被污染，正常边界被拉宽。
- ε 必须在验证集上选，不能拍脑袋，也不能按训练集的 p 值分布选（会过拟合训练数据）。
- 特征严重偏斜不做变换就上高斯，p(x) 形同虚设。
- 两个特征各自正常、组合才异常时，不构造组合特征，模型永远发现不了这类故障。

## 卡片：易错点

| 要点 | 说明 |
|---|---|
| K 是超参数，不是算法自动算出来的 | 肘部法则未必有拐点；按业务目标（T恤档位、营销分群）选 K 更实际 |
| 必须多次随机初始化 | 单次初始化可能落入局部最优；取 T 次运行中畸变值最小者 |
| 不能用"J 越小越好"选 K | K 越大 J 单调下降，K=m 时 J=0；K 的选择必须结合业务 |
| 异常检测 ≠ 二分类 | 异常样本极少且类型未知时，二分类没有足够数据学边界，且永远防不住新型异常 |
| 特征要先接近正态 | 偏斜特征（收入、访问量）先做 log、开方等变换，否则 μ、σ 失真，p(x) 失效 |
| σ 估计除以 m 而非 m−1 | 异常检测惯例是拟合"正常密度"；与统计推断中的样本方差不同，不要混用 |
| 特征必须标准化/可比 | K-Means 用距离平方，量纲大的特征会主导距离；异常检测中要保证各特征概率相乘有意义 |
| ε 用 F1 在验证集上调 | 不用准确率（异常太罕见，准确率虚高）；训练/验证/测试三集职责要分开 |
| 组合特征常是关键 | 单特征都"正常"、组合才异常时，构造 A/B 类比值特征往往立竿见影 |
| 下溢与除零 | 多特征概率连乘会下溢，改用对数累加；σ=0 时给 σ 加极小值保护 |
