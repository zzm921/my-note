# AI Agent是什么

AI Agent 是一个拥有目标感知，自助规划，迭代执行，记忆反思能力，可以主动完成复杂任务的自治AI实体。

# 标准agent的五大核心组件
## 感知层
接受外部信息：用户执行，工具返回结果，环境消息，其他agent发来的任务
## 2、记忆层
- 短期记忆：当前任务上下文，对话历史
- 长期记忆：知识库，国网任务经验，用户偏好，历史成果文件
## 规划/推理层
llm 作为思考器：
- 解析目标
- 把大人物拆分成多个子步骤
- 判断下一步该干什么，调用哪个工具，还是提交给另一个agent
- 自我反思：上一步失败了，换一条方案
## 动作/工具层（Action/Tools）

agen手动执行能力

## 5、输出层it
返回回答，生成文件等
循环闭环，感知->思考规划->执行动作->观察结果->在思考
