# Toolformer 与工具学习

## 大纲

### 1. 概念
- Toolformer：让模型**自己学会何时调用什么工具**（通过自监督学习），而非仅靠上下文示例
- 现代实践更多采用 **Function Calling 微调 / 提示**，原理同源：让模型具备工具使用能力

### 2. 核心思想
- 在文本中插入工具调用标记：`[工具名(参数) → 结果]`
- 模型学习：遇到特定需求时调用工具，把结果融入后续生成

### 3. 与 Function Calling 的区别
| | Toolformer | Function Calling |
|---|---|---|
| 能力来源 | 自监督训练学习 | 模型原生支持 + 工具 Schema |
| 部署方式 | 需训练/微调 | 提示即可使用 |
| 灵活性 | 工具集合固定 | 工具可动态增删 |

### 4. 工具学习的训练流程（Toolformer）
```
1. 构造样本：文本片段 + 期望的工具调用
2. 采样候选调用：LLM 生成多个调用位置
3. 执行并评估：调用结果能否降低损失
4. 保留有效样本，微调模型
```

### 5. 现代实践
- 使用支持 Function Calling 的模型 + 工具 Schema
- 通过 few-shot 示例提升工具选择准确率
- 微调：针对特定工具集合做指令微调

### 6. 设计要点
- 工具数量控制：过多工具增加选择难度
- 工具描述质量决定调用准确率
- 区分"必须调用"与"可选调用"

### 7. 常见问题
- 过度调用工具（简单问题也调）
- 调用顺序错误（依赖关系没理解）
- 参数不准确

### 8. 适用场景
- 需要稳定、高频使用特定工具的 Agent
- 对调用准确率要求高的生产系统
