## 核心主线

1. **概念**：Agent 是目标驱动、自主规划、迭代执行、记忆反思的自治实体
2. **架构**：五大组件构成闭环（感知→思考→行动→观察→再思考）
3. **能力**：工具、规划、记忆、反思、协作是 Agent 的价值来源
4. **范式**：不同任务选不同范式（ReAct / Plan-Execute / Reflexion / Multi-Agent）
5. **工程**：安全护栏、状态管理、可观测性决定生产可用性
6. **测评**：L1 行为层 + L2 语义层 双维度评估
7. **应用**：从问答助手到自动化工作流

## 学习路径建议

- 入门：01 基础概念 → 02 核心架构 → 05 工程实现（搭建步骤）
- 进阶：03 核心能力 → 04 构建范式
- 生产：06 测评优化 → 05（安全护栏/可观测性）
- 实践：07 应用场景
