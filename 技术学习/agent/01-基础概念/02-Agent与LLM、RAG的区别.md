# Agent 与 LLM、RAG 的区别

## 大纲

### 1. 三者定位
| | LLM | RAG | Agent |
|---|---|---|---|
| 本质 | 文本生成模型 | 检索增强生成架构 | 自主任务执行实体 |
| 输入 | Prompt | 问题 + 检索上下文 | 目标 + 环境 + 工具 |
| 输出 | 文本 | 基于事实的文本 | 动作序列 + 最终结果 |
| 主动性 | 被动 | 被动 | 主动 |

### 2. LLM vs Agent
- LLM 无状态、无工具、无循环
- Agent = LLM（大脑）+ 工具（手脚）+ 记忆（经验）+ 循环（执行）
- 一句话：**LLM 是零件，Agent 是组装好的机器**

### 3. RAG vs Agent
- RAG：把**知识**接入生成过程（外挂知识库）
- Agent：把**行动能力**接入生成过程（外挂工具和流程）
- 共同点：都为了弥补 LLM 能力边界（知识过时 / 无法执行）

### 4. 关系
- Agent 内部可以使用 RAG（记忆/知识检索）
- RAG 系统可以被 Agent 当作一个"工具"调用
- 两者互补而非互斥

### 5. 组合形态
- 简单 RAG：静态知识问答
- Agentic RAG：Agent 自主决定何时检索、检索什么（见 Agentic RAG）

### 6. 选型建议
- 只需知识问答 → RAG
- 需要多步操作与工具 → Agent
- 需要"边查边做" → Agentic RAG
