# 规划推理层（Planning / Reasoning）

## 大纲

### 1. 职责
Agent 的"大脑"，由 LLM 充当思考器，负责理解目标、制定计划、决定下一步动作。

### 2. 核心能力
| 能力 | 说明 |
|---|---|
| 目标解析 | 理解用户意图，明确要达成的结果 |
| 任务拆解 | 把大任务拆成多个可执行子步骤 |
| 动作决策 | 判断下一步：调用哪个工具 / 提交给谁 / 直接回答 |
| 自我反思 | 上一步失败后调整方案，换一条路径 |
| 推理链 | 多步逻辑推理（思维链） |

### 3. 工作方式
```
目标 → 拆解计划 → 执行一步 → 观察结果 → 修正计划 → ...
```

### 4. 规划策略
- 一次性规划（Plan-and-Execute）：先出完整计划再执行
- 逐步规划（ReAct）：边做边想
- 动态重规划：计划偏离时随时修订

### 5. 推理方法
- Chain-of-Thought（思维链）
- 工具选择推理：根据任务选择最合适的工具
- 结果评估推理：判断当前信息是否足够

### 6. 关键设计
- 决策可解释：记录"为什么做这个决定"
- 失败回退：规划层必须能处理执行失败
- 成本控制：减少无效推理轮次

### 7. 常见问题
- 规划过度/规划不足
- 目标漂移（做着做着忘了原始目标）
- 循环卡死（反复做同一件事）

### 8. 实现要点
- 用结构化输出约束规划格式（JSON 计划）
- 给计划加上限（最大步数）
- 与记忆层联动，避免重复犯错
