# 五大核心组件

## 大纲

### 1. 总览
Agent 由五大组件构成，协作形成"感知 → 思考 → 行动 → 观察 → 再思考"的闭环。

```
        ┌───────────── 循环 ─────────────┐
        ▼                                │
  ┌──────────┐   ┌──────────┐   ┌────────────┐
  │  感知层   │ → │ 规划推理层 │ → │ 工具行动层   │
  │  Perception│  │Planning│ │ │ Action/Tools│
  └──────────┘   └──────────┘   └────────────┘
        ▲           │  ↑             │
        │        ┌──┴───┐            │
        │        │ 记忆层 │            │
        │        │Memory │            │
        │        └──────┘            │
        └─────────────────────────────┘
                      │
                ┌─────▼─────┐
                │  输出层     │
                │  Output    │
                └───────────┘
```

### 2. 组件职责速览
| 组件 | 职责 | 关键问题 |
|---|---|---|
| 感知层 | 接收用户/环境/工具/其他Agent信息 | 如何理解输入？ |
| 记忆层 | 短期上下文 + 长期经验 | 记什么、怎么存、何时取？ |
| 规划推理层 | 拆解目标、决定下一步 | 下一步做什么？ |
| 工具行动层 | 执行动作、调用工具 | 如何落地？ |
| 输出层 | 生成答案/文件/触发流程 | 如何交付？ |

### 3. 协作流程
1. 感知层接收任务
2. 规划推理层拆解并决定动作
3. 记忆层提供上下文与历史经验
4. 工具行动层执行动作，观察结果
5. 结果回传感知层，进入下一轮
6. 目标达成后由输出层交付

### 4. 组件实现要点
- 感知层：消息标准化、输入校验
- 记忆层：分层存储、检索策略
- 规划层：任务分解、工具选择
- 行动层：工具封装、错误处理
- 输出层：格式化、多模态交付

### 5. 常见问题
- 组件耦合过深导致难扩展
- 记忆与上下文管理不当导致"失忆"
- 缺少护栏导致行为失控

### 6. 设计原则
- 组件解耦、接口标准化
- 每一层可观测（日志可追踪）
- 安全与权限贯穿全流程
