# 记忆层（Memory）

## 大纲

### 1. 职责
保存对话上下文、任务状态与历史经验，让 Agent 在任务内保持连贯、跨任务积累知识。

### 2. 记忆分层
| 层级 | 生命周期 | 内容 |
|---|---|---|
| 感知记忆 | 单次请求 | 原始输入数据 |
| 工作记忆（短期） | 当前会话 | 对话历史、任务上下文 |
| 长期记忆 | 跨会话 | 知识库、经验、用户偏好、历史成果 |

### 3. 长期记忆细分
- 情景记忆：历史交互轨迹、任务经历、对话摘要（半结构化）
- 实体记忆：抽取沉淀的稳定事实（用户信息、项目配置）
- 语义记忆：领域知识、规范文档

### 4. 记忆存什么
- 值得存：用户偏好、关键结论、外部知识
- 不值得存：中间推理过程、工具原始数据、闲聊

### 5. 记忆怎么存
- 向量数据库：非结构化文本（知识、摘要），语义检索
- 关系型 / KV：结构化字段（偏好、配置），精确查询
- 混合存储：两者结合，主流做法

### 6. 记忆何时取
- 主动检索：任务开始前注入 System Prompt
- 被动触发：封装成 Tool，推理过程中按需调用

### 7. 记忆管理
- 去重更新、过期清理、权限隔离、质量控制

### 8. 常见问题
- 上下文超长 → 摘要压缩
- 记忆污染 → 检索结果注入不可信内容
- 记忆冲突 → 版本与时效管理
