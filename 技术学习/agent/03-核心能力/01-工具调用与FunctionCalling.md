# 工具调用与 Function Calling

## 大纲

### 1. 概念
- Function Calling：模型在生成时输出结构化"工具调用指令"，系统执行后把结果回传
- 是 Agent 获得"行动能力"的基础机制

### 2. 工具定义（Schema）
```
工具 = 名称 + 描述 + 参数定义(JSON Schema)
描述决定模型何时选用；参数定义决定如何填参
```

### 3. 调用流程
```
1. 携带 tools 定义请求 LLM
2. LLM 判断是否需要工具 → 输出 tool_call(name, arguments)
3. 系统校验参数并执行工具
4. 工具结果作为消息回传
5. LLM 基于结果继续生成
```

### 4. 关键技术点
| 要点 | 说明 |
|---|---|
| 参数强制 | strict mode 保证输出合法 JSON |
| 并行调用 | 一次输出多个 tool_call 提升效率 |
| 结果截断 | 超长结果摘要化，避免撑爆上下文 |
| 错误回传 | 失败信息要让模型理解原因 |

### 5. 提升调用准确率
- 工具描述写清使用场景与参数含义
- 提供参数示例（few-shot）
- 相似工具减少，避免模型选错
- 高频组合预置为"复合工具"

### 6. 常见问题
- 幻觉调用（工具不存在）→ 严格 schema 约束
- 参数编造（ID 不存在）→ 校验 + 明确错误提示
- 调用死循环 → 次数上限

### 7. 实现要点
- 工具注册中心统一管理
- 工具执行可观测（日志、耗时、结果）
- 高危工具叠加权限校验
