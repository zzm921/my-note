# 上下文与状态管理

## 大纲

### 1. 概念
- 管理 Agent 运行中的**对话上下文与任务状态**，保证长任务的连贯与正确

### 2. 上下文管理
- 上下文组成：系统角色、对话历史、工具结果、任务状态
- 上下文窗口有限 → 需要压缩与取舍

### 3. 上下文压缩策略
| 策略 | 做法 |
|---|---|
| 裁剪 | 丢弃早期冗余消息 |
| 摘要 | 把历史压缩成摘要（滚动摘要） |
| 关键信息提取 | 只保留关键结论与决策 |
| 结构化状态 | 用固定字段保存任务进度 |

### 4. 状态管理
- 状态内容：任务进度、已完成步骤、中间结果、变量
- 状态存储：内存（会话内）/ 持久化（跨会话）
- 状态同步：多 Agent 间共享状态

```
状态 = {task_id, step, done[], results[], variables{}, error?}
```

### 5. 长任务支持
- 分段执行：每段只携带必要上下文
- 断点续跑：崩溃后从状态恢复
- 检查点：关键节点保存状态

### 6. 常见问题
- 上下文爆长 → 摘要 + 裁剪
- 状态丢失 → 持久化 + 恢复机制
- 状态不一致（多 Agent）→ 单一事实源

### 7. 实现要点
- 状态与上下文分离（状态不塞进 Prompt，按需注入）
- 上下文有优先级（关键信息永不丢）
- 可观测：能查"当前状态是什么"
