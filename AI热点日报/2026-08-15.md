💡 趋势洞察

1. "不换基座、只炼后训"成为开源旗舰新范式：GLM-5.3（743B 基座 + 后训练 Scaling，编程 +50%）与 DeepSeek V4 Pro 0813 路线一致——竞争从"堆参数"转向"后训练工程"，两周后开放权重延续"旗舰发布即开源"节奏。对工程团队：同一基座下，后训练数据配方与长程任务基准（Terminal Bench 3.0 等）将成为模型选型的新依据。

2. Agent 价值叙事全面切换到 ROI：公众号共识"企业不关心你有多聪明，只关心你能省多少钱"与 36氪"OpenAI 响指后 Agent 厂商重建护城河"相互印证——基础模型原生 Agent 化（深度研究、长程任务内置化）正在挤压中间层 Agent 厂商，垂直场景数据、交付与服务闭环成为新护城河；企业采购从 POC 演示转向可量化的成本节省指标。

3. 安全成为大模型竞争新维度：GLM-5.3 涌现网络安全能力（发现潜伏 40 年缺陷）、AI Agent 自动化渗透测试、企业 AI 安全治理路径文章同日密集出现——"安全/红队 Agent"可能是最快规模化变现的 Agent 场景之一，漏洞挖掘与渗透能力正在进入模型官方评测口径。

4. 大模型公司集体走向二级市场：智谱（02513.HK）首份财报 + 月之暗面冲刺 IPO（36氪"窗口期不会等太久"）——"拼完技术终要拼算力"，上市融资支撑算力资本开支成为大模型创业公司生存主线；"大模型，别飞成协和号"的反思提示商业化节奏风险。

5. AI 基础设施进入"光 + 存储"双紧周期：英伟达 CPO 交换机量产（硅光/共封装光学）与"明年最严重存储荒"预警同现热榜——算力供应链从 GPU 蔓延到互联（光模块/CPO）与存储（HBM/DRAM），基础设施成本与供应节奏将决定下半年模型厂商与云厂商的扩张速度。
