# 感知层（Perception）

## 大纲

### 1. 职责
接收并理解 Agent 需要感知的全部外部信息，是 Agent 与外界交互的"入口"。

### 2. 感知的信息类型
| 类型 | 示例 |
|---|---|
| 用户指令 | 自然语言任务、命令 |
| 工具结果 | API 返回、查询结果、执行回执 |
| 环境消息 | 系统事件、定时触发、状态变化 |
| 其他 Agent 消息 | 子任务下发、协作请求、结果回传 |

### 3. 感知输入的处理
- 消息标准化：统一消息结构（role / content / metadata）
- 多模态输入：文本、图片、语音、文件
- 输入校验与清洗：去噪、格式校验、安全过滤
- 意图解析：把原始输入转为可执行的目标描述

### 4. 感知与理解的关系
- 感知 ≠ 理解：感知负责"收"，理解交给规划推理层
- 感知层应保留原始信息的可追踪性（来源、时间、会话）

### 5. 关键技术
- 多模态理解（图片/语音转文本）
- 意图分类与实体抽取
- 消息队列与事件订阅（异步触发）

### 6. 设计要点
- 接口统一，新增输入源不影响内部逻辑
- 输入有兜底（未知指令的降级处理）
- 记录感知日志，支撑排查与复盘
