# 输出层（Output）

## 大纲

### 1. 职责
把 Agent 的执行结果以合适的形式交付给用户或下游系统。

### 2. 输出类型
| 类型 | 示例 |
|---|---|
| 文本回答 | 自然语言结论、解释 |
| 文件生成 | 报告、表格、文档、图表 |
| 结构化数据 | JSON、接口回执 |
| 多模态 | 图片、音频、视频 |
| 触发动作 | 发送消息、下单、更新状态 |

### 3. 输出设计要点
- 格式规范化：按约定结构输出（Markdown / JSON）
- 引用溯源：回答附依据来源，提升可信度
- 长度控制：按场景分简洁/详细
- 失败输出：明确告知"没做到什么、为什么"

### 4. 输出质量要求
- 忠实：基于事实与执行结果，不编造
- 相关：回应用户原始诉求
- 完整：覆盖任务的每个子目标
- 可验证：关键结论可追溯

### 5. 输出流程
```
执行结果汇总
  → 校验（是否满足目标？）
  → 格式化（模板 / 渲染）
  → 交付（回复 / 写文件 / 触发下游）
```

### 6. 常见问题
- 输出与目标脱节（答非所问）
- 结果丢失中间过程（无法解释怎么得出的）
- 超长输出失控 → 分段/摘要

### 7. 实现要点
- 用输出模板约束结构
- 重要结论附数据来源
- 交付失败时给出可重试的提示
