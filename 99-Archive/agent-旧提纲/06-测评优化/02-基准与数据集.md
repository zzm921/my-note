# 测评基准与数据集

## 大纲

### 1. 作用
统一的基准与数据集让 Agent 能力**可量化、可对比、可回归**。

### 2. 常见 Agent 基准
| 基准 | 评测内容 |
|---|---|
| GAIA | 通用助手型任务（多步推理+工具） |
| AgentBench | 多环境综合（系统操作、DB、游戏等） |
| WebArena | 真实网页操作任务 |
| τ-bench | 客服/零售工具任务 |
| SWE-bench | 代码仓库问题修复 |

### 3. 自建数据集设计
- 任务定义：目标 + 环境 + 可用工具
- 期望轨迹：参考执行路径（用于 L1）
- 金标准答案：用于 L2 正确性
- 难度分层：简单/中等/困难

### 4. 数据要求
- 覆盖真实场景分布
- 边界与反例（错误输入、越权请求）
- 可重复执行（环境可控、无随机影响）

### 5. 评估协议
- 固定模型版本与参数
- 固定环境（工具 mock / 沙箱）
- 固定指标口径与裁判提示词
- 记录版本，支持回归对比

### 6. 度量方式
- 指标聚合：均值/分桶（按任务类型、难度）
- 轨迹匹配：LLM 判断或规则比对
- 成本度量：token、调用次数、耗时

### 7. 数据与隐私
- 使用脱敏数据
- 评估环境与生产隔离

### 8. 持续演进
- 失败案例沉淀为回归样本
- 定期扩充数据集防过拟合
- 版本化维护基准
