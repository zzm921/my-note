# 反思与自我修正

## 大纲

### 1. 概念
- Agent 对自身执行结果进行**评估 → 反思 → 调整**，是提升复杂任务成功率的关键能力

### 2. 反思的类型
| 类型 | 内容 |
|---|---|
| 结果反思 | 本次输出是否达标，哪里不足 |
| 过程反思 | 决策路径哪里错了，为何失败 |
| 策略反思 | 换个思路/工具/查询方式再试 |

### 3. 反思流程
```
执行 → 评估结果（是否满足目标/标准）
  ├─ 达标 → 输出
  └─ 不达标 → 反思原因 → 生成修正策略 → 重试
                  ↑
        带着教训进入下一轮（记住不再犯）
```

### 4. 评估信号
- 自评：让模型自己打分（质量、忠实度）
- 外部校验：工具报错、规则校验、人工反馈
- 比较校验：与预期结果/金标准对比

### 5. 修正策略
- 查询改写：换个关键词/拆子问题
- 换工具：当前工具不合适
- 补充信息：先检索再回答
- 换范式：从直接生成改为分步执行

### 6. 实现方式
- 内置校验器（Validator）：生成后自动检查
- 反思循环（Reflexion）：失败后生成"教训"注入下一轮
- 重试机制：限次、限时，避免无限循环

### 7. 常见问题
- 过度反思（成本爆炸）
- 反思不彻底（重复同样的错）
- 无脑重试（不做实质调整）

### 8. 设计要点
- 设置重试上限与兜底答案
- 反思要落到"下一次具体怎么做"
- 记录反思历史，避免重复犯错
