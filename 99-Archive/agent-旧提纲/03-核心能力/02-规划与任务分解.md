# 规划与任务分解

## 大纲

### 1. 概念
- 把复杂目标拆成**有序、可执行**的子任务，是 Agent 处理长任务的核心能力

### 2. 规划方式
| 方式 | 说明 | 适用 |
|---|---|---|
| 一次性规划 | 先输出完整计划再执行 | 步骤明确的任务 |
| 逐步规划 | 边执行边规划下一步 | 结果依赖前一步 |
| 分层规划 | 高层策略 + 低层执行 | 大规模复杂任务 |

### 3. 任务拆解原则
- **可执行**：每个子任务能被一个动作/工具完成
- **有序**：子任务有依赖顺序（拓扑）
- **可验证**：每个子任务有完成标准
- **可合并**：粒度适中，不过度拆解

### 4. 规划输出结构
```
计划 = {
  goal: 目标描述,
  steps: [
    {id, 描述, 依赖, 工具, 完成标准}
  ]
}
```

### 5. 规划流程
```
目标解析 → 步骤拆解 → 排序定依赖 → 执行 → 动态调整
                                    ↑
                    结果反馈 → 计划修订（重规划）
```

### 6. 动态重规划
- 步骤失败 → 跳过/替代方案
- 信息不足 → 插入检索/询问步骤
- 目标变化 → 重新解析目标

### 7. 常见问题
- 过度拆解（成本高、易出错）
- 规划与执行脱节（计划脱离实际）
- 忘记原始目标（目标漂移）

### 8. 实现要点
- 用结构化输出（JSON）约束计划格式
- 设置最大步数与超时
- 关键节点记录计划与执行差异（可观测）
