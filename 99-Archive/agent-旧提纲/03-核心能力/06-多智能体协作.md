# 多智能体协作

## 大纲

### 1. 概念
- 多个 Agent 按角色分工，通过消息/共享状态协作完成复杂任务

### 2. 协作模式
| 模式 | 说明 | 适用 |
|---|---|---|
| 垂直分工 | 规划者 → 执行者 → 评审者 流水线 | 流程固定 |
| 水平分工 | 多个执行者并行处理不同子任务 | 可并行 |
| 辩论评审 | 多 Agent 互相评审提意见 | 质量要求高 |
| 层级结构 | 主 Agent 管理子 Agent | 大型任务 |

### 3. 角色设计
```
Planner(拆解任务)
  ├─> Worker A(检索)
  ├─> Worker B(分析)
  ├─> Worker C(生成)
  └─> Critic(评审验收) → 通过 / 返工
```

### 4. 通信机制
- 消息传递：结构化消息（from/to/type/content）
- 共享黑板：共同读写共享状态/内存
- 工具化调用：一个 Agent 通过调用另一个 Agent 的工具

### 5. 协调与仲裁
- 冲突解决：结果不一致时的仲裁规则
- 任务分配：避免重复执行
- 终止条件：何时算完成

### 6. 收益与代价
| 收益 | 代价 |
|---|---|
| 并行提效 | 通信开销与延迟 |
| 专业分工 | 协调复杂度高 |
| 相互校验 | Token 成本成倍上升 |

### 7. 常见问题
- 消息风暴 / 死锁
- 角色职责重叠
- 结果不一致无仲裁
- 上下文在 Agent 间传递失真

### 8. 实现要点
- 明确每个 Agent 的职责与输入输出
- 通信协议标准化、有超时
- 全局状态单一事实源
- 优先考虑"单 Agent + 工具"是否够用，多 Agent 是最后手段
