# 记忆机制

## 大纲

### 1. 概念与重要性
- 记忆让 Agent 在**多任务中保持状态、跨任务积累知识**
- 无记忆 = 每次对话"失忆"

### 2. 记忆分层
| 层级 | 生命周期 | 内容 |
|---|---|---|
| 感知记忆 | 单次请求 | 原始输入 |
| 工作记忆（短期） | 当前会话 | 对话历史、任务上下文 |
| 长期记忆 | 跨会话 | 情景记忆 + 实体记忆 + 语义知识 |

### 3. 长期记忆细分
- 情景记忆：交互轨迹、任务经历、对话摘要
- 实体记忆：抽取沉淀的稳定事实（用户、项目）
- 语义记忆：领域知识与规范

### 4. 存什么 / 不存什么
- 存：用户偏好、关键结论、外部知识
- 不存：中间推理、工具原始数据、闲聊

### 5. 怎么存（存储选型）
| 方式 | 适合 | 特点 |
|---|---|---|
| 向量数据库 | 非结构化文本 | 语义检索 |
| 关系型 / KV | 结构化字段 | 精确查询、快 |
| 混合存储 | 两者结合 | 主流方案 |

### 6. 何时取（检索策略）
- 主动检索：任务开始前注入 System Prompt
- 被动触发：封装成 Tool，推理中按需调用
- 可组合：开始注入背景 + 过程中按需检索

### 7. 记忆管理
- 去重与更新（新覆盖旧）
- 过期清理与归档
- 权限隔离（按用户/项目）
- 质量控制（只沉淀可信事实）

### 8. 常见问题
- 记忆污染：检索注入不可信内容
- 记忆冲突：过期信息与新事实矛盾
- 上下文超长：记忆摘要化

### 9. 实现要点
- 记忆写入有清洗与去重
- 记忆读取有相关性排序与阈值
- 记忆操作全部可观测
