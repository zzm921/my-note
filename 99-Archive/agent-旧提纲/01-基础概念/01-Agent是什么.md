# Agent 是什么

## 大纲

### 1. 定义
- AI Agent：拥有**目标感知、自主规划、迭代执行、记忆反思**能力，可主动完成复杂任务的自治 AI 实体
- 关键词：自治（Autonomous）、目标驱动（Goal-driven）、环境交互（Interactive）

### 2. 核心特征
- 目标导向：不是被动回答，而是主动拆解并达成目标
- 自主决策：自己判断下一步做什么
- 工具使用：调用外部 API / 函数完成任务
- 记忆反思：记住经验并在失败后调整策略

### 3. Agent 与 LLM 的边界
- LLM：单次"文本生成"引擎
- Agent：把 LLM 作为大脑，外接工具、记忆、循环，形成完整行动闭环

### 4. 判断标准
- 是否有目标设定与拆解
- 是否与环境/工具交互
- 是否具备多步循环执行
- 是否能从结果中学习调整

### 5. 典型形态
- 单 Agent（一个实体干完所有事）
- 多 Agent（角色分工协作）
- Agent 平台（Coze / Dify 等低代码编排）

### 6. 示例
- 任务："调研竞品并输出报告" → 拆解 → 搜索 → 整理 → 生成报告
