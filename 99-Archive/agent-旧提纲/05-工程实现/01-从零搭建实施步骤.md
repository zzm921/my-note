# 从零搭建 Agent 实施步骤

## 大纲

### 1. 总体思路
从"单轮对话"起步，逐步叠加能力，每步完成一次闭环验证。

### 2. 七个递进步骤
| 步骤 | 动作 | 目的 |
|---|---|---|
| 1 | 请求大模型，单轮对话 | 验证模型连通 |
| 2 | 增加工具（Function Calling） | 获得行动能力 |
| 3 | 增加 while 循环 | 多步执行闭环 |
| 4 | 增加权限（Permissions） | 行为可控、安全 |
| 5 | 增加 History | 上下文连贯 |
| 6 | 增加角色（System Prompt） | 行为规范 |
| 7 | 增加 Todo Write | 长任务管理 |

### 3. 伪代码骨架
```
messages = [system_role]
while not done:
    resp = llm.chat(messages, tools)
    if resp.tool_calls:
        for call in resp.tool_calls:
            check_permission(call)      # 步骤4
            result = execute(call)
            messages.append(result)
        update_todo(call)               # 步骤7
    else:
        done = True
return resp
```

### 4. 每步要点
- 工具：Schema 要准，错误信息要明确
- 循环：设最大轮次，防死循环
- 权限：高危操作白名单 + 人工确认
- History：按会话持久化，超长摘要
- 角色：System Prompt 约束行为与输出格式
- Todo：拆解、执行、更新、完成标记

### 5. 工程化扩展
- 可观测性：日志、耗时、token 统计
- 容错：重试、降级、兜底
- 配置化：工具/模型/权限可配置

### 6. 常见坑
- 一次堆叠太多能力，难排查
- 工具错误信息不清晰，模型反复失败
- 权限后补，导致返工
- 长任务无 Todo/记忆，"失忆"

### 7. 建议
- 每步独立验证再叠加
- 从简单工具开始，逐步丰富
- 先跑通闭环，再上生产级加固
