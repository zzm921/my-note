# 主流框架与平台对比

## 大纲

### 1. 分类
- 代码框架：LangChain / LangGraph / LlamaIndex
- 多 Agent 框架：AutoGen / CrewAI / MetaGPT
- 低代码平台：Coze / Dify / FastGPT

### 2. 框架速览
| 框架 | 定位 | 特点 |
|---|---|---|
| LangChain | 通用链式编排 | 生态大、组件全 |
| LangGraph | 图状状态机编排 | 适合复杂流程/多 Agent |
| LlamaIndex | 数据/RAG 中心 | 检索增强强 |
| AutoGen | 多 Agent 对话 | 角色间自由对话 |
| CrewAI | 角色化团队 | 任务驱动、易上手 |
| MetaGPT | SOP 软件团队 | 标准化流水线 |

### 3. 平台速览
| 平台 | 定位 | 特点 |
|---|---|---|
| Coze | 字节低代码 Agent | 国内生态、插件丰富 |
| Dify | 开源 LLM 应用平台 | RAG + Agent + 工作流 |
| FastGPT | 知识库问答 | 侧重知识库 |

### 4. 选择维度
- 任务复杂度：简单链式 → LangChain；复杂图状 → LangGraph
- 是否需要多 Agent：需要 → AutoGen / CrewAI
- 是否需要开发：要 → 框架；不要 → 平台
- 数据/RAG 为主 → LlamaIndex / Dify
- 部署环境：国内合规 → Coze / Dify

### 5. 框架核心概念
- Chain / Agent / Tool / Memory / Callback
- 状态管理（LangGraph State）
- 节点与边（Node / Edge）

### 6. 常见问题
- 框架抽象导致难以调试（上可观测性）
- 生态锁定（版本升级破坏）
- 平台数据外泄合规问题

### 7. 建议
- 小任务别上重型框架
- 优先选择可自托管、可观测的开源框架
- 框架只是工具，核心是 Agent 设计与数据质量
