## 归档规则

1. **归档 ≠ 删除**：归档只是移出主检索区，内容仍在，可随时回查
2. **归档必登记**：每次归档要在本文件或对应清单里说明「什么、从哪来、为什么」
3. **禁止双写**：内容一旦归档，主区不应再保留同名副本，全部引用改为指向归档路径或新合并稿
