### ⚠️ 重要教训：git mv 在中文路径下静默失败

**踩了坑**：第一版迁移脚本用 `git mv` + subprocess，结果 **118 个文件被 `git rm` 从 index 删除，但 `git mv` 失败没搬到新位置**——数据一度"丢失"。

**根因**：
1. `git mv` 在 Windows + Git Bash + 中文路径 + subprocess 编码组合下静默失败。
2. 我误把 `git status` 显示的 R（重命名）当成磁盘成功——**git 索引 ≠ 磁盘**。
3. Git Bash 的 `find` 对中文路径返回空，掩盖了问题。

**修复**：改用 Python `shutil.move`（Unicode 路径 API，不受 shell 编码影响），并加：
- 默认 dry-run，必须 `--apply` 才执行
- 目标存在则跳过（不覆盖）
- 用 Python `rglob` 统计磁盘（不用 find）

**恢复**：`git checkout -- .` 从 HEAD 恢复 + `git reset --hard 6a17c5d`。**还原点救了一命**——执行前打 git 还原点是硬性前提。

**已沉淀为技能**：`~/.workbuddy-ai/skills/windows-bulk-file-move/SKILL.md`
