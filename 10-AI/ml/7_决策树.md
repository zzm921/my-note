# 决策树

## 卡片：什么是决策树

**定义**：决策树是一种通过「一系列 if-then 规则」把数据一步步划分、最终输出预测结果的树形模型：每个内部节点是一个「问题」，每条边是一个「答案」，叶子节点给出「预测结果」。

**伪代码（预测过程）**：

```
预测(x)：
    当前节点 = 根节点
    循环直到到达叶子节点：
        读取节点规则（如：耳朵形状 == 尖？），把 x 送入对应子节点
    返回叶子节点存储的预测值
```

**符号表**：

| 符号 | 含义 |
|---|---|
| 根节点 | 树的第一个问题，含全部训练样本 |
| 内部节点 / 叶子节点 | 判定问题 / 停止分裂、存预测结果的节点 |
| 分支 | 某条规则的一个答案，指向下一层节点 |

**为什么（设计动机）**：人类做决定就是「先问最关键的问题，再逐步细化」。决策树把这一过程机械化：从根开始，每层问一个能把样本分得最开的问题，直到每个子群足够「纯」，学出来的模型天然就是一组可读规则。

**直觉**：决策树是一本「看图识物手册」——见到一只动物，先看耳朵、再看脸、再看胡须，逐条核对，翻到对应页面得到答案。

**实例（猫领养判断树）**：

```
                耳朵形状？
                /        \
          [尖耳朵]        [圆耳朵]
            脸型？          否（不领养）
          /        \
     [圆脸]        [方脸]
    是（领养）       胡须？
                  /        \
             [有胡须]      [无胡须]
            是（领养）     否（不领养）
```

手算预测：来了一只尖耳朵、圆脸、有胡须的猫 → 根问耳朵：尖 → 走左分支；问脸型：圆 → 走左分支 → 叶子输出「是（领养）」，全程仅 2 步，任何人可复核。

**特点与常见误区**：
- 可解释性强：整棵树可翻译成「如果…那么…」规则；分类、回归通用（分类树叶子输出多数类别，回归树输出均值）
- 对特征缩放不敏感：分裂只比较大小 / 取值，不依赖距离度量，无需归一化；但该结论仅对树成立，SVM、逻辑回归等基于距离的模型仍需归一化
- 决策树不是「随机乱问」，每层问题都按信息增益精心选出；单棵树不稳定，数据稍变结构就可能完全不同

## 卡片：熵与信息增益

**定义**：熵（Entropy）衡量一个节点内数据的「混乱程度」；信息增益（Information Gain）是「分裂前后熵的下降量」，决策树用它决定每个节点选哪个特征来分裂。

**公式**：

```
二分类（p₁ 为类别 1 占比，p₀ = 1 − p₁）：
    H = −p₁·log₂(p₁) − p₀·log₂(p₀)
一般形式（K 类）：H = −Σₖ pₖ·log₂(pₖ)
分裂后加权熵：H_split = Σⱼ (nⱼ / n) · Hⱼ
信息增益：IG = H(分裂前) − H_split
```

**符号表**：

| 符号 | 含义 |
|---|---|
| H | 节点熵，单位比特（bit） |
| pₖ / K | 第 k 类样本占比（Σₖpₖ = 1）/ 类别总数 |
| log₂ | 以 2 为底的对数；约定 0·log₂0 = 0 |
| n / nⱼ / Hⱼ | 节点样本总数 / 第 j 个分支样本数 / 第 j 个分支的熵 |
| IG | 信息增益，即分裂带来的熵下降量 |

**为什么（设计动机）**：目标是把数据「分得越纯越好」。熵在 p 接近 0 或 1 时很小（纯）、p = 0.5 时最大（最混乱），正好量化纯度。信息增益 = 分裂前熵 − 分裂后加权熵，差值越大说明该特征把数据整理得越干净。

**直觉**：熵 = 「猜中样本类别平均还要问几个问题」：全同类别不用问（0 比特），一半一半每次都要猜（1 比特）。信息增益 = 「问完这题后少猜了多少次」。

**实例 1：计算节点熵（手算，节点有 10 个样本：6 猫 4 狗）**

```
p₁ = 0.6，p₀ = 0.4
log₂(0.6) ≈ −0.737，log₂(0.4) ≈ −1.322
H = −0.6·(−0.737) − 0.4·(−1.322) ≈ 0.442 + 0.529 ≈ 0.971
```

对比：5 猫 5 狗 → H = −0.5·(−1) − 0.5·(−1) = 1（最混乱）；10 猫 0 狗 → H = 0（最纯）。

**实例 2：计算信息增益（手算）**

父节点 6 猫 4 狗，H ≈ 0.971。按「耳朵形状」分裂成 2 支，各 5 个样本，两分支熵分别为 0.3 和 0.8：

```
H_split = (5/10)·0.3 + (5/10)·0.8 = 0.15 + 0.40 = 0.55
IG = 0.971 − 0.55 ≈ 0.421
```

另一候选「脸型」分裂后加权熵 = 0.70：IG = 0.971 − 0.70 ≈ 0.271。

**选特征原则：IG 越大越好** → 0.421 > 0.271，选「耳朵形状」。

**常见误区 / 注意点**：
- log₂ 必须以 2 为底；换底后数值不同但特征间排序一致
- 熵与信息论中「平均信息量」严格对应，不是随便编的指标
- 分支太碎时增益虚高：C4.5 用增益率、CART 用基尼系数修正

## 卡片：停止分裂的条件

**定义**：停止分裂的条件是一组规则，任一满足时节点就不再分裂、直接变成叶子节点，防止树无限生长导致过拟合。

**为什么（设计动机）**：不设停止条件时，树会一直分裂到每个叶子只剩 1 个样本——训练集错误率为 0，但模型记住了噪声，对新数据几乎没有泛化能力，这就是典型过拟合。

**各停止条件及原因**：

| 条件 | 何时触发 | 为什么 |
|---|---|---|
| 熵为 0 | 样本全属同一类 | 已最纯，再分无收益 |
| 信息增益太小 | IG < 阈值（如 0.05） | 纯度提升微乎其微，不值得增加复杂度 |
| 样本太少 | 节点样本数 < 最小样本数（如 5） | 统计不可靠，分裂出的规则无意义 |
| 达到最大深度 | 深度 ≥ 最大深度（如 6） | 直接限制树的复杂度 |
| 特征用完 | 可用特征全被用过 | 没有特征可问 |

**数字阈值例子**：某节点熵 H = 0.80，按候选特征 A 分裂后加权熵 = 0.77：

```
IG = 0.80 − 0.77 = 0.03 < 0.05 → 收益太小，停止分裂
该节点直接成为叶子，预测值取多数类别（6 猫 4 狗 → 预测「猫」）
```

**常见误区 / 注意点**：
- 停止条件（预剪枝，边建边停）与剪枝（后剪枝，先建完再砍）是两回事
- 阈值不是越大越好：太大会欠拟合、太小会过拟合，需交叉验证调参
- 各条件「任一满足即停」，不是全部满足才停

## 卡片：连续特征与回归树

**定义**：连续特征（如体重 5.0~8.0 kg）不能按离散取值逐一分支，而是尝试多个「阈值」把样本分成「≤ t」与「> t」两组，选信息增益最大的阈值；回归树把分裂标准换成「方差降低」，叶子输出均值。

**阈值分裂伪代码**：

```
候选阈值取排序后相邻样本值的中间点：t ∈ {(x₁+x₂)/2, (x₂+x₃)/2, …}
    对每个候选 t：
        左子树 = {x | x ≤ t}，右子树 = {x | x > t}
        计算信息增益 IG(t)
选 IG 最大的 t 作为分裂点
```

**符号表**：

| 符号 | 含义 |
|---|---|
| t / xᵢ | 候选阈值（分裂点）/ 排序后的特征取值 |
| 左 / 右子树 | 特征值 ≤ t 与 > t 的两组样本 |
| Var(D) / ΔVar | 节点内标签方差（衡量数值离散程度）/ 方差降低量 |
| yᵢ / ȳ | 第 i 个样本的数值标签 / 节点内标签均值（叶子预测值） |

**实例：连续特征阈值选择（手算）**

5 个样本按体重排序：5.0、5.5、6.0、7.0、7.5，标签 [狗、狗、猫、猫、猫]（猫 = 1，狗 = 0）。父节点熵：p₁ = 0.6，H ≈ 0.971。

```
试阈值 5.75 = (5.5 + 6.0) / 2：
    左 = {5.0, 5.5} → 2 狗 0 猫，熵 0
    右 = {6.0, 7.0, 7.5} → 0 狗 3 猫，熵 0
    加权熵 = (2/5)·0 + (3/5)·0 = 0
    IG = 0.971 − 0 ≈ 0.971

试阈值 6.50 = (6.0 + 7.0) / 2：
    左 = {5.0, 5.5, 6.0} → 2 狗 1 猫
        H = −(1/3)·log₂(1/3) − (2/3)·log₂(2/3) ≈ 0.528 + 0.390 ≈ 0.918
    右 = {7.0, 7.5} → 0 狗 2 猫，熵 0
    加权熵 = (3/5)·0.918 + (2/5)·0 ≈ 0.551
    IG = 0.971 − 0.551 ≈ 0.420
```

结论：0.971 > 0.420 → 选阈值 5.75。

**回归树（预测数值）**：

```
节点方差：Var(D) = (1/n)·Σᵢ (yᵢ − ȳ)²
分裂后加权方差：Var_split = Σⱼ (nⱼ / n) · Var(Dⱼ)
方差降低：ΔVar = Var(D) − Var_split
分裂标准：选 ΔVar 最大的特征 / 阈值；叶子输出该叶子标签均值 ȳ
```

**回归树数字实例（手算）**：

节点内 5 个样本的目标值 y = [2, 4, 6, 8, 10]，均值 ȳ = 6。

```
父节点方差：Var = ((−4)² + (−2)² + 0² + 2² + 4²) / 5 = 40 / 5 = 8

候选 1「耳朵形状」：尖耳朵 y=[2,4,6]，圆耳朵 y=[8,10]
    左分支：均值 4，方差 = (4 + 0 + 4) / 3 ≈ 2.67；右分支：均值 9，方差 = (1 + 1) / 2 = 1
    加权方差 = (3/5)·2.67 + (2/5)·1 ≈ 2.00 → ΔVar = 8 − 2 = 6

候选 2「是否有胡须」：有胡须 y=[2,4,6,8]，无胡须 y=[10]
    左分支：均值 5，方差 = (9 + 1 + 1 + 9) / 4 = 5；右分支：均值 10，方差 = 0
    加权方差 = (4/5)·5 + (1/5)·0 = 4 → ΔVar = 8 − 4 = 4
```

结论：6 > 4 → 选「耳朵形状」；尖耳朵叶子预测 4，圆耳朵叶子预测 9。

**常见误区 / 注意点**：
- 阈值只取相邻值的中间点即可，不需遍历所有实数
- 回归树分裂标准是方差降低、叶子取均值，不是信息增益和多数类别
- 连续特征可在树中多次使用（用不同阈值），与离散特征「用完即止」不同

## 卡片：树集成

**定义**：树集成 = 训练多棵决策树并组合它们的预测，用「群体智慧」弥补单棵树的敏感与过拟合。

**为什么（设计动机）**：单棵树对训练数据的微小扰动极其敏感，方差高、易过拟合。多棵树各学各的、互相纠正，投票 / 平均后随机噪声被抵消，预测更稳更准。

**直觉**：一位专家可能看走眼，但 10 位背景各异的专家投票，错的个体互相抵消，对的方向被放大。

**随机森林（Random Forest）伪代码**：

```
for t = 1 … T：
    1. 有放回抽样（Bagging）：从 D 中随机抽 m 个样本组成 D_t（允许重复）
    2. 在 D_t 上建树：每个节点分裂时先随机挑 k 个特征（k < 总特征数），
       只在这 k 个里选增益最大的
    3. 树长到停止条件为止，不做剪枝
输出：分类 → T 棵树投票；回归 → T 棵树取平均
```

**XGBoost（梯度提升）伪代码**：

```
1. 初始化：f₀ = 常数（如标签均值）
2. for t = 1 … T：
    a. 计算每个样本的残差：rᵢ = yᵢ − f_{t−1}(xᵢ)
    b. 用一棵决策树拟合残差 rᵢ（逐棵补错）
    c. 更新：f_t = f_{t−1} + η·h_t
3. 输出：f_T = f₀ + η·(h₁ + h₂ + … + h_T)
```

**符号表**：

| 符号 | 含义 |
|---|---|
| m / T / k | 训练样本总数 / 树的数量 / 每节点随机挑出的候选特征数（如 √总特征数） |
| η / rᵢ | 学习率（如 0.3，控制每棵树贡献）/ 第 i 个样本的残差 |
| h_t | 第 t 棵树 |

**为什么树之间要有差异（文字实例）**：

假设 100 名评委评审一个项目：若 100 人都照抄同一位专家的意见，投票结果就等于那一位专家，毫无改善；只有当评委们各自从不同角度（不同资料、不同背景）给出意见，错误的个体才会互相抵消。随机森林的「有放回抽样 + 随机特征子集」正是刻意制造这种差异：每棵树看到的样本不同、可用特征不同，树之间「长得不一样」，集成才有效。若所有树都用全部特征、都选最强特征，得到的是一堆几乎相同的树——投票退化为单棵树。

**常见误区 / 注意点**：
- 单棵决策树快、可解释但易过拟合；随机森林并行独立训练更稳健；XGBoost 串行逐棵补错通常精度更高但更慢
- 随机森林树间是「抽样独立」，不是训练目标独立；XGBoost 是显式串行补错
- 提升树对异常值更敏感（残差被异常点带偏），随机森林更抗噪；集成后可解释性下降，需借助 SHAP 等工具辅助解释

## 卡片：易错点

| 要点 | 说明 | 后果 |
|---|---|---|
| 选特征靠直觉，不算信息增益 | 应逐个计算候选特征的熵下降量再比较 | 树结构差、预测不准 |
| 不设停止条件 / 不剪枝 | 树长到每个叶子只剩 1 个样本 | 训练集完美、测试集崩盘（过拟合） |
| 连续特征处理不当 | 按取值直接分支而非阈值分裂 | 分支爆炸、找不到合适分裂点 |
| 回归树误用信息增益 | 回归应看方差降低、叶子取均值 | 优化目标与预测目标不符 |
| 误以为决策树需要特征缩放 | 分裂只看阈值比较，不需要归一化 | 白白增加预处理步骤 |
| 认为树越多一定越好 | 树到一定数量后收益递减，关键是制造差异 | 训练成本高、收益趋平 |
| 用单棵树做关键决策 | 单棵树方差大，数据小扰动就改变结构 | 结论不稳定，应改用集成模型 |
