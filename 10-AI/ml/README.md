# 机器学习笔记（吴恩达课程）

> 本笔记整理自吴恩达（Andrew Ng）《机器学习》2022 新版课程（Machine Learning Specialization）。
> 风格为知识卡片式：每个概念按「定义 / 直觉 / 公式 / 伪代码 / 易错点」组织，公式与算法用伪代码表达，不使用具体编程语言实现。

## 学习地图

课程共三门，本笔记按主题拆分为独立文档：

### 课程 1：监督学习（回归与分类）

| 文档 | 对应周次 | 核心内容 |
|---|---|---|
| [机器学习导论](1_机器学习导论.md) | 第 1 周 | 什么是机器学习、监督/非监督学习、术语（训练集、特征、标签） |
| [线性回归模型](2_线性回归模型.md) | 第 1 周 | 单/多元线性回归、代价函数 |
| [梯度下降](3_梯度下降.md) | 第 1-2 周 | 梯度下降算法、学习率、特征缩放、多项式回归 |
| [分类与逻辑回归](4_分类与逻辑回归.md) | 第 3 周 | 逻辑回归、决策边界、过拟合与正则化 |

### 课程 2：高级学习算法

## 使用建议

- **按顺序学习**：先学课程 1 的三篇基础（线性回归 → 梯度下降 → 逻辑回归），再进入神经网络。
- **每个卡片问自己三个问题**：这个概念解决什么问题？公式每一项代表什么？伪代码如何一步步执行？
- **配合动手**：建议在学完每篇文档后，用实际数据集（如房价预测）把伪代码翻译成代码跑一遍。
