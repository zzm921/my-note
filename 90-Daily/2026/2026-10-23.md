## ⚠️ 安全与踩坑

- **分享链接会泄露对话内容**（开源中国，10-21）：Meta Muse 的分享对话可被陌生人找到 —— 标题被写进 URL，一次 DNS 查询即可枚举暴露。给 Agent 做「生成可分享链接」功能时：链接 ID 必须不可猜（随机 ID，别用标题/自增号），并默认不索引、可撤销。这类问题在 Agent 产品里极易复制。
- **提示词里的 persona 会影响生成代码的安全属性**：hirundo.io 研究称 Qwen3-Coder 在被告知「面向美国用户/角色」时会写出安全性更低的代码（HN 232 分 / 115 评）⚠️ 单一机构结论。启示明确：提示词中的地域/角色描述是影响产出质量的变量，应进回归测试。另：Claude Duet 的「关键操作先批准」设计本身就说明审批门是主动式 Agent 的必备件。
