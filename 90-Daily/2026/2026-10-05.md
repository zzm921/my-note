## 🧩 Agent 开发

**3. ollama v0.40.0（rc2）：Apple Silicon 默认走 MLX**
- 改动点：在 Apple Silicon 上，MLX 运行时支持的模型架构会自动跑 MLX，不再走旧推理后端。
- 今天就能做：升级到最新版，Mac 上的本地 Agent 推理延迟/吞吐应直接受益；升级后回归测试模型是否被正确路由到 MLX。

**4. 谷歌开源 AX：面向自主 AI 代理的 Kubernetes 风格编排器（InfoQ）**
- 把 Agent 编排当集群调度来做（声明式、可调度、可治理）。
- 对 Agent：多 Agent 编排 / 任务分发的抽象可直接参考；如果你在做「一群 Agent 协同」，这是本轮最值得读源码的项目。

**5. browser-use/jev-ultrafast（★21970）：主打「最快最省的 web agent」**
- 定位：浏览器自动化 Agent 的开源实现，强调速度与成本。
- 对 Agent：可直接替代 / 对比你现有的浏览器工具层，先跑通再按需改造。

**6. yetone/magpie（★4783）：把各家 Agent 模型统一到一个入口**
- 卖点：菜单栏一键切换，Codex 接 DeepSeek、Claude Code 接 Kimi——不同 CLI Agent 混用不同模型。
- 对 Agent：多模型路由 / 降本时，可参考它如何做「同一 Agent 后端换模型」。

**7. openJiuwen X-Router：自演进模型路由，实测省 50%+ Token（昇腾亲和）**
- 做法：自演进的模型路由，按任务把请求分给合适的模型，Agent 越跑越省。
- 对 Agent：路由层是最直接的降本手段；国产 / 昇腾环境下可优先评估。（⚠️ 来源日期 10-02，略超 48h。）

**8. Agent 工具链三连更新：DeepSeek Harness / Termexo / MateClaw**
- DeepSeek Harness v0.2 桌面版：核心理念「一切皆插件」，插件以 npm 包名安装，还能让 AI 自己写插件（IT之家专访崔添翼）。
- Termexo v0.10.9：终端内集中显示五种 Agent 状态，可确认完成——可观测性补强。
- MateClaw 2.3.0：用不可变 JSON 接管长任务验收，避免 Agent「自报完成」——长任务可靠性的一个具体思路。

**9. InfoQ（QCon 上海）：Agent 的记忆与基础设施**
- 《Agent 的记忆不在对话里》：把企业数仓沉淀为可治理的共享语义记忆——记忆工程从「聊天历史」转向「结构化语义层」。
- 《企业级 Agent Infra 架构实践》：从安全沙箱到网络管控与身份治理——生产化 Agent 的必备三件套。

## 📊 评测与基准

**11. arXiv 四篇与 Agent 直接相关的新工作**
- **AutoCompact**：学习「长程 coding agent 何时该压缩上下文」——上下文工程里最痛的问题，值得直接读。
