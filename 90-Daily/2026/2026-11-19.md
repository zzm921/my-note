## 🧩 Agent 开发

**4. Uber 的 MCP Gateway：800+ MCP Server、5000+ 工具的治理方案（InfoQ）**
控制面 Registry（工具定义/Schema/归属/启用状态）与执行面 Proxy 分离，Proxy 把 MCP 请求转 HTTP/gRPC/TChannel 再转回；AutoCrawler 扫内部 IDL（Protobuf/Thrift）自动生成 MCP Schema、工具描述由 LLM 代写，新工具默认禁用直到归属团队审核启用；授权分 server 与 tool 两级，支持响应侧 PII 脱敏与第三方 Token 交换。
「工具太多装不进上下文」的解法也给了：Omni MCP 做渐进式发现（搜 server → 找工具 → 按需取单个 Schema），Response Projection 让 agent 只取需要的字段。
对 Agent：工具上到几十个就该照这个分层抄——注册表 + 代理 + 默认禁用 + 按需加载 Schema，而不是把全量工具塞进 system prompt。
https://www.infoq.cn/article/FrDlAvNIwkr8ttdvWMCC

**5. openai-agents-python v0.25.0 / crewAI 1.15.42：会话适配与存储解耦**
openai-agents-python v0.25.0（11-17）：把第三方 session adapter 的公共工具函数对外暴露，自建会话存储（Redis/DB）不用再抄内部实现。crewAI 1.15.42：ChromaDB 降为可选 extra，Knowledge 默认走本地 Qdrant、存储与 ChromaDB 解耦；独立 agent 可以先选工具、之后再补。
对 Agent：crewAI 升级要留神——默认向量库变了，旧知识库需重新指回 ChromaDB 或迁移到 Qdrant；openai-agents 侧可把已有会话表直接接成 adapter。
https://github.com/openai/openai-agents-python/releases/tag/v0.25.0 ｜ https://github.com/crewAIInc/crewAI/releases/tag/1.15.42

claude-code v2.1.327：`/install-github-app` 改动仓库前先确认；新增 `claude mcp add-json <name> -` 从 stdin 读 server JSON，token 不再出现在命令行历史里。Dify 1.20.0：trace 可导出到任意 OpenTelemetry collector（兼容 Langfuse 旧 ingestion 端点退役），上传的知识库文件在入库索引前先做扫描。

## ⚠️ 安全与踩坑

**13. 两个今天该处理的依赖安全事件：agent-framework 被投毒、MCP servers v2.5.0 修 8 个漏洞**
Socket：微软 agent-framework 的 PyPI 包被劫持并植入凭据窃取器（11-18）。modelcontextprotocol/servers v2.5.0：修复三个 server 里的 8 个漏洞，`mcp-server-git` 升到 2026.11.18、`@modelcontextprotocol/server-filesystem` 升到 2.4.0、`server-everything` 升到 2.3.1。
对 Agent：MCP server 是跑在你机器上、拿着你凭据的进程——锁版本 + 哈希校验 + 最小权限（只给需要的目录/仓库），并审计近期装过的 agent-framework 版本、轮换可能暴露的 token。
https://socket.dev/blog/agent-framework-pypi-package-compromised-with-credential-stealer ｜ https://github.com/modelcontextprotocol/servers/releases/tag/v2.5.0
