## 🧩 Agent 开发

- **DeepSeek 开源 `dsh-superagent-prototype`（★16.3k，TypeScript，MIT；10-31 建仓、11-03 仍在推）**，配套技术文《Super-agent 设计探索：迈向更自主的 Agent 系统》。架构可抄：router 只做全局协调与派单、不深入执行；worker 各自独立上下文并行干活、可再调 subagent；worker 直接订阅话题，省掉经 router 转发的协调开销。
  另有四个工程件：事件驱动（群聊/邮件/GitHub 评论/CI 结果都是触发源）、存算分离（执行循环在云端、会话状态落库、本地只留轻量 daemon，电脑关机任务照跑）、外部 watchdog 检测无效循环、投机执行（不确定被采纳就先在后台试）。双级过滤也值得抄：先用规则筛掉明显无关消息，再让模型判断是吐槽还是真问题。作者自述：任务完成中位数 12.4 分钟、p95 15.7 分钟（合成负载 + 简化环境，非生产结论）。注意是研究原型，与内部系统不同。
  https://github.com/deepseek-ai/dsh-superagent-prototype
  https://www.tmtpost.com/8190971.html
- **Claude Code v2.1.317（11-03）**：两处直接关系 agent 治理——①`/schedule` 新建云端定时任务时，若被塞进你没申请的 connectors 会明确警告并给出移除方法；②web/shell 工具调用若要把账号邮箱发到网络，先弹确认。
  对 Agent：这就是「连接器显式授权 + 出网敏感字段拦截」的可抄实现，搬到自己的工具层：工具返回前扫一遍待出网 payload，命中身份标识就转人工确认。
  https://github.com/anthropics/claude-code/releases/tag/v2.1.317
- **Anthropic 工程经理、Claude Cowork 负责人 Felix Rieseberg 访谈（InfoQ 11-03）**：两个能立刻用的做法——①Skill 会过时，为上一代模型写的 skill「删掉效果反而更好」，要定期做删减对照；②对抗式审查：一个模型干活、几个模型专门挑错（挑错可用更弱的模型），再由一个模型裁决哪些批评成立。
  对 Agent：skill 库不是越多越好，常驻上下文的冗余 skill 会稀释选择准确率；多 agent 评审用「生成—挑错—裁决」三段式，比让单个模型自查可靠。
  https://www.infoq.cn/article/xaWSKT3MlZjbuJw16Vem
- **ollama v0.40.14（11-03）**：`ollama launch claude` 现在会把模型的 output token 上限透传给 Claude Code，云端模型不再撞 128k 默认上限；`/api/chat` 的云端 web search 响应解码也修了。
  对 Agent：拿 ollama 当本地统一网关、后端接云模型的，先升这版，否则长输出会被默认上限静默截断。
  https://github.com/ollama/ollama/releases/tag/v0.40.14
- **Anthropic 团队零 Rust 经验靠 Claude 完成核心 API 跨语言重构：CPU 省 40%、延迟降 20%（InfoQ 11-03）**。
  对 Agent：「agent 参与大重构」的边界样本——先由人锁接口契约与等价性测试，再让 agent 批量翻译并逐模块对拍，收益才能量化；顺序反了就是一次性大爆炸。
  https://www.infoq.cn/article/IMWM7ZXDi99sMiUVZBIF

## 📊 评测与基准

- **arXiv `WebHarbor`（2611.03618）**：把真实网站「停靠」成可演进的 GUI agent 环境——站点改版后环境跟着演进，而不是录播/静态快照。
  对 Agent：browser/GUI agent 最难的是环境漂移，这类可演进环境比一次性 benchmark 更接近线上，适合当回归床。
  https://arxiv.org/abs/2611.03618
- **arXiv `VeriHarm-Bench`（2611.03551）**：可验证地度量 coding agent 的「有害成功」——任务确实完成了，但执行路径造成危害。
  对 Agent：评测别只看 pass rate，加一条「成功但越界」判定（改了不该改的文件、跑了破坏性命令、越权读凭据）；这类失败在日志里最容易被当成成功。
  https://arxiv.org/abs/2611.03551
