## 🧩 Agent 开发

3. **腾讯混元 Terminal-RSI：不改模型规模，让终端 Agent「跨出自己原本的框架」** — 钛媒体 10-19（论文口径，已 curl 核实细节）：以 Qwen3.8-27B 为基座做两段递归自改进训练终端 agent。RSR（Recursive Self-Rewrite）：把通过完整验证的成功轨迹提炼成操作手册（runbook），由独立审查 agent 检查格式与「是否泄漏验证器答案」，再在全新沙盒里重做一遍，仍通过才留用，SFT 时抹掉手册只保留动作序列；RPR（Recursive Policy-Refine）：actor 换了打法后先让 critic 单独重练 4 轮再上 PPO。结果 Terminal-Bench 2.1 从 51.7% → 86.5%，Terminal-Bench 4.0 从 0% → 19.84%，四项平均 20.7% → 50.6%。⚠️ 论文自认只在 27B 上验证过、仅三次评测、无独立训练种子。
   对 Agent：三个可以直接搬的做法——① 用「成功轨迹 → 手册 → 重做验证」筛训练/示例数据，天然滤掉偶发成功；② 策略一变先预热 critic 再 RL，别直接重置；③ 设独立审查环节防验证器答案泄漏进数据。
   https://www.tmtpost.com/8173087.html
4. **谷歌开源 Harness²（Apache 2.0）：不动模型权重、只改 harness 的递归式能力提升** — InfoQ 10-19，代码在 github.com/google-research/harness2。8 类可改组件（系统提示词、护栏、记忆、工具指导、子智能体、Skills、脚本、插件）；两层递归——任务内「提出—探测—组合」（不要求任务有标准答案，靠执行证据决定保留哪套 Harness），任务间维护一个持续存在的 Improvement Harness 沉淀经验。默认 OpenCode、可切 Codex；实测一步优化即可让 WorkBuddy-Bench 最高 +11.5 分、JobBench +4.5 分、LAB 最高 +11.8pp（基座 GLM-5 / Gemini 3.5 Flash）。代价是用测试时算力换成功率。
   对 Agent：今天就能 clone 下来当「可插拔 harness」的参考实现，把记忆、子智能体、工具指导拆成独立可调组件。⚠️ 官方提醒：executor 默认不限网络、Codex executor 会关闭 sandbox，跑公开 benchmark 要自己限网，否则评分细则可能被联网捞到；且它是研究原型，非谷歌官方产品。
   https://www.infoq.cn/article/AD1M3mJ2SH1dJrTA1r5q ｜ https://github.com/google-research/harness2
