## 🧩 Agent 开发

**4. 谷歌开源 AX：面向自主 Agent 的「Kubernetes 风格」编排器**（InfoQ 09-30 20:40，已核实原文）
- 关键点：Apache 2.0，代码在 `google/ax`（站点 agentexecutor.io）；基于 Agent Substrate 运行时，把 Agent 当**有状态 Actor** 而非微服务 / 批处理；**亚秒级 checkpoint 挂起与无冷启动恢复**；四类声明式原语 **Task / Workspace / Gateway / Model**；同一宿主进程上复用数十个隔离 Actor 沙箱。
- 对 Agent：这正对「长周期、间歇性计算」的 Agent（等工具、等审批、等外部事件的空转）——以前这段空转只能靠常驻进程烧内存。若你现在自己写调度 + 容器池，先读它的 Workspace/Actor 模型再决定要不要换。
- 今天就能做：clone `google/ax`，先用 Task + Model 两个原语跑通一条多步工具链，重点量挂起/恢复延迟与单机可承载 Actor 数。

**5. Codex Harness 开源**（雷锋网 09-30 16:24）——OpenAI 侧的 harness 层开源，该文借它讨论「AI 公司的护城河是什么」。
- 对 Agent：harness（循环结构 + 工具描述 + 上下文剪裁）是同一模型上差异最大的一层；此前 Strands 的 harness 官方称省 28% token，同属一条线，现在多了一份可对照的实现可读。

**6. DeepSeek Harness v0.2 桌面版**（开源中国 09-30 13:59）：插件改为按 **npm 包名**安装，并支持「让 AI 自己写插件」。

**7. 长任务的「验收」工具链**（开源中国 09-30）：MateClaw 2.3.0 用**不可变 JSON** 接管长任务验收，官方定位「告别自报完成」（14:08）；Termexo v0.10.9 在终端集中显示**五种 Agent 状态**并支持原地确认完成（13:20）。
- 对 Agent：这是「失败是否被如实上报」那类基准的生产化对应物——把「完成」从模型自然语言自述，变成外部可校验的结构化产物 + 人工确认点。做长任务 Agent 时优先补这块，比继续调 prompt 收益高。

**8. 多智能体与网关侧**：InfoQ 报道 **openJiuwen workSwarm** 全双工多模态（像聊天一样与 Agent 交互，昇腾算力原生亲和，09-30 11:52）；雷锋网给出 **OpenClaw 2.0** 实测，主题是「Agent 网关能否重塑工作流边界」（09-30 16:22）。

## ⚠️ 安全与踩坑

**14. 三条安全面**
- **Agent 留痕泄露**（IT之家 09-30 15:11，Glow Security）：AI 智能体无意间把企业敏感信息带出，超 **1.3 万张截图**出现在公开 GitHub 仓库——Agent 的截图 / 浏览器轨迹默认落盘时必须做脱敏、加密与访问控制，「功能默认开启」是最常见的事故源。
- **开源权重能力外溢**（Anthropic 09-29 研究报告，HN 240 分，已核实原文）：该文分析 GLM-5.3 的防护可被简单手法绕过（文中给出 64%–100% 的区间），并引用 NIST CAISI 09-17 的评估称其为「迄今网络能力最强的开源权重模型」、整体落后美国前沿约 4 个月。结论对做 Agent 的人很直接：**开源权重的防护边界要当作选型的非功能指标**，防御方也应假定对手手上有同等模型。
- ⚠️ **监管传闻**：IT之家 09-30 表示美国 FTC 加大了对 Anthropic、OpenAI 及其他 AI 实验室的调查力度（原文用「曝」，未见官方确认）。
