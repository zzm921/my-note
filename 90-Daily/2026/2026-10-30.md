## ⚠️ 安全与踩坑

- **Claude Code 会把每个后台 agent 的完整 transcript 发给模型**（HN 534 分/216 评，10-29）：另一条帖补充「它把你的邮箱写进 prompt，模型又把这段带到访问的网站上」。对 Agent：后台/并行 agent 的上下文里往往混着仓库路径、内部域名、身份信息，这些都会进推理请求并可能被模型带进网页表单或工具调用。**今晚就能做**：审一遍 agent 的 prompt 组装（哪些字段是自动注入的）、给外发工具加域名白名单、把敏感字段在进入上下文前脱敏。
  https://gist.github.com/flamerix-ai/c3905705cc4205e5de3011fa2e74efce ｜ https://news.ycombinator.com/item?id=50286306
- **「100% 免疫提示词注入」是厂商结论，不是你的护栏**（量子位 10-29）：Carbon 在自家安全基准上宣称可免疫提示词注入，但那是干净评测环境、满血权重下的结果。对 Agent：只要你的 agent 会读网页/邮件/工单，注入面就在数据里而不在模型里——工具白名单、参数校验、危险操作二次确认、出站域名限制，一样都不能省。
  https://www.qbitai.com/2026/10/506227.html

## 🔥 值得深看

- **MCP servers v2.2.0 的 CA 事件**：CA 私钥可恢复意味着「证书有效」不再可信，今晚 `pip/npm ls` 一遍你的 MCP server 与基础镜像版本，是最低成本的一次风险出清。
- **Carbon 的 token 效率数据（12.3 万 vs 17.3 万输出）**：真正决定 agent 账单的是「每次任务吐多少 token」+「缓存命中率」，先把前缀稳定化和工具 schema 顺序固定下来，换不换模型都有收益。
- **answer-me-with-html**：一个几百行就能抄的 skill 形态——让 agent 交付可读 artifact 而不是长文，评审和排障都省一半时间。
