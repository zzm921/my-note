## 🧩 Agent 开发

- **谷歌开源可插拔 Agent 框架 Harness²（harness2）**，Apache 2.0，GitHub: google-research/harness2。把 harness 拆成 8 类可改组件——系统提示词、护栏、记忆、工具指导、子智能体、Skills、脚本、插件；支持 OpenCode（默认）与 Codex 双后端。核心是两层递归：任务内「提出—探测—组合」多套 harness 实测取优，任务间用一个持续存在的 Improvement Harness 保留有执行证据的经验。不动模型权重，一步优化即让 WorkBuddy-Bench 最高 +11.5 分、JobBench +4.5 分、LAB 通过率 +11.8pp，代价是更多测试时算力。⚠️ 官方声明为研究原型（非官方支持产品），executor 默认不限网络、Codex executor 关闭 sandbox，正式评测需自行限制网络。
  https://github.com/google-research/harness2 · https://www.infoq.cn/article/AD1M3mJ2SH1dJrTA1r5q
- **版本更新三则**：① Claude Code v2.1.304——插件跳过 mod 钩子时新增 transcript 提示，mod 的 tool.check 新增 `decider: "person"`（把决策交回权限弹窗/宿主），写 CC 插件与做权限门控直接相关；② OpenHands v1.28.1——agent-server 升到 1.56.0，维护性更新；③ anthropic-sdk-python v1.16.0——User Profiles 转 GA、Admin API 支持 workspace 级限流调整、analytics report 增加分页字段，做多租户 Agent 平台可直接用。
  https://github.com/anthropics/claude-code/releases/tag/v2.1.304 · https://github.com/OpenHands/OpenHands/releases/tag/v1.28.1 · https://github.com/anthropics/anthropic-sdk-python/releases/tag/v1.16.0
- **可直接复用的新开源项目**：① `answer-me-with-html` ★4096——一个 Agent Skill，让 Agent 用一页 HTML 回答复杂问题，输出层可读性的现成解法；② `git-ai` ★2536——为 AI Agent 设计的 Git 工作流；③ `AIHOT` ★8170——自己找热点、自己写日报的站点框架，换掉信源与精选标准即可成为自己的行业热点站（可直接复刻进现有日报流水线）。
