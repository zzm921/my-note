## 🤖 大模型

**1. 谷歌发布首个「决策专用」模型 Gemini Decision 1 + Decisions API**（AI Studio 已上线，Decision 1 暂免费）
不生成文本，单次前向传播对封闭选项集打分：支持是/否判断、多选（≤255 项）、按评分标准打分；一次可评最多 1000 个问题，输入覆盖文本/图像/音频/视频/PDF。9 项测试拿下 7 项第一，最高准确率 92.2%。定价 $0.10/百万输入 token、输出不计费（约 Flash-Lite 的 1/5）。
→ 对 Agent：把「工具选择 / 分支判断 / 候选重排」从生成式调用里拆出去，router 不再吐一段 JSON 让你解析。今天可在 AI Studio 对现有 router 做一次 A/B。
https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/ ｜ https://www.infoq.cn/article/E7QKIMUz3h0G0IE5Paii

**2. Gemini 4 Carbon 全面开放**

https://www.infoq.cn/article/YiANe38yfSYitvZOtab0

**3. 百度文心 5.5 Flash 开源 + 讯飞 SparkAudio 1.0 上 API**

https://www.ithome.com/1/026/386.htm

**4. MiniMax 开源 SOTA 生图模型 MiniMax-H3-Image（原生 4K）**
量子位称「一张两毛」，HF 镜像下载量已 14 万+；同榜 Kimi K3.1 Pro 上线，主打编程与智能体任务。对 Agent：海报/示意图/UI 草图这类产出节点可以走自托管，省掉第三方图像 API。

## 🧩 Agent 开发

**5. crewAI 1.15.40：状态可按 row id 精确回查**
改动点：embedding 层移除 chromadb 依赖；新增按 row id 的历史状态精确查询；RAG 数据类型发现接入 jsonl；独立 agent 默认以 JSON 脚手架生成。升级 `pip install -U crewai==1.15.40`。
→ 长跑任务做检查点/回放、定位「第 N 步为什么走岔」有了原生手段，不用自己存快照。

## 💰 成本与基础设施

**12. ReTrace：把工具型 Agent 蒸馏成「无 planner」工作流**

https://arxiv.org/abs/2611.14487

## 🔥 值得深看

1. **Gemini Decisions API** —— 今天就能在 AI Studio 免费试。它把「决策」从生成里剥离，router/tool-choice 的成本结构可能整个变；建议先拿一个高频二选一场景对比延迟与准确率。
