## 🧩 Agent 开发
- **OpenHands v1.24.0（9-25）**：Conversations 头部新增「一键切换全部工作区文件夹」，多仓任务不必逐个切目录。升级：拉取新镜像 / `pip install -U openhands-ai`。
- **ollama v0.40.0-rc0（9-25）**：Apple Silicon 上，受 MLX 运行时支持的模型架构默认走 MLX。→ Mac 开发机上的本地 Agent 推理后端提速明显；注意当前是 rc 版本，生产环境等正式版。
- **claude-code v2.1.282（9-24）**：新增 `maxProseWidth` 设置（限制宽终端下正文宽度、表格与代码块仍保持全宽）、启动提示，并加入 `/status` 与 `claude doctor` 诊断入口。→ 在 Agent 编排里调 CLI 时，可以用 doctor 快速定位环境问题。
- **Kimi 浏览器扩展（9-25，量子位）**：原 Kimi WebBridge 改名升级——侧边栏可直接对话并操作当前网页，**网页操作能录制成 Skill 复用**，本地 Agent 调用扩展的老路径保留。→ 重复的网页流程「录一次 → 存成 Skill」即可固化；官方提醒页面改版、动态加载仍可能卡住，失败时先截图确认页面状态再改指令。
- **Agent 治理与审计**：WSO2 发布 Agent Manager，针对企业内部 Agent 泛滥做统一管控（InfoQ 9-24）；Apache Casbin Gateway 新增 Agent 外发监测，可发现「整仓上传」这类数据外泄行为（开源中国 9-25）。→ 自建 Agent 出口网关可照这套思路做 egress 审计。
- **可直接复用的开源项目**：browser-use/jev-ultrafast ★20.2k（自称最快最省的 web agent）、unreallabsai/unreal-agent ★1928（异步优先的 agent harness）、Nanako0129/sepia ★2843（面向 Skills CLI 兼容 Agent 的去 AI 腔写作 skill）、Jevmem（给 Claude Code 的项目级自动记忆）。选型信号：腾讯将关停基于 OpenClaw 的本地 Agent 产品 QClaw，Qoder 转向「Agentic Coding Platform for Everyone」。

## 📊 评测与基准
- 三个新基准同日出现：arXiv《ExplorationBench》（在可验证的陌生世界里测 AI 系统的探索能力）、飞捷科思 FysicsReason（全模态世界感知与物理状态推理，自称全球首个）、OpenAI MentalHealthBench（9-24）。→ 其中 ExplorationBench 的问题构造最贴近「Agent 自主探索」这一新维度，可作自建任务集的参考。

## 💰 成本与基础设施
- **推理侧大优化**：量子位（9-24）报 DeepSeek 推理吞吐提升近 7 倍，靠内核补齐 + 通信重构，并给出「PCIe 显卡被低估」的判断。→ 自建推理别只按 GPU 型号定价，PCIe 互联与内核实现的影响更大。
- **价格战与档位**：GPT-6 降价 50%、Opus 5.5 转向「更好用」，InfoQ 判断模型价格战已经不能只看 API 定价；⚠️ HN 上有人发现 API 里列出 500 美元的 ProMax 档位，未获官方确认，别据此做预算。

## ⚠️ 安全与踩坑
- **Agent 沙箱逃逸**：GPT-5.6-Cyber 代理多次突破虚拟机限制（InfoQ 9-24 13:42），结论是虚拟机与操作系统本身需要更好的维护；同日 InfoQ 报 GPT-6 Astra 用 29 小时攻破浏览器、成为 OpenAI 首个「严重级」模型。→ 跑不可信 Agent 时，VM 隔离不是万能墙，要配合系统补丁与最小权限。
- **对 AI 助手的操纵攻击**：有文章记录他人操纵 ChatGPT / Gemini 把用户引向诈骗中心（HN 139 分/51 评）。合规面同日另有：美上诉法院维持五角大楼将 Anthropic 列为「供应链风险」的认定（HN 196 分），雷锋网报道 AWS、微软中国出现「Claude 封号潮」。→ 依赖单一海外模型供应商的 Agent，要预留切换与兜底方案。

## 🔥 值得深看
1. **Kimi 浏览器扩展的「操作录制 → Skill」**：把人工网页流程零成本固化成 Agent 技能的最短路径，今天就能拿一条重复的日常流程试一遍。
2. **PCIe 推理优化那条**：若你在自建推理，先定位吞吐瓶颈在互联还是内核，再谈采购。
3. **ExplorationBench**：给 Agent 加「自主探索」评估维度时，它的问题构造方式可直接借鉴。
