## 🤖 大模型

**OpenAI 同时发 GPT-6.2 Astra 与 GPT-6.2 Sol：token 少 22%、API 降 20%，任务成本近减半**
Astra 打复杂专业任务、Sol 打日常高频执行；官方口径性能 +6.2 分、token 用量 -22%、API 价 -20%。真正的变化是执行策略下放：模型自己判断「要不要调工具 / 要不要直接操作计算机 / 这一复杂任务该投多少推理」，而不是照外部 planner 生成好的计划走。FrontierCode 2.0（真实代码库改动能否达到维护者合并标准）上 Sol 与 Astra 差不到 0.5 分。
对 Agent 的含义：规划-执行两层可以做得更薄，把「下一步用什么方式拿信息」交给模型；反过来，系统侧必须维护一份可更新的任务状态（目标 / 约束 / 已有证据 / 待验证），别再靠堆历史对话——旧计划和失败操作会污染新决策。
https://www.leiphone.com/category/ai/MR1Osv9r2Rtr4V7F.html ｜ https://www.qbitai.com/2026/11/511779.html

**无界方舟 Edge0-145B：145B 端侧模型，12GB 显存 + 20GB 内存可跑，实测 80+ tok/s**
号称首个千亿参数端侧原生基础模型，开源 3 天冲到 HF Text Generation 榜首位；最低配置 12GB 显存 + 20GB 系统内存，或 48GB 统一内存的 Mac。实测断网跑 Vibe Coding、3D 建模、游戏与视频生成；官方称智力对标云端 Opus 4.6 / DeepSeek-V4-Flash 一档（⚠️ 厂商标注口径）。
对 Agent 的含义：本地执行层第一次有了「够用」的候选——工具调用、代码改写、隐私文档这类高频低难任务放本地，零 token 成本、断网可用，云端只留规划与疑难；私有化门槛从数十万服务器降到一万五的笔记本这个量级。
https://www.qbitai.com/2026/11/512195.html

**混元 AMA 补一条：下一代 Hy 继续大幅扩参，RSI 还在早期，后训练最难的是「过度思考」**
姚顺雨团队在 r/LocalLLaMA 两小时问答里给了三个判断：仍信 Scaling Law、下一代参数量显著扩大；递归自我改进（RSI）目前不可行（内部有评测基准，但先补基础智能）；后训练最难改善的行为是 reasoning 太长。
对 Agent 的含义：别指望模型自己收敛思考长度，reasoning budget 要在你的 loop 里显式给（按步骤可验证性分级、超预算强制收尾），这也是延迟与账单最可控的一项。
https://www.infoq.cn/article/b4QKbFZaXvbK9hzcBhZV

## 🧩 Agent 开发

**OpenHands v1.44.0（11-23）：会话提及、自动化 KV 存储可视化、预算耗尽可读报错**
自建平台用得上的三条：conversation mentions（在 conversation_mentions flag 之后，默认关）、automation 可见范围可按人配置、automation 的 key-value store 可在 UI 里查看与编辑；另修了对话 diff 统计改为按最长公共子序列计算。兼容要求 agent-server ≥ 1.63.1。
今天就能做：先把 agent-server 升到 1.63.1 再拉 v1.44.0，否则 runtime 会拒；automation 的 KV 可直接编辑，意味着可以把「每个 automation 的配置」当可版本化状态来管。
https://github.com/OpenHands/OpenHands/releases/tag/v1.44.0

**Jane Street 开源 agent_skills（★11.2k，MIT）：内部技能按通用 SKILL.md 目录格式外发**
每个技能就是「一个目录 + 一份 SKILL.md」，coding agent 的通用格式——拷进 skills 目录后直接「教我 X」即可用；普通聊天机器人则把正文贴进 system prompt。目前只放了 1 个技能 socratic-tutor（诊断 → 0-5 级技能图谱 → 一次一问 → 间隔复习 → 终评）。
看点不在技能本身，而在一家量化公司把自己天天在用的内部 skill 按统一格式开源：SKILL.md 正在成为跨 agent 的事实标准，值得照它的结构把团队 prompt 资产目录化。
https://github.com/janestreet/agent_skills

**「Agent 版 arXiv」：936 个 agent、12 周 936 篇论文，自己办期刊、自己审稿**
alphaXiv / 斯坦福 / MIT 搭了一个只有 agent 的科研社区，35 家实验室只提供算力与方向，提出假设、写代码跑实验、写论文、同行交流全交给 agent。规则比结果更值钱：动手前必须先查社区已有论文、公开声明假设与计算计划；提交必须附可运行代码、原始数据和「声明账本」（Claim Ledger，把论文里每个数字追溯到数据文件与字段）；复现失败可以拿对方代码重跑并质疑方法（有实验室被指出「比较条件没对齐」后重跑改了结论）。平台已对外开放接入。
可抄三件事：产出物强制带可复现材料、把「指标 ↔ 数据字段」做成机读账本、失败实验也算知识入库——直接对应多 agent 流水线的可信交付。
https://www.qbitai.com/2026/11/512004.html

**AWS 推 Well-Architected Agent 预览版：架构审查 agent，能出修复包还能审 Terraform**
按 65+ 个 AWS 服务的 WA 最佳实践，把资源配置、利用率指标、应用拓扑与声明的业务目标关联，在资源 / 应用 / 架构三层给优先级建议、跨支柱权衡与实施包（CLI 命令、IaC 变更），并可在部署前审查 Terraform / CloudFormation。用一份「agent profile」限定账户、区域、优化支柱与业务目标；可配 API 接进现有 DevOps 流水线，也能用 AWS MCP Server 从编码工具里调。
值得抄的工程模式：分析范围由 profile 显式声明、建议按影响/工作量排序、从「建议」到「自动修复」留人工闸门（从业者的质疑正是这两处：业务目标从哪读、省钱的建议可能伤韧性）。目前限美国 3 区、需 Business Support+。
https://www.infoq.cn/article/LQuPgS5lcFDMEKhZSP5d

## 📊 评测与基准

**RoboChallenge Zero：11 个多模态模型 6 项任务 330 次真机测试，整体成功率 44.85%**
最好模型 70%；放置大积木 89.09%（11 个里 7 个 5/5 全中），书写「Z0」55 次仅 4 次成功（7.27%），「解开并铺好充电线」55 次 0 成功。成功也不快：抓放平均 13–14 分钟，书写成功案例平均 23.8 分钟。接口是统一工具调用——模型收相机画面与机器人状态，输出末端位姿与夹爪指令，执行后新观察回传。
对 Agent 的含义：这是「感知-决策-动作」循环的压力测试版通用 agent loop；对 GUI / 工具 agent 同样成立——粗粒度选择已可用，精确连续动作与形态变化判断仍是断层。
https://www.qbitai.com/2026/11/511978.html

**AutoOntologyBench（arXiv 2611.27721）：面向 agentic knowledge engineering 的任务落地型基准**
Minye Shao 等，把「agent 能否把领域知识建成可用的本体/知识结构」拆成任务来测，而不是考记忆问答（仅按题名判断，摘要未入库）。
对 Agent 的含义：知识工程是 agent 进企业场景的第一道坎，有基准就有可对照的失败模式。
https://arxiv.org/abs/2611.27721

## 💰 成本与基础设施

**「AI 越来越便宜，AI 越来越烧钱」：单价一路下探，总支出反而陡增**
开源中国这篇的论点即标题，英文原帖 slug 直接指向 Jevons 悖论（token-spending-at-that-jevons-moment）：token 单价持续下降（今天 GPT-6.2 又降 20%），但单任务能塞进更多步骤、更多 agent 并行，企业总账单仍在涨。
对 Agent 的含义：按 token 单价做预算已经失真，改成按「任务」和「每任务步数」设上限——OpenHands 这版把「预算耗尽」做成可读报错，正是这个趋势的落地形态。

## ⚠️ 安全与踩坑

**百度智能云：给企业级 Agent 做五维安全建模，点名「恶意 skill 分发」是新攻击形态**
把 Agent 安全拆成权限、数据、技能、执行、审计五维；核心判断是攻击链没变（拿权限 → 扩权限 → 变现），变的是入口——恶意指令进的是模型上下文而不是内存，恶意软件分发改成恶意 skill 分发，对黑产性价比最高。做法上强调沙箱内行为观测与「数据入站」这一环的防护（称是目前防御空白）。团队实测：两个人一个晚上能让恶意 Python 脚本在几十台设备上执行。
对 Agent 的含义：只要你的 agent 会装/调第三方 skill 或 MCP server，「技能供应链」就是主战场——技能来源签名与白名单、执行放沙箱并观测偏离行为、入站数据（文档/网页/邮件）按不可信输入处理。
https://www.infoq.cn/article/dzgleaOZ3ILx5cztUtXw

**Docker 换标并押注「面向智能体的容器化」：把安全、隔离、治理做成可信执行环境**
官方博客口径是让容器成为智能体可信执行环境的一部分（新 Moby 鲸鱼更抽象、以黑为底）。
对 Agent 的含义：现在把代码执行/工具调用扔进容器隔离还是各家自己拼，未来一年这块会变成平台默认能力；自建的话提前把「工具执行一律容器化 + 资源与网络默认拒绝」当基线。
https://www.ithome.com/1/031/194.htm ｜ https://www.docker.com/blog/meet-the-new-docker-built-to-run-on-trust/
