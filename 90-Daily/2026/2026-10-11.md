## 🧩 Agent 开发

**Claude 动态多 Agent 工作流开始公测**｜官方支持庞大工作负载。对 Agent：多智能体编排从「自己搭」走向托管形态，可对照它的事件/状态模型设计自己的编排层。
→ https://www.oschina.net/news/502951

**claude-code v2.1.296：企业策略下沉**｜网关 `managed.policies[]` 新增 `code` 键——把与 `cli` 相同的策略同时应用到 Claude Desktop 的 Code 标签页；和 `desktop` 键并存时开启 Desktop 网关模式。对 Agent：做集中式策略/网关管控的今天升级并回归。
→ https://github.com/anthropics/claude-code/releases/tag/v2.1.296

**openai-python v3.28.0：托管 agent 生命周期**｜API 新增 agent environment 的挂起（suspension）与过期（expiration）。对 Agent：托管环境下终于有正式的暂停/回收接口，适合长跑任务的资源治理。
→ https://github.com/openai/openai-python/releases/tag/v3.28.0

**crewAI 1.15.27**｜新增 deepinfra 作为 OpenAI 兼容 provider、OpenCLIP 增加 XPU 设备选项，并「记录一次评估为何在得出结论前停止」。对 Agent：自托管/多 provider 切换更省事，评估可观测性增强。
→ https://github.com/crewAIInc/crewAI/releases/tag/1.15.27

**laya ★32130（GitHub）/ convaiinnovations/laya（HF ♥5451）**｜非自回归「System 1」决策引擎：单次前向完成 typed choice / 打分 / yes-no 判断，支持 100+ 语言，自带路由器（router）。对 Agent：决策/路由层可换成这种小模型自部署，延迟与成本都低一档。
→ https://github.com/NandhaKishorM/laya

**开源速览**｜AIHOT ★7063：一个「自己找热点、自己写日报」的网站框架，换信源与精选标准即变行业热点站（对你自己的日报管线可参考）；Talorys ★161（HN）：跑在 Cloudflare 免费额度上的自托管个人 Agent；REA ★5 万：把逆向工程变成 agent 的一项本地能力。
