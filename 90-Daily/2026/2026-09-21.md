- **「System One」低延迟决策模型成一条独立技术线**：前 OpenAI 研究员发布 **Jev**（面向软件的快速、结构化决策，09-20）；GitHub `browser-use/jev-ultrafast` **★11281**（09-16 建仓，简介只有一句 "i. am. speed."）是浏览器侧的超快实现；APUS 开源国内首批 Jev 跨平台复现，主打「秒级决策」（量子位 09-20）。对 Agent：慢思考（大模型规划）+ 快决策（小模型内循环）是降延迟的正解——browser / computer use 循环里每次动作选择交给快模型，规划留给大模型。来源：[开源中国](https://www.oschina.net/news/502609/typesafe-ai-system-one-models-and-jev)、[量子位](https://www.qbitai.com/2026/09/492939.html)、[GitHub](https://github.com/browser-use/jev-ultrafast)
- **Show HN：CUA-S1 —— A System One Model for Computer Use**（87 分）：[trycua/cua](https://github.com/trycua/cua) 给出 computer use 的 System One 模型 + 开源框架。对 Agent：想自建 GUI 操作 Agent，可以直接用它的框架起一版，再按需替换模型层。
- **Java 生态 AI 工具链两连发**：`mica-voice 1.0.2` 一行代码接入 ASR / TTS / 声纹 / VAD / 说话人分离 / KWS / 降噪；`mica-ppocr v1.2.3` 是 Java 8 兼容的 PP-OCRv6 纯 ONNX 推理引擎，内置 10 类证件/票据结构化解析。对 Agent：Java 后端做语音/OCR 工具节点的现成轮子，纯 ONNX 意味着可完全离线、不必再挂一个 Python 服务。来源：[开源中国](https://www.oschina.net/news/502596)、[开源中国](https://www.oschina.net/news/502595)
