## 🤖 大模型

**1. Gemini 4 Argon 发布（谷歌 09-30 20:04 官宣；InfoQ / 量子位 / 钛媒体 10-01 报道；官方博客已核实原文）**
- 关键数字：**输出 token 上限 64K → 100 万**（InfoQ 特别澄清：这是**输出上限**，不是输入上下文窗口）；定价 $2/百万输入 token、$10/百万输出，**缓存输入再降 95%**。基准：DeepSWE v1.1 77.9%、Zapier AutomationBench 51.3%（第一）、LVBench 91.7%（长视频）、CWE-bench v1 68%。
- 开放节奏：暂不对所有开发者开放——先通过 **Fairwind 计划**给受信任的安全防御团队，之后才轮到付费 API 用户与 Google AI Ultra；谷歌称将按早期反馈继续调整护栏。
- 对 Agent：天花板从「一次回答」挪到「单条轨迹几十万 token」，长任务（代码迁移、多轮调研、审计）可少做手工分段与状态拼接；但跑分不等于完成能力——InfoQ 的判断是成败仍取决于**目标一致性 + 工具调用正确性 + 自我纠错**。若你正为长任务写分段/摘要缝合逻辑，把「1M 输出」作为未来选项留口，别把分段策略写死。
- 谷歌自述的内部案例（部署规模参考）：一组 Argon agent 分析集群遥测自主做数据中心内存优化，落地后释放 **300+ TiB**；Fuchsia 内核（Zircon）**80 万行** C/C++→Rust 迁移在走，其中 Argon agent 把 libgav1 的约 3.2 万行 SIMD 换成可自动向量化的安全 Rust，跑出**原 Rust 移植版 2.7×**（同输出；注意不是 C++ 版的 2.7×）。
- 今天就能做：把 Argon 的 $2/$10 与「1M 输出」填进你的模型选型表（列：输入单价 / 输出单价 / 缓存折扣 / 最大输出 / 可用性）。它博客里写明的缓解项——prompt injection 防御、监测思维链与行动并在越界时停止——正好是一份现成的 agent guardrail 清单。

**2. OpenAI GPT-6.1 Sol（开源中国 09-30 17:10）**：官方定位「智能水平接近 Astra，价格仅为其五分之一」。
- 对 Agent：五分之一价的次旗舰是 agent 循环的天然主力档（路由、长链工具执行、格式转换）。配 Argon 的 $2/$10 一起进表，用你自己的工具定义做同题对比：p95 延迟、单轮 token、工具调用成功率。

## 🧩 Agent 开发

**4. `claude-code` v2.1.287（10-01 18:00，release notes 已核实原文）——本次改动最密集的一条**
- **MCP 兼容开关**：MCP 服务器现在支持 2025-11-25 协议的 URL prompts（例如登录页）；**升级后若有服务器连不上**，在该服务器的 MCP 配置项里加 `"bareElicitationCapability": true`。
- **遥测脱敏要同步改**：OpenTelemetry 的 `user_prompt` 事件新增 `prompt_text`（`prompt` 的副本，方便按点号嵌套取键的后端）——**凡是屏蔽/脱敏 `prompt` 的地方都要处理 `prompt_text`**，否则敏感 prompt 会从新字段漏出去。
- Claude Mods：插件可修改更深层行为；新增内置侧路 agent “You should know”（`/plugin enable cc-plugin-you-should-know@builtin`，一方会话 + 遥测开启时可用）。
- 其它值得知道的：agents 视图新增 `n:<text>` 过滤（匹配会话名与任务）；修复 `asyncRewake` hook 在脚本文件缺失时反复唤醒；修复在 Opus/Sonnet 间切换会重写早前的 MCP 工具公告、导致丢失 extended thinking；Windows 下禁用 Bash 工具会连带关掉 PowerShell 工具，现在有启动警告。
- 今天就能做：升级后查两处——MCP 配置项、遥测脱敏规则。它们都会在无人值守时静默出问题。

**5. MCP 生态开始「按客户端授权」：Figma 把 MCP 访问限制在白名单客户端，排除 Pi（HN 10-01 15:10，111 分 / 61 评）**
- 对 Agent：MCP 正从「开放即接入」变成「需注册/授权的受控通道」。自建 MCP 客户端要预留**客户端身份注册 + OAuth** 流程；不要把关键路径押在「某个第三方 MCP 永远免费开放」上，接口一变就是断供。
- 同向材料：OpenID Foundation 的《Identity Management for Agentic AI》(HN 10-01 15:11) 在定义 agent 的身份与授权模型——「给 agent 发身份、限定它代表谁行动」正在标准化，架构里先留位。

**6. 可复用的开源件 &「小模型替大模型做决策」这条线**
- `browser-use/jev-ultrafast` ★21669（09-16 建）：browser-use 团队出的「最快最便宜的 web agent」。
- `jaredpalmer/kev` ★8169：基于 Qwen3.5/3.8 的决策模型家族，可自行训练并自托管。
- `NandhaKishorM/laya` ★29701：非自回归 System-1 决策引擎，单次前向给出 typed choice / 打分 / yes-no，100+ 语言并带路由器。
- `KKKKhazix/AIHOT` ★4593：自己找热点、自己写日报的框架，信源与精选标准可替换（与本日报同类工装）。
- 对 Agent：前三条是同一思路——**循环里最贵的是每次「判断」**。把路由 / 分类 / 打分换成单次前向的小模型，能同时省 token 和降延迟；kev、laya 都能本地跑，适合当前置过滤器。

**7. 中文技术媒体的主线：上下文与 harness 被单独当成一层**
- 雷锋网《AI办公进入「上下文战争」，百度如何出牌？》（09-30 19:50）；雷锋网《在三张圆明园鼠首照片里，我们看到了 3D AI 的「Harness 时刻」》（09-30 15:57）——后者把「harness 决定模型上限」的判断从 LLM 推广到 3D/视觉模型。
- 对 Agent：与 10-01 日报里的 Codex Harness 开源同属一条线——**同一模型换 harness 的收益常大于换模型**。做对比实验时先固定模型、扫 harness（工具描述、上下文剪裁、重试策略），再决定要不要换模型。

**8. 新方向：世界模型（两条并读）**
- 钛媒体《豪掷 82 亿美元，芯片巨头押注的世界模型究竟是什么》（10-01 16:04）；雷锋网《越大越强，不再是 LLM 的专利：PixVerse R2 攻克实时世界模型 Scaling 难题》（09-30 15:53）。
- 对 Agent：世界模型是「行动前先预演」那类组件（规划 / 仿真）。做具身或浏览器操作的 agent，可以先把它当**离线仿真环境**用来回放与压测，不必急着当模型引进推理链。

## 🔥 值得深看

1. **`claude-code` v2.1.287 的两处静默坑**——MCP 的 `bareElicitationCapability` 兼容开关，和 OTel 新字段 `prompt_text` 的脱敏。前者会让某个 MCP 工具「突然连不上」，后者会让敏感 prompt 从你以为已经屏蔽的字段漏出去，且都在无人值守时发生。今晚就能查完这两处。
2. **Gemini 4 Argon 的「1M 输出」+ $2/$10**——第一次有人把**输出**上限（此前 64K）抬到百万级，长任务 agent 的分段与状态拼接策略可以重做。现在做不了接入（未开放），先把参数写进选型表。
