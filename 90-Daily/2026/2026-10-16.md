## ⚠️ 安全与踩坑

- **Archestra 开源 OpenAPPA：把权限策略搬到 agent loop 之外做确定性执行** — 用「数据源 / 访问对象 / 信任等级 / 权限主体」的格代数标签（标签只会更严格：读受限记录即缩小可访问面，读未核验外部网页即降信任等级）在模型之外强制数据流管控；Bench-Corp（20 个多步企业工作流）与 AgentThreatBench 上攻击成功率 0，对照 Claude Auto-Mode 10%、微软 FIDES 31%。其论点值得记住：用第二个模型审每次工具调用本质是概率化的（最好也只有 99.3%），且分类器自身会被注入、harness 又会为保护它而遮蔽工具输出，所以「跨工具调用的数据流追踪」必须放在确定性层。论文 APPA：arXiv 2607.24625。
  https://www.infoq.cn/article/LQCqiPUzgZyB3v24rsNO ｜ https://arxiv.org/abs/2607.24625
- **两条安全面：桌面端预览窗格可外泄 + AI 找漏洞已进入人力修补阶段** — noma.security 披露 Claude Code Desktop 的预览窗格可用于数据外泄（HN 15 分，细节见原文）；CNBC 报道美国银行雇了 1000 名合同工修补由 Mythos 暴露出的软件漏洞（HN 37 分）。对 Agent：前者提醒桌面 / IDE 类 Agent 的「渲染面」也是出网面，工具输出不要直接进 UI 预览；后者说明 AI 找漏洞的产出量已超过人类修补能力，安全向 agent 的价值点在「自动验证 + 给补丁」而非只发现。
  https://noma.security/noma-labs/sneakpeek-how-the-preview-pane-in-claude-code-desktop-can-exfiltrate-your-data ｜ https://www.cnbc.com/2026/10/14/anthropic-mythos-bank-of-america-hiring-cost.html
