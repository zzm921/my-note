## 🧩 Agent 开发
- **Claude Code 支持 AGENTS.md（v2.1.277）**：项目里没有 CLAUDE.md 时改读 AGENTS.md，可在 `/config → Project instructions` 切换（Bedrock/Vertex/Foundry 暂不支持）——多工具（Claude Code / Codex / Cursor）共用一份项目指令文档终于成立。同版还加了 `CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1`（出网只走正向代理时交给代理解析主机名）、网关 upstream 自定义 `headers`，并修掉 `claude -p`/Agent SDK 内部错误后**无结果挂起**（现改为报错并 exit 1）。[v2.1.278](https://github.com/anthropics/claude-code/releases/tag/v2.1.278)（09-19）把 auto mode 默认切到服务端分类器（不收分类器开销），`CLAUDE_CODE_AUTO_MODE_SERVER=0` 可退回。升级：`npm i -g @anthropic-ai/claude-code@latest`。来源：[Release v2.1.277](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)（09-18，HN 702 分）
