## 🤖 大模型

**1. Gemini 4 Carbon 开放 API：$2/$10 每百万 token，主打长程 Agent 工作流**
Google 官方博客确认 Carbon 已对开发者/企业开放（AI Studio、Gemini for business），输入 $2 / 输出 $10 每百万 token，与 Gemini 4 Argon 同价；官方称在 CursorBench 4.0、Perplexity WANDR、Zapier AutomationBench 排第一，单任务成本不到对手一半。同时预览 Antigravity 的 `/swarm`：一句 prompt 拆成一组可实时追踪的 agent，Carbon 负责架构/协调/审计，轻模型在并行隔离工作区跑执行，外加独立 verifier 对抗式校验。
对 Agent 开发：等于多了一个「贵活专用」的规划+审计模型（同价但按需多花 token 深挖），而 `强模型定架构 + 弱模型并行执行 + 对抗 verifier` 这套编排今天就能照搬进自己的流水线。
→ https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/

**2. Meta Muse Ember：专为 Agent 高频任务优化的轻量模型，单任务成本约 1/3**
定位很明确——工具调用、编码子任务、任务路由、信息抽取、长文档解析这类「一天跑几万次」的活。Artificial Analysis 智能指数最高档约 36，与 Claude Haiku 5.5 持平（GPT-6 Luna 28）；单任务成本 $0.136 vs $0.411。AutomationBench-AA 37.8%（对手 20.2% / 13.9%）、Agents' Last Exam 61.6%、Terminal-Bench 4.0 40.9%；但 FrontierCode 2.0-AA 只有 27.2%，落后 Haiku 5.5 的 34.9%。
对 Agent 开发：适合当「路由器 + 子任务执行器」，把贵模型留给规划与疑难；别指望它顶复杂重构。Meta Model API 和 Muse Code 已可调用。
→ https://www.infoq.cn/article/Ou4l4aD7zvUzXWXsWJfY

**3. 蚂蚁灵波开源 LingBot-Touch 触觉基础模型：触觉信号 Token 化**

**10. arXiv HiVe-Mem：多模态 Agent 的记忆要「横向铺开 + 纵向缝合」交错做**
2611.12864 把记忆扩充分成两条轴——横向扩展（并列铺开多模态证据）与纵向组合（沿推理链把证据缝合成结论），两者交错执行，而不是一次检索完事。
工程启发：图/表/文档多源证据时，把「收集」和「缝合」拆成两个阶段，调参和排查都会容易很多。
→ https://arxiv.org/abs/2611.12864

## 📊 评测与基准

**11. arXiv WorkflowArena：评多智能体工作流「能不能真的跑通」**
2611.12820，面向 LLM 多智能体系统的可执行工作流编排基准——评的不是最终答案，而是工作流本身能否执行成功。
用法：自建编排时拿它的任务形态对照自己的失败模式（节点失败、依赖错序、产物不匹配），比只看成功率更能定位问题。
→ https://arxiv.org/abs/2611.12820

## 💰 成本与基础设施

**12. microsoft/TokenEconomizer（★5625）：Coding Agent 的黑盒成本控制**
