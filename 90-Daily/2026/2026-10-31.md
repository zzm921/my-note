- **VeriCUA：把「验证」本身做成 agentic exploration**（arXiv 10-30）：面向 computer-using agent，让 agent 主动探索来确认自己的操作结果，而不是事后外部打分。对 Agent：GUI / 浏览器类 agent 最大的失败是「看起来点对了」——把验证做成动作序列的一部分（回读页面状态、断言副作用），比外挂一个 judge 模型可靠。

## ⚠️ 安全与踩坑

- **官方 Claude Code VS Code 扩展在 Cursor Marketplace 被植入后门（2.1.313）**（Phorion 10-30，已核原文）：受影响版本 **2.1.313**，bundle 里带持久化 SSH 后门（macOS / Linux / Windows 都有逻辑）；Cursor 已下架该发布，并从 npm 与 VS Code 市场撤回 2.1.313。macOS 上脚本用 `systemsetup -getremotelogin` 判断状态时权限不足、把报错当「已开启」而跳过开启步骤，入站通路没打通，但 SSH key 与持久化项照样落地，主机侦察仍在回连。**今天就能做**：`claude --version` 核对版本并升到 2.1.314；查 `~/.ssh/authorized_keys` 有无陌生 key，查 `~/Library/LaunchAgents`、`~/.config/systemd/user`、计划任务有无新增项；开发机与 CI 上的 SSH key 轮换一遍。
