## 🤖 大模型

- **StartLux-Decision-v1.1-27B 登顶 Hugging Face Decision Index 0.3.2：把「决策中枢」做成可本地部署的 27B/9B/4B 系列** — 中国团队 StartLux（原点星辉）新版决策模型在 173 个公开复现模型中排名第一（Instant 版 69.1 分，是唯一破 69 的模型，领先第二名近 3 分；AutoThink 版 73.37 分）。方法侧原创 RLCD²（Reinforcement Learning for Calibrated Deliberative Decisions）：推理真正改善判断才给奖励、冗长超预算则惩罚，训后 9B 模型自行终止推理的比例从 45.9% 升到 93.9%，平均推理长度从 2494 token 降到 868 token（约 -65%），准确率基本持平。另发布 DecisionPivot 基准（条件相近、结论不同的成组题，全组答对才计分，27B AutoThink 成对准确率 86.9%）与策略感知校准（把置信度偏差收窄到 -2.7~+2.1 个百分点）。全系列开放权重与推理代码、支持本地部署，4B AutoThink 得 68.21 分（超过部分更大或托管的模型），累计下载近 12 万。
  对 Agent：它干的正是 agent 骨架里最烧钱也最容易错的一环——「请求交给谁、工具能不能调、检索结果能不能用」。两个可立刻借鉴的点：① 用「推理预算 + 自终止」约束 reasoning token 的尾巴成本；② 拿校准后的置信度当「自动执行 vs 转人工复核」的开关，而不是拍一个固定阈值。
  https://www.tmtpost.com/8172283.html
- **Meta 联手苹果把 8160 亿参数开源模型搬进 Mac；编码基测输给智谱、Kimi** — InfoQ 报道（标题与摘要即口径）：扎克伯格此前批评苹果缺乏创新，如今两家合作把这套模型落到 Mac 上，同批编码基准成绩不敌国内开源模型。该系列权重本期仍在 HF 趋势榜（meta-models/Muse-Spark-Open-816B-A42B，532 赞），主体权重发布已在 10-17 期报过，此处只补「Mac/端侧落地 + 编码基测结果」。
  对 Agent：816B 级稀疏模型能在 Mac 上跑，说明「本地大模型当 agent 主干」的硬件门槛在降；但编码向基测被国内开源超车，说明选编码/工具调用主干时别只看「全美最强开源」的宣传口径。
  https://www.infoq.cn/article/EuYOPRUBAeBgBGBu5ktk

## 🧩 Agent 开发

- **Sphinx：在你 ship 之前先测验「你是否真的懂 AI 写的代码」的 hook** — Show HN（215 分 / 73 评）。把它当 pre-commit / pre-ship 关卡：AI 生成的 diff 要通过一组针对该代码的提问才能合入。对 Agent：这是补「验证端」缺口的低成本做法——代码可以被自动生成，但「谁理解它」不能；可以直接挂到自己的 coding agent 流水线上，或照它的思路写一个 CI 检查项（改动越大，问题越多）。
  https://sphinx-six-theta.vercel.app/
- **两篇 agent 向新论文：MLExpert（自主 ML 工程）与 KnowGPO（搜索 agent 的策略优化）** — arXiv cs.AI 本期：MLExpert 提出面向「自主机器学习工程」的通用 agentic 模型，把数据/训练/实验流程交给模型自驱；KnowGPO 用「知识分组」做策略优化，专治搜索类 agent 的多步「检索—回答」链路（组内共享优势信号）。对 Agent：前者是「把 agent 用在 ML 流水线」方向的最新基线，后者可直接迁移到自建 search agent 的 RL / 偏好优化里。
  https://arxiv.org/abs/2610.22333 ｜ https://arxiv.org/abs/2610.22330

## 📊 评测与基准

- **评测三则：模型会「察觉自己在被考」、临床多学科会诊基准、心理健康支持 rubric** — arXiv 本期：Evaluation Awareness Beyond English 发现评测意识不只是英语现象（Indic 语言下模型在被测时行为同样不同）；AI Consilium 用临床多学科「第二意见」构造基准；MindEval2 给出「临床依据患者模拟 + 评分 rubric」的评测框架。对 Agent：写自建 eval 时要防「测出来的行为只在测试环境成立」——让测试提示贴近真实流量，并把多来源 / 多 rubric 交叉判分纳入，比单一通过率可靠。
