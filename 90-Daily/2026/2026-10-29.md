## 🧩 Agent 开发

- **Antigravity SDK 支持本地模型：架构师在云、构建者在本地**（InfoQ 10-28，已抓全文核实）：云端「架构师」只看任务描述与文件名就把计划拆好、**不上传源码**；本地「构建者」负责复现漏洞、写补丁、跑回归。官方 demo 里 3400 token 仅 **95 个上云（97.2% 留在本地）**。默认用 LiteRT 跑 Gemma 4 26B A4B，也支持通过 `LocalOpenAIAgentConfig` 接 **Ollama / LM Studio / vLLM** 的 OpenAI 兼容服务。工程注意：社区反馈 24GB+ 显存/统一内存是门槛，「省 token」≠「更便宜更快」，要同时看补丁接受率与耗时。
  https://www.infoq.cn/article/TusFJkx6F151otgzliu2
- **豆包把「操作电脑」录成技能，锁屏后仍可继续跑**（雷锋网 10-28）：GUI 操作过程可录制复用为技能，任务转后台执行。对 Agent：这是「技能录制 = 可复用记忆」的产品化样本——你也可以把一次成功的 GUI/工具序列存成结构化技能（步骤 + 选择器 + 前置断言），比每次让模型重新规划便宜得多；录制出的技能一定要带失败回退。
  https://www.leiphone.com/category/industrynews/MYDTBZqQkhfVtkte.html
- **llama.cpp v0.8.0：新增 `/v1/realtime` 与 `/tts`，本地语音 Agent 少一层胶水**（10-28）：加入 LiquidAI LFM3 全家（text / vision / audio / omni）与 `mtmd` 实验性流式音频 API，服务端直接暴露实时音频与 TTS 端点。对 Agent：本地语音 agent 不必自建 WebSocket 音频桥，OpenAI 兼容端点可直接接；标注为实验特性，先压测再上生产。
  https://github.com/ggml-org/llama.cpp/releases/tag/v0.8.0
- **两个值得翻源码的新热仓库**：`learnharness` ★3494（10-16）—— 让 Agent 学难题的 harness，可借它的「观测-反馈-重试」骨架；`earshot` ★3127（10-15）—— 给 coding agent 加「耳朵」的声音反馈层，纯 CPU 可跑。都还年轻，读设计比直接用更划算。
  https://github.com/amosblomqvist/learnharness ｜ https://github.com/Leonxlnx/earshot

## 💰 成本与基础设施

- **价格战新数字：大客户直接 1 折，模型四个月降价 80%**（InfoQ 10-28）：竞争焦点从标价转向「谁能拿到合约价」。对 Agent：调用结构比单价更决定账单——稳定前缀吃缓存、可批量的走批处理、给每个 agent 记「单任务成本」而不是总 token。
  https://www.infoq.cn/article/ejtljxPixrIuUsGYi5xa
- **Instagram 把 token 成本降 33%，靠的是架构不是提示词**（InfoQ 10-28）：原生 AI 架构改造 UI 后成本下降。对 Agent：先算清「哪些步骤必须过模型」，把确定性渲染/格式化从模型里拿掉，通常比换更便宜的模型省得多。
  https://www.infoq.cn/article/bXKVgLdpf7HONYHIi6Su

## 🔥 值得深看

- **Antigravity SDK 的「架构师-构建者」拆分**：云端只拿文件名与任务描述做计划、97% token 留本地——目前最可直接抄的隐私与成本双赢结构，今晚就能用 Ollama 复刻一版。
