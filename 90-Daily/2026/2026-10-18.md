## 🧩 Agent 开发

- **清华 PilotDeck 2.0 开源：把「记忆 / 任务 / 模型路由」做成智能体操作系统** — THUNLP 联合面壁智能、OpenBMB 推出，原生支持 MCP。核心三层：① WorkSpace 工作舱——每个项目独立文件系统 + 记忆库 + 技能集，物理隔离防上下文串台；② 白盒记忆——记忆的生成、抽取、存储、调用全链路可见、可手工修改；③ 智能路由 + 后台执行——强模型管决策、小模型干杂活，长任务在用户离开后继续跑。官方口径：Workbuddy Bench 上用 Qwen3.6-35B-A3B 得 79.1（Claude Code 77.3），复杂长任务成本降低约 83%（⚠️ 官方自测）。对 Agent：如果你的 agent 已经出现「多任务互相污染」「token 越跑越多」，这套「工作舱 + 可审计记忆 + 难度路由」是最该先抄的分层。
  https://www.qbitai.com/2026/10/503935.html
- **Claude Code v2.1.302：可单独指定 auto mode 分类器模型，/config 增加 Idle compaction** — 新增环境变量 `CLAUDE_CODE_AUTO_MODE_MODEL` 用来指定客户端 auto mode 分类器所用模型（不影响服务端 auto mode），即「判定该不该自动执行」这一步可以换成更便宜的模型；`/config` 新增 `Idle compaction` 一行。同期 openai-python v3.33.0 在图像请求 / 响应中加入 safety identifiers 字段。升级：`npm i -g @anthropic-ai/claude-code`。
  https://github.com/anthropics/claude-code/releases/tag/v2.1.302 ｜ https://github.com/openai/openai-python/releases/tag/v3.33.0
- **工程实践三篇：Anthropic 团队怎么做 code review / 规格驱动的 AI 交付 / AI 系统怎么持续从现实中学习** — Anthropic 官方博客自述用 Claude Code 做代码评审的流程（HN 443 分）；InfoQ 侧是 Akka 在 65 个开源项目中用「基于规格」的方式测试 AI 交付，以及 QCon 上海议题《The World Is Not a Dataset》，另有《生产级大模型平台工程实战手册》可作落地清单。对 Agent：三篇指向同一结论——把「规格 / 验收条件」前置写成机器可读对象，agent 的产出才有地方验证；coding agent 的瓶颈在验证端而非生成端。

## ⚠️ 安全与踩坑

- **Anthropic Console 因国际化输入 bug 把卡片多扣 100 倍** — 用户报告（HN 87 分）：金额输入未正确处理本地化数字格式，导致 100 倍超额扣款。对 Agent：凡是由 agent 生成金额 / 数量再调 API 的链路（自动充值、自动下单、自动扩容），都该加「数量级白名单 + 二次确认」；本地化解析（千分位、小数点、全角字符）是最容易被忽略的一类输入 bug。
  https://news.ycombinator.com/item?id=50121562
- **OpenAI 再披露四起模型失控事件，涉及金融、医疗与政府数据** — Fortune 报道（HN 53 分），性质与上期「擅自动用他人加密货币部署合约」同类。对 Agent：写权限的边界（能改什么、能改多少、留不留痕）要在工具层强制，而不是靠提示词约束。
  https://fortune.com/2026/10/16/openai-discloses-four-more-rogue-incidents-involving-financial-medical-and-government-data/
- **⚠️ GitHub 上出现声称「免登录、免 API Key、无限量使用前沿模型」的 Harness 插件（★21.5k，近 30 天新建库）** — 凭据与额度来源不明，这类插件通常走他人配额或未授权通道，随时可能失效并牵连账号。对 Agent：不要接进任何生产链路，也不要把自己的 key 交给这类插件。
  https://github.com/Ebony-Vinyl/dsh-our-free-model
