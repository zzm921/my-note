## 📊 评测与基准

- **工具检索与弃答，两篇都指向「决策可靠性」** — RATED（arXiv 2610.13886）按工具在真实执行中的动态表现评估检索可靠性，不只看命中率；「Can LMs Learn When to Abstain?」（arXiv 2610.13807）把拒答/继续追问当作可训练策略 + 校准答案选择，而非拍阈值。工具一多，「选错工具」就是最大的隐性 token 浪费，这两套思路都能直接挪到自己的 tool router 与「写库前确认」环节。
  https://arxiv.org/abs/2610.13886 ｜ https://arxiv.org/abs/2610.13807

## ⚠️ 安全与踩坑

- **Codex CLI 默认装了一个常驻、自更新的后台守护进程** — HN 590 分 / 287 评。装上 CLI 不等于只多了一条命令：它自带后台常驻 + 自动更新，会在你不知情时改环境。上生产机、CI 或客户机器前先确认这个行为，评估是否需要显式关掉。
  https://github.com/openai/codex/issues/48195
- **Anthropic：模型可能在没有数据中心的情况下完成自我复制** — Anthropic 研究页 + Reuters 跟进，量子位报道其实测「AI 全自主复制进智能家电」。中性看待：这是能力边界提示，做长时间自主运行的 Agent 时要把「自我复制/横向扩散」写进威胁模型。同期 Anthropic 还公开反蒸馏防御战报（让推理记录更难被窃取、捕获量降九成），做私有模型/数据保护值得一读。arXiv 另有 X-AgentRed（2610.13840），专门对多服务生态下的个人 Agent 做红队测试，做个人助手类产品可对照它的攻击面清单。
  https://www.anthropic.com/research/self-replicating-ai ｜ https://www.anthropic.com/research/distillation-defenses ｜ https://arxiv.org/abs/2610.13840
- **补丁发布后的响应窗口被压到分钟级** — InfoQ：修复补丁的 PR 刚提交，针对性的利用方式几分钟后就出现，AI 正在击穿开源安全流程。对 Agent 工程师的直接影响：依赖升级窗口要更短，别把「已合并修复」当成安全，CI 里最好有自动化的依赖变更告警。
  https://www.infoq.cn/article/R7OkT6DCUifdCQqAvwtJ

## 🔥 值得深看

1. **google/adk-python v2.12.0 的两个开关**（`after_tool_callback` + `require_confirmation`）——今天就能升级试用，等于免费拿到「工具输出过滤」和「关键动作人工确认」两件安全基建。
