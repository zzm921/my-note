📰 AI 热点日报 | 2026年11月26日

## 🤖 大模型

**智谱 GLM-5.4：旗舰首次上 Loop Transformer（Loop 循环 28 层 ×2 轮，750B 级）**
11/23 发布，不再从零预训练，而是把已训好的 GLM-5 基座改造为权重共享循环结构——不加参数量、换更深的「有效计算深度」，主打长程任务与「泛 Coding」（用代码做视频/3D/游戏）。已向 GLM Coding Plan 全量开放（个人 V2/V3 与团队版额度 ×1.5），接入 ZCode、Trae、WorkBuddy、Qoder、OpenCode 等编码平台；API 待安全评估后开放，官方称后续将开源权重。
对 Agent：实测能跑通 1.5 小时级的多步工程任务（Blender Bullet 物理 + FFmpeg 渲染 + 原生 JS 游戏），但会进入「雷霆大思考」模式，峰值 5504.7 万 token；更关键的是连续 3 次自动上下文压缩后仍在 3 轮工具调用内被填满——**工具返回体量大的 Agent 必须做分块读取 + 子会话隔离，别指望长上下文硬扛**。
https://www.infoq.cn/article/gXU31yBa9HMEe19PxHVB

**腾讯混元 Hy4-flash：220B 开源权重，量化后可塞进 64GB Mac mini**
HF 仓库 `tencent/Hy4-flash` 为 BF16 共 2202 亿参数，许可标记为 other（非标准 OSI 协议，商用前先读条款）。
对 Agent：这是目前少见的「本地可跑的大尺寸通用模型」，适合把私有数据的工具调用链放在自己机器上，避免每次 function call 都出网；代价是 KV cache 吃内存，长会话要配 gputaskman 之类工具盯显存。
https://www.oschina.net/news/503813

**百度文心 5.5 Flash Preview 正式开源，Apache-2.0**
`baidu/ERNIE-5.5-Flash-Preview` 11/23 上传、11/24 更新，仓库同时给 INT8 为主 + FP8/BF16 部分层的混合精度权重；Apache-2.0 是这个仓库最实用的信息——可商用、可改、可二次分发。
对 Agent：Apache-2.0 的国产主力模型权重，适合做需要长期自建、不能绑定单一 API 的 Agent 后端；Preview 版本，别直接上生产。
https://huggingface.co/baidu/ERNIE-5.5-Flash-Preview

**英伟达开放 Nemotron-Labs-Image-30B-A3B 权重：30B MoE / 3B 激活**
官方口径称某些生图跑分超过 GPT Image 2。MoE 只激活 3B，单卡可部署。
对 Agent：多模态 Agent 的出图环节可以从「调外部 API」改成「本地子模型」，延迟和素材合规都可控。
https://www.ithome.com/1/032/444.htm

## 🧩 Agent 开发

**claude-code v2.1.332：MCP server 也能下发 skills，新增 skill 级 shell hook**
两个改动点：① MCP server 提供的 skill 进入 `/` 菜单，显示为 `server:skill`，其余 skill 保持原名——**skill 分发从「本地目录」扩展到「远程 MCP 服务」**；② 新增 `PreSkillShellCommand` 钩子，可以在 skill / 命令的内联 shell 执行前拦截。
对自建 Agent 的启示很直接：能力包走 MCP 分发 + 执行前 hook 做审批，是社区正在收敛的形态。升级：`npm i -g @anthropic-ai/claude-code`。
https://github.com/anthropics/claude-code/releases/tag/v2.1.332

**google/adk-python v2.15.1：A2A 流式与工具调用校验的稳定性修复**
修复集中在 model sampling、agent-to-agent streaming、tool call validation、instruction routing 四条线，版本号补丁级、无破坏性变更。
对 Agent：正在用 ADK 做多 Agent 编排的，这是低风险升级——尤其 tool call validation 修的是「参数不合 schema 仍被下发」这类静默错误。升级：`pip install -U google-adk`。
https://github.com/google/adk-python/releases/tag/v2.15.1

**arXiv《Delegent》：多 Agent harness，砍成本不掉性能**
把任务按「谁做更便宜」在多个 Agent/模型间分派，而不是全交给最强模型跑到底，构建在既有 harness 之上、无需重训。
对 Agent：这是本周最对口的一篇——你的路由层如果还只是「按任务类型硬编码模型」，这篇给的是可直接照抄的成本-性能折中框架。
https://arxiv.org/abs/2611.33086

**sybil-solutions/inference-optimisation-skill ★2.7k：让 Agent 自己调本地推理速度**
一个 Agent skill，专门在任意硬件/量化配置上「爬山」式优化本地 LLM serving：decode、投机解码、prefill、KV、启动时间、TTFT 逐项调参。
对 Agent：把「性能调优」变成 Agent 可执行的技能，适合接在你已有的 skill 目录里，跑在自建推理服务上。
https://github.com/sybil-solutions/inference-optimisation-skill

**shanselman/gputaskman ★3.8k：按进程看 VRAM / KV cache 的跨平台 GPU 任务管理器**
支持 NVIDIA / AMD / Intel，Linux 上还支持华为昇腾，能给出每个进程的显存、GPU 活动，以及 LLM 模型与 KV cache 占用。
对 Agent：本地跑 Agent + 本地模型的组合最容易死在「不知道谁吃了显存」，这个比 nvidia-smi 直观。
https://github.com/shanselman/gputaskman

## 📊 评测与基准

**AIChipBench（arXiv 2611.33078）：用 Agent 自动做 AI 加速器设计当基准**
把「设计一个 AI 加速器」拆成 Agent 可执行的完整任务链来评测，而不是单轮问答。
对 Agent：如果你的 Agent 要碰 EDA/硬件这类长链路、强约束领域，这个基准的拆题方式（任务分解 + 可验证产物）比分数更值得抄。
https://arxiv.org/abs/2611.33078

**《Auditing the Judge》（arXiv 2611.33035）：LLM-as-judge 的人类偏差审计**
从人类标注里先挖出偏差，再量化它在 LLM 裁判中的复现程度，最后给缓解手段。
对 Agent：凡是用 LLM 打分做 Agent 回归测试的，都要先跑一遍这个思路——否则你测的是「裁判的偏好」，不是「Agent 的能力」。
https://arxiv.org/abs/2611.33035
