- 今天就能做：`claude-code` 升到 v2.1.284（该版本已把它设为默认），API 侧模型名 `claude-sonnet-5-5`。

## 🧩 Agent 开发

**4. ollama v0.35.0 新增「决策模型」支持**：走 `/v1/systemone`（基于 TypeSafe 的 Jev API），决策模型返回 choices / probabilities / scores 而不是文本。
- 对 Agent：这是把 System-1 从 LLM 里拆出来的路线——路由、门控、意图分类、工具选择这类"选一个"的步骤，用毫秒级、单次前向的非自回归模型替代 LLM 调用，同时砍延迟与 token 成本。
- 同族开源可自建：`NandhaKishorM/laya` ★28.4k（100+ 语言）、`jaredpalmer/kev` ★7.9k（基于 Qwen3.5/3.8，可自训自跑）、`Contrastive-LM/CLM` ★2.5k；开源中国报道的 Jeff 用 0.8B 微调逼近 Jev，22ms 出一次决策。
- 今天就能做：升级 `ollama` 到 v0.35.0，用 `/v1/systemone` 起一个本地决策模型，替换 Agent 前置分流。

**5. SDK / CLI 升级点**：`anthropic-sdk-python` v1.9.0 新增 `between_tools thinking` 思考类型（工具调用之间插入思考，直接影响多步工具链的规划质量）；`claude-code` v2.1.284 的 auto mode 权限确认多了"是，但下次再问"这个半自动放行选项；`openai-python` v3.21.0 加新模型标识符。
- 今天就能做：三个包一起升级，在你的多步工具 Agent 上把 `between_tools` 开起来做一次 A/B。

**6. crewAI 1.15.23**：新增原生 Gemini 3.8 Flash 支持；`crewai eval` 改为记录最近一次 trace 并对其评测（不再只打印）——多智能体编排的回归评测终于能沉淀下来。
- 今天就能做：`pip install -U crewai`，把 eval 接进 CI，对 crew 改动做基线对比。

**7. Strands 开源「组装好的 Agent harness」**（开源中国）：官方称同模型下 token 消耗省 28%。
- 对 Agent：说明 harness 层（工具描述写法、对话剪裁、循环结构）的收益已能独立于模型来量化，值得做一次对照实验。

**8. `browser-use/jev-ultrafast` ★21.4k**：官方定位"最快最便宜的 web agent"，browser-use 系在浏览器自动化 Agent 上继续加码。
- 对 Agent：如果你的采集/操作环节还是通用 LLM + 手搓 Playwright，这是可直接替换的候选。

**9. `KKKKhazix/AIHOT` ★2897**：一个"自己找热点、自己写日报"的网站框架，换掉信源与精选标准即可变成自己的行业热点站。
- 对 Agent：正好是「定时采集 → 筛选 → 生成 → 落站」的完整可跑编排样板，写自建日报/监控类 Agent 可直接参考其结构。

**10. Cloudflare 推出智能体开发栈生命周期，取代传统 SDLC**（InfoQ）：按"智能体"重新组织构建—部署—观测—回滚，而不是套用软件交付流程。
- 对 Agent：搭 Agent 上线流程时，这是一份现成的框架参考（沙箱、工具权限、可观测三件事怎么串）。

## 📊 评测与基准

**11. arXiv 方向（cs.CL / cs.AI）**：
- `Failure-Transparent Agents`：系统评测"工具调用失败后模型是否如实上报"的基准——直接命中生产里最贵的静默失败。
- `FinAutoRubric`：专家引导的自动 rubric 生成，用于评测金融研究 Agent（rubric 自动化 = 评测可扩展）。
- `Report: Progressive Disclosure of Agent Skills`：Agent Skills 的渐进式披露（按需加载技能说明以省上下文），对自建技能库的设计可直接借鉴。
- `Shockingly Simple Self-retrospection Improves Agentic Models Without RL`：无需 RL 的自我回溯即可提升 agentic 表现，属低成本改进路线。
