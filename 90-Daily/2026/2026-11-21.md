**Gemini 4 Neon 首批实测出炉：100 万上下文，单任务成本不到 Carbon 一半**
InfoQ 20 日给出实测细节：上下文约 100 万 token、最多输出 100 万，吃文本/图片/视频/音频/PDF，原生支持 Computer Use、代码执行、文件搜索。定价 $3 / $15 每百万输入输出 token（Carbon 与 Argon 首发价 $2/$10 到 11-30，12-1 起回涨到 $4/$20）。Artificial Analysis 智能指数同为 60 分时，Neon 单任务 $3.74 vs Carbon $7.76，输出约 110 tok/s、任务完成时间快约四成 —— 长工具循环、多次重试的 agent 任务，这一档是当下最划算的换血位。
https://www.infoq.cn/article/tDxNggErsJNeb53ZkYeF

**同一份实测里最该抄的是 harness 结论，不是模型分数**
SWE-sweep 上 Neon 用 mini-SWE 只解 12.8%，接入 Antigravity 后 39.0%（该 harness 与 Gemini 联合训练）；同组 Claude Opus 5.5 换到 Claude Code 是 3.6%→10.1%，而 GPT-6.2 Sol 换到 Codex 反而 11.6%→8.3%。**换 harness 的收益可能大于换模型，也可能是负的** —— 选型必须模型×harness 成对测，别只搬榜单分。Neon 另带「Neon 规划 + Hydrogen 执行」的模型切换与 /swarm 并行子 agent。

## 🧩 Agent 开发

**google/adk-python v2.15.0：会话写入异步化、Live 工具调用不阻塞语音、评测能算「可靠率」**
直接可用的改动：`BufferedSessionService` + `append_events` 把会话事件内存缓冲、后台批量刷盘，慢 DB/网络不再卡在 turn 关键路径上（experimental）；`run_live` 把每次工具调用丢进后台 task，语音、转写、打断不再被慢工具堵住，且 `send_context_update` 可在已开的 Gemini 3.x Live 连接上热更新 system instruction 与工具，不用重连。评测侧区分 `pass@k`（至少成功一次）与 `pass^k`（每次都可靠），并新增 `tool_parameter_match` 按参数给部分分（IN_ORDER/EXACT/ANY_ORDER 配对）—— 判断「工具调用到底多准」终于不用全有全无。RAG 记忆检索复用 client，延迟最多降 6x；`BaseEnvironment.scope` 支持 SHARED/USER/SESSION 沙箱隔离且不互相等锁。
⚠️ 破坏性变更：ADK Web 移除交互式 Visual Agent Builder（`/dev/apps/{app}/builder*` 与 `google.adk.cli.built_in_agents` 删除），已建好的 YAML 仍可 `adk web/run/deploy`。今天就能做：`pip install -U google-adk==2.15.0`，先试 BufferedSessionService，再查 CI 有没有依赖 builder 路由。
https://github.com/google/adk-python/releases/tag/v2.15.0

**蚂蚁 OceanBase 开源 PowerContext ★1761：把「决策/约束/证据/进度」搬出对话**
定位是 agent 的 context 服务：持久部分做成可版本化的 artifact，下次会话、下一个 agent、换个人接手都不用重读 transcript；Scope 隔离数据（Source journal / Memory / Handoff）。接口齐：HTTP/MCP、Python client、CLI、Dashboard，插件已支持 Claude Code 与 Codex，Apache 2.0。1.5.2 带交互式 setup wizard，需 Python 3.11+/Git/uv；Basic memory 不需要模型 API，Full memory 才要 generation+embedding 凭据。今天就能做：起本地 server → 在 Claude Code 里挂 MCP → 把同一个任务拆成两次会话验 handoff。
https://github.com/oceanbase/powercontext

**本周版本速览：四个改动点都落在错误处理与交付物上**
anthropic-sdk-python v2.12.0 新增 `image_dimensions_too_large` 错误码（图片超限可单独降采样重试，不必吞掉整轮），Bedrock 改在请求 body 里传 `user_profile_id`；openai-python v3.57.0 支持 Live WebRTC standby（实时语音断连可切换）；crewAI 1.15.44 可把文件存成可版本化、可分享的 artifacts，并修了 flow 内联 agent/crew 的相对引用与分隔符重复；claude-code v2.1.329 增加 hooks 信任对话框（显示该文件夹的 hooks 在哪声明），managed settings 里 hooks 加载失败会直接在对话里告警 —— 用企业策略下发 hooks 的团队，这是排查入口。

**量子位：Agnes 用「双系统决策 + 双层自进化」把 Agent 提速 14 倍、成本降到 1/27（厂商自述）**
架构思路可借鉴：快路径/慢路径分离决策，经验回写到策略层而不是堆 prompt。数字属厂商自报，迁移到自家场景前需自测。
