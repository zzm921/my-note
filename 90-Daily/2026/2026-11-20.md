## 🧩 Agent 开发

**claude-code v2.1.328：交互会话默认 auto 模式 + onFailure: block**
两处改动直接影响生产用法：Opus 4.6 / Sonnet 4.6 在 Amazon Bedrock、Google Cloud Agent Platform、Microsoft Foundry 与 Claude apps gateway 上新增 auto 权限模式，且未指定权限模式的交互会话默认进入该模式；新增 `"onFailure": "block"` 配置，工具/hook 失败时直接阻断而不再降级继续。今天就能做：检查 CI 与自动化脚本里依赖"失败继续"的环节，显式补上该配置。
https://github.com/anthropics/claude-code/releases/tag/v2.1.328

**openai-agents-python v0.24.0：MCP 发现注解 + 全 run 级错误格式化**
官方 SDK 小版本，改动集中在三处：run 级别的函数错误统一格式化、MCP 服务发现注解、以及恢复能力 / 沙箱安全 / tracing 的改进。用 MCP 接外部工具时，这次能把"工具发现"阶段的元信息带进 trace，排查"模型挑错工具/传错参"会容易很多。升级方式就是常规 `pip install -U` 到 v0.24.0。
https://github.com/openai/openai-agents-python/releases/tag/v0.24.0

**OpenHands v1.42.0 / crewAI 1.15.44：接入与产物两处修补**
OpenHands 1.42.0 主要加"精确选择已连接的 git provider 来取仓库"，多 git 托管并存时不再猜错仓库；crewAI 1.15.44 增加"把文件保存为可版本化、可分享的 artifacts"，并修了 flow 内联 agent/crew 相对引用与分隔符重复的 bug。都是小版本，但前者对自建 coding agent 平台、后者对需要交付物留档的流水线值得排一次升级。
https://github.com/OpenHands/OpenHands/releases/tag/v1.42.0
https://github.com/crewAIInc/crewAI/releases/tag/1.15.44

## 📊 评测与基准

**arXiv：视觉 Agent 的"预算配对反事实审计"**
2611.24845。方法上是给视觉 agent 的每次观察决策配一个同等预算的反事实对照，判断性能提升究竟来自"看得更准"还是"多看了几帧/多跑了几步"。对自建 agent 的直接用处：把能力提升与预算提升分开归因，避免评测被 token 与步数预算污染。
https://arxiv.org/abs/2611.24845
