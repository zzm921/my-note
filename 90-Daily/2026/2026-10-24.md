## 🧩 Agent 开发

- **Dify 1.18.0**（10-23，已核 release notes）：四个能直接用上的改动 —— ① **Agent Output Routes**：让 Agent 自己决定走哪条工作流分支，每个路由带选择条件，只读的 `switch` 输出暴露所选路由（比在节点里堆判断清晰得多）；② **`.ifpkg` 可移植应用包**：Workflow / Chatflow 连同内联 Agents、Skills 及其文件一起打包搬走，导入后自动重建资源并重映射引用，跨工作区迁移不用手工拼；③ **嵌套工作流可下钻**：从运行历史点开 Workflow Tool 调用，看子工作流每一步，子图支持 pause / resume / stop（多 Agent 编排的调试面补齐）；④ **Agent Knowledge Base（Beta）** + 新 CLI **difyctl**（`difyctl install skills <dir>` 能给「写 Dify 应用的 Agent」直接装上技能，另支持 DSL 导入导出、发布、版本回滚，草稿哈希防并发覆盖）。
  升级注意（官方警告）：API / workers / Agent Backend / Agent runtime 镜像要**一起升**；本地 Agent sandbox 需非空认证 token；源码安装要求 Python 3.13；保留原有 `PASSWORD_PEPPER`。
  https://github.com/langgenius/dify/releases/tag/1.18.0
