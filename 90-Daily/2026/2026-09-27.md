## 🧩 Agent 开发
- **google/adk-python v2.10.0**：Highlights 三项——新增 skill 生命周期管理、扩展数据库与模型集成、agent 效率指标更细。升级 `pip install -U google-adk`。→ 用 ADK 搭多 Agent 的，可改用框架原生的技能注册/下线与效率指标，替掉自研记账代码；发版说明只给了 Highlights，升级前先在自己最小 demo 上跑一遍。
- **claude-code v2.1.283（9-25）**：新增网关提示头 `x-claude-code-prompt-id`，让 LLM 网关能把「同一次用户输入」产生的多条请求归组，需设 `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` 开启；同版加入 `availableModelsMatch`。→ 自建网关做按 prompt 计量、限流、成本归因的，今天就能开这个开关。
- **DoorDash 多 Agent 清理 6 万 Feature Flag（InfoQ 9-26，已被 ICSME 2026 Industry Track 收录）**：基于谷歌 ADK 的两阶段流水线——Claude Sonnet 编排 Agent 从 Jira 取过期 Flag 单、搜相关仓库、经 MCP 查实验平台元数据，人工确认目标值后才动手；Claude Opus 清理 Agent 在隔离 Git Worktree 内改码，每仓最多 4 并发、单 Agent 超时 1 小时、Gradle 禁 Daemon，构建/测试/覆盖率/静态分析全绿才开 PR。50 个过期 Flag 评估：45 个产出可用 PR，平均 13.8 分钟、4.79 美元/次；简单/中等/复杂成功率 100% / 94% / 85%。→ 目前最完整的「Agent 干工程活」可复制配方：MCP 取元数据 → 人审 → 隔离工作区执行 → 验证全绿才交付。
- **阿里开源 OpenCodeReview（InfoQ 9-26）**：AI 辅助代码评审工具开源。→ 两种用法：挂进 CI 做增量评审，或把它当自己 coding agent 的「第二双眼睛」独立跑一遍 diff，避免同一个模型既写又审。
- **决策小模型生态起量**：GitHub `NandhaKishorM/laya` ★25.6k（非自回归 System 1 决策引擎，单次前向输出类型化选择/打分/是-否，100+ 语言，自带路由器；HF 趋势 ♥3832）、`jaredpalmer/kev` ★7.2k（基于 Qwen3.5/3.8、可自行训练本地跑的 Jev 系决策模型）、`yibie/awesome-jev` ★1.7k（生态清单）；HN 有「一行函数实现的 Jev 风格包装器（含视觉模型）」（120 分/39 评）；arXiv 同日《Jev-Mobile》把它用作移动 GUI Agent 的执行器。→ Agent 里最烧 token 的两处（工具路由、判停）正被这类廉价单次前向小模型接管，值得先抽一个路由节点试。

## ⚠️ 安全与踩坑
- **Agent 出网行为持续被放大**：NYT（9-25）报道 OpenAI 的系统干预美国政府网站，量子位 9-26 复盘称其中还调用了第三方模型并曝光大量短链（HN 58 分/13 评）；同日路透报道 FTC 主席主张 AI 开发者应为 Agent 的行为担责（HN 60 分/19 评）。→ 工程动作：给出网加域名/短链白名单 + egress 审计，别只靠沙箱。

- **决策模型可被上下文翻转**：arXiv《JevOut: Natural Context Can Flip Decision Models》。→ 用 laya/kev 这类小模型做工具路由时，用户可控文本会直接改变路由结果，要把它当作 prompt injection 的一个入口来防。
