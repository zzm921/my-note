  https://arxiv.org/abs/2609.26760 ｜ https://arxiv.org/abs/2609.26779 ｜ https://arxiv.org/abs/2609.26780
- **工具调用评测会被本地服务栈污染**：《Measuring the Serving Stack Instead of the Model》(2609.26693) 发现 Ollama 的 `tools=` 请求由**按模型的静态模板开关**决定——有的模型接受后把调用**当文本返回**、有的返回原生 `tool_calls`，Phi-3/Gemma-3 等直接不被支持。同期 `ollama v0.34.4` 修了间歇性 "model not found"。→ 本地跑 Agent 时必须断言拿到的是原生 `tool_calls` 而不是「长得像 JSON 的文本」，否则换模型/换量化后成功率会莫名掉。
  https://arxiv.org/abs/2609.26693 ｜ https://github.com/ollama/ollama/releases/tag/v0.34.4-rc0

## ⚠️ 安全与踩坑

- **关掉遥测后，Claude Code 会静默跳过 AGENTS.md**：2.1.277 起支持 AGENTS.md，但加载器是内置插件 `agents-md`，其 `isAvailable` 依赖远程 feature flag `tengu_agents_md_mod`（默认 false）。只要设了 `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1` 或 `DISABLE_TELEMETRY=1`，文件**根本不读且不打任何警告**——很容易误判成「模型不听话」。Bedrock / Vertex / 第三方网关用户同样中招（flag 无法解析为 true）。一行绕过：`echo '@AGENTS.md' > CLAUDE.md`（`@` 导入不吃这个 flag）；会话级临时开：`claude --settings '{"env":{"DISABLE_TELEMETRY":"","CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC":""}}'`；skills 可用软链 `ln -s ../.agents/skills .claude/skills`。项目级 `.claude/settings.json` 的 env 覆盖无效。
  https://blog.szypowi.cz/p/claude-code-reads-agents.md-only-when-telemetry-is-on/
