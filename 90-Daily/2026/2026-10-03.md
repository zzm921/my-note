## 🧩 Agent 开发

**3. `google/adk-python` v2.11.0（10-01 00:44；release notes 已核实原文）——本次最贴近 Agent 工程的一条**
- **优雅中止**：`Runner` / `Workflow` / 节点都接受 `abort_signal`；`/run_sse` 在客户端断连时自动取消 run，并合成 abort 事件与函数响应。
- **工作流工具确认**：Tool node 现在像 `LlmAgent` 一样通过 `RequestInput` 暂停等用户批准，而不是把错误往下传。
- **`ModelConsultTool`**：agent 可在任务中途「咨询另一个模型」，按**每轮 + 每会话预算**封顶，并有 model consult 会话上下文交接层。
- **内置 SQLite 记忆服务**：用 `sqlite://` 记忆服务 URI 把 agent memory 存在本地 SQLite。
- 另有可选的 `ToolCallIntegrityPlugin`、BigQuery 工具在 CMEK 环境可用、`list_accessible_data_agents` 分页、sync 工具遵守 `tool_thread_pool_config`。
- **今天就能做**：升级后给长任务接 `abort_signal`（断线即停、省算力）；要本地记忆直接切 `sqlite://`，不必外挂向量库。

## 🔥 值得深看

- **arXiv `AutoCompact: Learning When to Compact Context in Long-Horizon Coding Agents`（2610.02150）**：让 agent 学会「何时」压缩上下文，而非按固定 token 阈值。你的长任务 agent 若靠 token 数硬触发摘要，这篇直接替换那个阈值。
- **arXiv `Causal Memory Policy: Making Memory Utility Identifiable by Intervening on Retrieval`（2610.02066）**：对检索做干预来识别「哪条记忆真有用」。评估记忆模块时，从「召回率」升级到「因果效用」。
