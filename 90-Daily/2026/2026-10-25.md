## 🧩 Agent 开发

- **google/adk-python v2.13.0（已抓 release 正文核实）**：三处能直接用上的改动——① **TypesafeClassifier / ClassifierNode**：用 TypeSafe 分类模型**单次前向给出校准概率**来给工作流路由，比调 LLM 判分支快得多（多分支编排的成本可以整块砍）；② **MongoDbSessionService / MongoDbMemoryService**：会话跨 runner 副本共享，长期记忆**不依赖嵌入模型**，任意 MongoDB 上按关键词召回历史轮次（可无向量库起步）；③ **Live Audio**：Gemini STT/TTS 串联 + **barge-in（打断）** 的实时语音对话。另将 12 个成熟实验特性转为 stable。升级：`pip install -U google-adk`。
  https://github.com/google/adk-python/releases/tag/v2.13.0
- **claude-code v2.1.310**（10-23）：新增 **Monitor 工具与插件 monitor**，在 Bedrock / Vertex / Foundry 以及遥测或非必要流量关闭时也可用；**长前台 sleep 被阻断**（把「等一会儿再轮询」堵掉，逼着用事件/回调）；修了部分网关后的请求失败与兼容问题。配套：**anthropic-sdk-python v2.3.0** 增加 Claude Tag 端点（Enterprise 组织）并把 google-cloud 的用户画像请求改走组织端点；**crewAI 1.15.30** 仅修 AGENTS.md 登录流程（三轮内结束），无破坏性变更。
  https://github.com/anthropics/claude-code/releases/tag/v2.1.310
- **ollama v0.40.11**（10-24）：macOS 上支持**语音生成**，`ollama run` 可边生成边把文本或模型回复**朗读出来**，应用可通过 OpenAI 兼容接口**流式取音频**。做本地语音 Agent 可以少接一个 TTS 服务；配合昨日提到的本地小模型（多模态 + 工具调用），「听懂 → 调工具 → 说回来」能在单机闭环。
  https://github.com/ollama/ollama/releases/tag/v0.40.11
- **千问蒋冠军：Personal Agent 需要「模型 + 记忆 + 生态」协同推进**（InfoQ / 雷锋网，10-23，同一场分享）：把个人 Agent 的短板明确定位在**记忆与生态接入**，而不是模型能力本身——与 adk 的 Mongo 记忆服务、以及「证据缺失下的评测」是同一问题的三个侧面。做个人助理向 Agent 的，可按「记忆写入策略 / 召回口径 / 工具生态接入」三层自查。
  https://www.infoq.cn/article/6EJRFIef67xr3x6vyCJa
- **工程侧两条：coding agent 的瓶颈正从写代码挪到人**：**Xcode 27.2** 推出对 Agent 友好、**显著减少合并冲突**的 JSON 项目配置格式（InfoQ，10-23）——工程配置从「易冲突的文件」变成可 diff、可程序化改写，是让 Agent 安全改项目配置的前置条件；**PostgreSQL 19 发不出来？AI「找茬」太快，人类修 Bug 速度跟不上**（同日）——Agent 产出的缺陷报告压过人类修复带宽，团队要提前建「AI 报告分级 + 自动关闭」闸门，否则评审队列会被灌爆。
  https://www.infoq.cn/article/7ResdjAZYy8yltOh6drM ｜ https://www.infoq.cn/article/Q6mgHWCSqV6KeZzee3NT
- **可直接复用的两个开源项目（已核实 star）**：**Corgi**（HN 119 分 / 40 评，corgi.computer）——面向 agent 与终端的 **multiplexer**，把多个 agent 会话与 shell 放进同一套窗口/复用体系，跑并行 Agent 时不必手工开一堆终端；**KKKKhazix/AIHOT**（★8548，9-28 建）——「自己找热点、自己写日报」的站点框架，**把信源与精选标准换成你的，它就是你的行业热点站**，与我们这套「采集脚本 → 分析员 → 落库」管线同构，可作为自建情报站的外壳参考。
  https://corgi.computer/ ｜ https://github.com/KKKKhazix/AIHOT

## 📊 评测与基准

- **三篇评测工作，提醒「分数之外看什么」**：**How Ground Truth Shapes Retrieval Scores**（2610.31586）证明 **RAG 检索分数强烈依赖标注口径**——同一系统换一份 ground truth 排序就变，评估 RAG 时必须把标注来源写进报告；**Would an LLM Match into a Residency?**（2610.31529）用西班牙 MIR 考试考开放模型，看的是**不确定性、推理过程与图像使用**而不只是正确率；**An Empirical Study of Recent LLMs for KG-to-Text**（2610.31520）在标准基准上横评知识图谱转文本——Agent 要做「结构化知识 → 人话」这一步，可直接借其基准与失败分类。
  https://arxiv.org/abs/2610.31586 ｜ https://arxiv.org/abs/2610.31529

## 🔥 值得深看

- **google/adk-python v2.13.0 的 TypesafeClassifier + Mongo 记忆**：一个把路由成本从「调 LLM 判分支」变成「单次前向出概率」，一个让长期记忆**不依赖向量库和嵌入模型**就能起步——两条都是今晚就能试的降本/降依赖改动。
