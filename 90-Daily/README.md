# 90-Daily · 日报归档

AI 热点日报按年归档。**本域笔记不套用 frontmatter 规范**（除 `type: daily` 与日期），因为其价值在于时序检索而非主题分类。

## 目录结构

```
90-Daily/
└── 2026/
    ├── 2026-06-27.md
    ├── 2026-06-28.md
    └── ...
```

## 检索方式

- **按日期**：文件名即日期，直接搜 `2026-07`
- **按关键词**：Obsidian 全文搜索（如搜「开源模型」）
- **跨年对比**：新建视图查询 `path:90-Daily`

---

## 约定

- 文件名严格用 `YYYY-MM-DD.md`
- 正文保留原始抓取格式，不做二次编辑（保持原始信息）
- 日报中若出现值得长期沉淀的知识点，**应另建卡片**到对应域，再用双链语法关联回日报
