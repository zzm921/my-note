### Q1 · 概念 ★｜为什么「多层线性变换叠起来」仍然等价于一个线性模型？

**考点**：非线性的必要性；隐藏层到底在做什么。

**答案要点**

1. 记一层为 `a = Wx + b`。两层复合就是 `W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)`，**仍然是一个线性变换**——多加几层不增加表达能力。
2. 所以关键不是「层数」，而是**层与层之间的非线性激活**；没有激活函数，100 层 = 1 层。
3. 反例：XOR（异或）无法用任何一条直线分开。要拟合它，**至少需要一层隐藏层 + 非线性激活**（隐藏层把输入映射到新空间，在那里才线性可分）。
4. 隐藏层的实质是**自动学出来的特征表示**：浅层学简单模式，深层组合成复杂概念；这也是「深度学习」相对「手工特征工程」的核心收益。

**追问**：如果激活函数是线性的（如 a = 2z），结论变不变？→ 不变，仍是线性复合；激活必须**非线性**（ReLU/sigmoid/tanh 等）才有效。

**易错点**：把「层数多」当成拟合能力强的充分条件；记住「深度 × 非线性」才是关键。

### Q2 · 原理 + 计算 ★★｜一个 2 → 3 → 1 的网络（隐藏层 sigmoid、输出层线性）有多少参数？前向传播要几步？

**考点**：参数计数；前向传播的矩阵化写法。

**答案要点**

1. **参数计数**：隐藏层 2×3 个权重 + 3 个偏置 = 9；输出层 3×1 个权重 + 1 个偏置 = 4；**合计 13 个参数**。
2. **前向传播**：
   `z1 = X W1 + b1 → a1 = σ(z1) → z2 = a1 W2 + b2 → ŷ = z2`（输出回归用线性，分类换 sigmoid/softmax）。
3. **矩阵化要点**：`X` 的每一行是一个样本，一次矩阵乘就同时算完整个 batch——这正是向量化的意义，**不要写 for 循环遍历样本**。
4. **规模感**：参数量 ≈ Σ(前层宽度 × 后层宽度 + 后层宽度)。宽度从 3 加到 100、输入从 2 加到 784（28×28 图像）时，参数量从十几跳到几万——**参数量决定过拟合风险与显存占用**。

**追问**：为什么偏置 b 常常被忘记？→ 因为权重矩阵更显眼，但少了 b 所有超平面被迫过原点，表达能力下降；在代码里把它写成独立的 `b` 向量即可。

**易错点**：把 W 的形状写反（导致维度对不上）；多分类输出层用 sigmoid 而不是 softmax。

### Q3 · 实操 + 直觉 ★★｜写出 sigmoid / tanh / ReLU 的表达式与导数区间，并解释 sigmoid 在深层网络里为什么会「梯度消失」

**考点**：激活函数选择；梯度消失的成因。

**答案要点**

1. `σ(z) = 1/(1+e^{-z})`，导数 `σ' = σ(1−σ) ∈ (0, 0.25]`；`tanh` 导数 `∈ (0, 1]`；`ReLU(z)=max(0,z)` 导数 **1（z>0）或 0（z<0）**。
2. 反向传播是**链式法则连乘**：`∂L/∂W₁ = ∂L/∂a · ∂a/∂z · … · ∂z/∂W₁`。sigmoid 每层最多贡献 0.25，20 层就是 `0.25²⁰ ≈ 1e−12`，梯度指数衰减 → 浅层几乎不再更新，这就是**梯度消失**。
3. 为什么 ReLU 缓解：正区间导数恒为 1，不再连乘缩小；代价是负区间梯度为 0，可能产生「死神经元」（可由 Leaky ReLU / 合适的初始化缓解）。
4. **实践惯例**：隐藏层默认 ReLU（深层网络）；输出层按任务选：二分类 sigmoid、多分类 softmax、回归线性。

**追问**：为什么输出层二分类用 sigmoid、多分类用 softmax？→ sigmoid 独立对待每个输出（适合互斥性不强的多标签）；softmax 把 K 个 logits 归一成和为 1 的概率分布，适合**互斥**多分类。

**易错点**：以为「梯度消失」是因为学习率太小（那是另一回事）；把 tanh 当成万能替换（导数上限 1，深层仍会衰减）。
