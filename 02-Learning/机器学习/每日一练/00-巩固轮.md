### Q1 · 机制理解 ★★｜梯度下降的三个旋钮：为什么必须做特征缩放？学习率过大 / 过小分别是什么症状？批量大小改变的是什么？

**考点**：梯度下降的收敛机制；特征缩放、学习率、批量各自的作用与代价（**不要求算数字**）。

**答案要点**

1. 梯度下降就是「沿负梯度方向、按学习率 α 的步长」反复更新参数：每一步走多远 = α × 当前梯度大小。
2. **特征缩放的机制**：特征量纲差几个数量级时（面积上千、房间数 1~3），代价函数等高线被拉成细长椭圆，梯度几乎垂直于谷底方向 → 更新来回震荡、到极小点要走很多步；把特征归一到相近尺度后等高线接近圆形，梯度直指极小点。它**不改变最优解，只改变走得多快**（对输入做可逆线性变换，模型仍能表示同一族函数）。
3. **学习率的症状**：太小 → 每步挪得少，代价曲线缓慢下降、迭代次数暴涨；太大 → 步子跨过谷底来回跳，代价不降反升甚至发散。实践做法：按 3 倍量级试几个值，盯代价曲线的形状（一直降 / 震荡 / 上升）来选。
4. **批量大小改变的是「梯度估计的方差」**：全批量方向最准，但每步要扫全量数据（单步慢、显存占用高）；随机梯度（SGD）每步只看一个样本（迭代快、方向噪声大）；小批量是折中 —— 噪声带来的抖动反而有助于离开平坦的差区域，同时又能让硬件并行吃满。
5. **怎么判断收敛**：看代价曲线是否趋于平坦（或参数更新量足够小），而不是死等固定轮数。

**追问**：为什么学习率不能一路固定到底？→ 早期离极小点远、希望步子大，接近极小点时希望步子小以免跨过去；所以有学习率衰减、也有自适应优化器（Adam 等），但它们仍需给定一个初始学习率。

**易错点**：以为「学习率越小越稳」；把 SGD 的抖动当 bug；以为要迭代到代价变成 0。

### Q2 · 应用判断 ★★｜在 Agent 里用逻辑回归做「相关性打分 / 意图路由」：什么时候该加正则？阈值怎么定？什么时候必须换成带隐藏层的模型？

**考点**：决策边界与阈值取舍；正则化的作用与代价；「线性够用 vs 非线性必要」的判断（范围都在已学 4、5 章内）。

**答案要点**

1. 逻辑回归输出 `σ(w·x+b) ∈ (0,1)`，把「打分」与「判定」合成一步：决策边界是超平面 `w·x+b=0`，**0.5 只是默认阈值、不是定律**。业务上按代价挪阈值：漏判代价大（该召回的相关内容、该路由的意图）就调低阈值，误判代价大就调高。
2. **正则化（L2）在做什么**：在代价里加 `λ·Σwⱼ²`，惩罚大权重 → 决策边界更平滑、对个别特征和噪声不敏感；λ 越大越保守（偏差↑、方差↓）。用一批标注样本对比不同 λ 挑一个，别凭感觉定。
3. **什么时候线性就够**：特征已经给好（embedding 点积、明确的显式特征），判别信息集中在少数方向；**什么时候不够**：需要**特征交叉**（「含具体时间 + 具体地点」「否定词 × 意图」这类组合条件）—— 这时必须加隐藏层 + 非线性激活（第 5 章结论：没有非线性，多层 = 一层）。
4. **打分模型最常见的三类坑**：① 训练与线上**特征口径不一致**（离线拼的特征与线上实时取的对不上，模型再好也没用）② **类别不平衡**（正样本极少时模型学成「一律判负」）③ 把 sigmoid 输出当成校准好的概率（0.8 不等于真有 80% 命中率，需要单独校准）。
5. **落地顺序**：规则 / 检索 / 线性基线先上线（延迟低、可解释、好回滚，能看清哪个权重在主导），指标确实卡住且有标注数据时再上非线性模型。（延伸，不作考点）

**追问**：为什么线上常出现「离线看着不错、线上很差」？→ 多半不是模型问题，而是特征口径、样本分布、或阈值没跟着分布漂移调整 —— 这类排查先查数据链路，再查模型。

**易错点**：把 0.5 当固定阈值；以为 sigmoid 输出天然是校准好的概率；一上来就上神经网络（忽略部署与回滚成本）。

### Q3 · 概念 + 机制 ★★｜为什么回归用「平方误差」、分类用「对数损失」？把损失换错会怎样？

**考点**：代价函数每一处设计（平方 / 除 m / 除 2）的动机；逻辑回归为什么不能直接沿用平方误差；损失函数决定了模型在优化什么。

**答案要点**

1. 平方误差的设计理由有三条：① 平方让误差恒为非负，避免正负抵消（+5 与 −5 相加会假装修正了）② 平方放大较大的误差，逼模型优先修正错得离谱的样本 ③ 平方处处可导、整体是凸函数（像一只碗，只有一个谷底），梯度下降能稳定求解。
2. 除以 m 是**取平均**，让 J 与样本量无关、可跨数据集比较；除以 2 纯粹是**求导便利**（抵消平方求导带出的系数 2），它只是把整个函数缩小一半，**不改变最优的 (w, b)**，别给它编「平均」之类的含义。
3. 逻辑回归套用平方误差会出两个问题：① f = σ(z) 之后 J 不再凸，曲线呈波浪状有多个波谷，梯度下降可能停在浅波谷里；② 预测错得离谱时 sigmoid 落在饱和区、导数接近 0，惩罚反而推不动参数 —— 变成「错得越狠、学得越慢」。
4. 对数损失 −y·log(f) − (1−y)·log(1−f) 只在**真实类别那一侧**计分：y=1 时 f→0 损失 →+∞；y=0 时 f→1 损失 →+∞。它错得越离谱罚得越狠，而且是凸的，所以能稳定收敛。
5. 一句话：**损失函数就是你告诉模型「什么算错」**。选/设计时可以问三件事：错得越离谱惩罚是否单调加重？函数形状好不好优化（凸、可导、梯度别消失）？它是否对应你真正在意的业务目标？
6. 工程注意（延伸）：log 里的 f、1−f 要做数值裁剪防 log(0) 爆炸；训练损失（J）与线上业务指标（准确率 / AUC / 命中率）不是一回事，别拿 J 当业务指标汇报。

**追问**：把分类的损失直接换成「准确率」会怎样？→ 准确率不可导、几乎处处梯度为 0（阈值挪一点命中数不变），没法做梯度下降；所以训练时用平滑可导的代理损失，评估时才看准确率。

**易错点**：把「除以 2」说成取平均；以为平方误差「不能用」（准确说是不能直接用于逻辑回归的凸性与梯度，对线性回归仍是标准选择）；把训练损失当成业务指标。

### Q4 · 应用判断 ★★｜过拟合与欠拟合各是什么症状？为什么必须同时看训练误差和测试误差？在 Agent 的小模型（路由 / 相关性打分）上按什么顺序处理？

**考点**：欠拟合（高偏差）/ 过拟合（高方差）的识别；两类缓解手段方向相反；线上小模型排错顺序。

**答案要点**

1. 只能靠**两个误差一起看**：训练高 + 测试高且接近 → **欠拟合**（没学够）；训练很低、测试明显更高 → **过拟合**（把噪声一起背下来了）；两条都低且接近 → 拟合良好。只看训练误差会把过拟合误判成「完美」。
2. 两类手段方向相反：治欠拟合要**加容量**（更多/更强的特征、多项式项、更大网络、训得更久）；治过拟合要**减容量或加约束**（更多数据、减特征、加正则 λ、早停、数据增强）。搞反了会越调越差。
3. 正则化是把同一把尺子往两边调：λ=0 容易过拟合；λ 太大权重被压到接近 0，模型退化成近似常数 → **欠拟合**；合适值要在留出的数据上试，而不是凭感觉定。
4. Agent 小模型的排查顺序（经验）：① 先查**特征口径与数据链路**（离线拼的特征与线上实时取的对不上、标签有噪声 —— 表现为「怎么调都学不会」，看着像欠拟合，根因在数据）② 再看样本量与参数量是否失衡 ③ 再调 λ、早停 ④ 最后才加容量、加特征。
5. 「特征越多越好」是错的：特征数接近样本数时更容易过拟合；样本量不大时先减特征 / 降维，往往比换更大模型有效。
6. 一个纪律（延伸，训练/评测分工相关）：不要反复用测试集来调参，用多了它就不再是「未见数据」；这与「6_模型评估与调优」相关，等学到那章再展开（本题不作考点）。

**追问**：为什么「加数据」往往比「调模型」更有效？→ 过拟合的本质是数据不足以约束模型容量；样本变多后噪声被平均掉，同容量模型的方差自然下降，这比调旋钮省事得多。

**易错点**：只看训练误差；以为特征越多越好；把调大 λ 当万能药（会转成欠拟合）；反复用测试集调参。

### Q5 · 概念解释 ★｜什么是监督 / 无监督学习？「回归还是分类」到底靠什么判断？这两类活在你的 Agent 工程里分别对应什么？

**考点**：两大范式的分界（有没有标签）；回归与分类的判定标准（连续量 vs 有限类别）；无监督结果「没有对错、只有是否符合业务目标」。

**答案要点**

1. 分界只有一条：**训练数据有没有标签 y**。有成对的 (x, y) → 监督学习，学的是 x→y 的映射；只有 x 没有 y → 无监督学习，任务变成发现数据内部的结构（聚类 / 异常检测 / 降维）。
2. 判「回归还是分类」不看输出是不是数字，而看**这个数字是不是连续量**：房价、温度、相似度打分是回归（1.7 和 1.8 之间还有意义）；「猫 / 狗」、意图标签、图片里的数字 5 是分类（类别即使写成数字，也不具备「中间值」的含义）。
3. 监督学习能跑起来的前提是**有参照物**：每次预测都能和标签对比，误差越大调整越多 —— 所以**标注质量直接决定上限**，标签错了一切都白做；无监督没有参照物，只能靠业务意义评估（聚类只输出分组，**不给簇命名**，命名要人来做）。
4. 评价方式不同：监督学习能与真实标签对比，误差/准确率可量化；无监督结果没有唯一正确答案，判据是「切出来的分组/挑出的异常点是否可用、是否符合业务目标」。
5. Agent 场景映射（延伸，不作考点）：意图分类、相关性打分、工具选择 → 监督（需要标注样本、需要维护口径）；把历史会话聚成话题、找出异常的调用链路与异常流量 → 无监督（先探索，再决定要不要人工标注转成监督问题）。
6. 一句话取舍：**标签是稀缺资源**。能拿到（或能构造）标注就用监督，目标明确、可量化；拿不到、或者还不确定要找什么结构时，先用无监督探路。

**追问**：为什么「识别图片中的数字 5」算分类、而「预测房价 380 万」算回归？→ 前者输出是有限类别中的一个（是标签，不是量），后者输出是数轴上的连续取值；判断标准落在「含义」而不是「形态」。

**易错点**：以为分类只能是两类（多分类很常见）；用「输出是不是数字」判断回归；认为无监督「没用」（现实中无标签数据远多于有标签数据）；指望聚类算法直接吐出有含义的类别名。

### Q6 · 机制理解 ★★｜为什么给线性模型加上 x² 就能拟合出曲线？阶数越高会怎样？为什么加了多项式几乎必须做特征缩放？

**考点**：多项式回归 = 特征工程 + 线性回归；阶数是容量旋钮（欠拟合 ↔ 过拟合）；特征缩放的必要性（跨第 2、3 章）。

**答案要点**

1. 关键洞察：**x²、x³ 被当成新特征**，模型写成 `f(x) = w₁x + w₂x² + w₃x³ + b` 之后，仍然是「特征加权求和 + 偏置」这个线性形式 —— **结构没变复杂，变的是输入特征**。所以线性模型也能弯：`w₂ < 0` 提供向下的弯曲，与 `w₁x` 的上升趋势叠加，正好贴合「先涨后平」这类形态，而 w₁、w₂ 由代价函数 + 梯度下降自动定，不用手工指定。
2. 阶数（次数）就是**容量旋钮**：阶数太低 → 欠拟合（用直线硬拟合曲线，两端和中间都偏）；阶数太高 → 曲线为了穿过每个点而剧烈震荡，把噪声一起背下来 = 过拟合。判断依据不是阶数本身，而是**训练误差与验证误差一起看**（延伸，属于第 6 章的内容，本题不作考点）。
3. **为什么几乎必须做特征缩放**：x²、x³ 会放大数值差异的数量级（x 从 50 到 100 只差 2 倍，平方后差 4 倍，立方后差 8 倍，取值上百时能拉开几个数量级）。特征尺度差太大 → 代价函数等高线被拉成细长椭圆，梯度在尺度小的特征上步子偏大、尺度大的上步子偏小，收敛极慢甚至来回震荡。做法：对**每个特征单独**做归一化 / 标准化（多项式特征也要一起缩）。
4. **特征工程不是机械堆变换**：要依赖对问题的理解 —— 「面积 × 地段」「房龄的倒数」「是否有阳台」这类有业务含义的组合才有价值；加特征在提升灵活性的同时也抬高过拟合风险，所以「特征越多越好」不成立。
5. 顺序建议：先用简单模型 + 少量有含义的特征做基线 → 按训练/验证误差判断是欠拟合还是过拟合 → **欠拟合**才加多项式/加特征/加容量，**过拟合**则减特征、加正则 λ、加数据、早停。
6. 单位陷阱（延伸）：权重 w 的数值大小依赖特征的单位，跨数据集或跨版本比较权重之前要先统一单位或做缩放，否则「哪个特征更重要」的结论会失真。

**追问**：x² 作为新特征进来后，训练方式和平凡的多元线性回归有什么不同？→ 没有任何不同，同一个代价函数、同一套梯度下降；只是这个特征的值由 x 算出来、不随参数变化。也就是说**模型的非线性表达能力来自特征，而不是来自优化过程**。

**易错点**：以为多项式回归是「另一种模型」（本质是线性回归 + 特征工程）；以为阶数越高越好；只加多项式不缩放，然后抱怨收敛慢；拿线性回归硬做分类。

### Q7 · 概念 + 机制 ★★｜为什么线性回归（平方误差）不能直接拿来分类？「给它的输出加个阈值」到底错在哪、什么时候才勉强能用？

**考点**：分类标签的离散性与回归输出的越界；离群点对最小二乘的全局拉扯（第 2 章）；平方误差代入 Sigmoid 后的非凸；决策边界 vs 判定阈值（第 4 章）。

**答案要点**

1. **输出形态对不上**：标签是 0/1 两个类别，线性回归给的是连续实数 —— 会出现 −0.17 或 1.33 这种**根本不在标签取值范围内**的预测，这些数字没有类别含义，只能事后硬加阈值。
2. **更要命的是边界会被异常点带偏**：平方误差对大偏差**平方**惩罚，而最小二乘是**全局拟合**（第 2 章），所以远端一个异常样本就能把整条直线拉过去。标准例子里，多出一个 (x=10, y=1) 的样本后，阈值位置整体右移，原本判对的样本反而被判错 —— **分类要的是「边界在哪」，平方误差优化的却是「全局数值贴合」，目标不一致。**
3. **换成 Sigmoid 之后，平方误差自己也不合适**：把 z 送进 `g(z)=1/(1+e^−z)` 后，以平方误差构造的 J 关于参数是**非凸**的（多个波谷），梯度下降容易停在差的解上；换成对数损失才是凸的，而且对「自信地判错」惩罚极大（y=1 却给 f→0 时损失 → +∞）。所以第 4 章的组合是 **Sigmoid + 对数损失**。
4. **「决策边界」和「判定阈值」是两件事**：逻辑回归的边界是 `z = w·x + b = 0`（等价于 f = 0.5 的那条线），而 0.5 只是默认阈值，可以按代价挪（漏判代价大就调低）。线性回归这两层概念都没有，只吐数值。
5. **什么时候勉强能用**（延伸判断）：样本干净、两类明显分开、只要个**粗排分数**，那就可以把回归输出当连续打分用，但**必须补阈值 + 校准**（输出大小并不等于概率）。正样本极少 / 严重不平衡时，这种做法的边界极不稳，别当成分类器的替代品。
6. **Agent 场景（延伸）**：相关性打分 / 意图路由这类任务里，连续分数本身有用（能排序、能按业务设不同阈值），所以常见组合是「**打分头（Sigmoid/逻辑回归）+ 阈值层**」；直接拿线性回归输出冒充概率，会同时踩「越界」和「未校准」两个坑。

**追问**：如果非要给线性回归输出加阈值分类，最直接的代价是什么？→ 边界完全由数值拟合决定，异常样本一动边界就跑；而且输出 1.3 没有可信的概率解释，阈值也就没法按代价来调。

**易错点**：以为「加个阈值就能把线性回归当分类器」；把「平方误差不适合逻辑回归」记成「平方误差不能用」（准确说法是代入 Sigmoid 后非凸、难收敛）；把决策边界（z = 0）和判定阈值（0.5）混为一谈。
