## 二、阶段目标

### M1 · 工具三件套（本周）
**目标**：能独立用 NumPy 做向量化计算、用 Pandas 读写与清洗表格、用 Matplotlib 画四类常用图。

- 交付物：
  1. 3 个可运行脚本 → `10-AI/ml/练习/`（`01_numpy_basics.py`、`02_pandas_eda.py`、`03_matplotlib_plots.py`）
  2. 1 篇速查笔记 → `10-AI/ml/NumPy-Pandas-Matplotlib速查.md`（用教程卡模板）
  3. 学习日志 3 条
- **验收标准**（不看资料能做到）：
  - [ ] 用 NumPy 写出批量梯度下降迭代（20 行内，向量化、无 for 循环遍历样本）
  - [ ] 用 Pandas 读 CSV → 处理缺失值 → groupby 聚合 → 两表 merge
  - [ ] 用 Matplotlib 画「散点 + 拟合线」双子图，含标题/轴标签/图例

### M2 · 从零实现（第 2 周）
**目标**：不调库，用 NumPy 手写两种模型的训练过程，并与 sklearn 对照。

- 内容：线性回归（批量 / 随机梯度下降、特征缩放、学习率对比）、逻辑回归（Sigmoid、对数损失、决策边界）
- 交付物：`linear_regression_from_scratch.py`、`logistic_regression_from_scratch.py` + 1 篇笔记（站点卡片候选：`ml-linear-regression-from-scratch` / `ml-logistic-regression-from-scratch`）
- **验收标准**：
  - [ ] 损失随迭代单调下降（画曲线验证）
  - [ ] 与 sklearn 的系数/截距差异 < 1e-2
  - [ ] 逻辑回归在测试集准确率与 sklearn 差距 < 2%
  - [ ] 能解释「为什么需要特征缩放」并演示有无缩放的收敛速度差异

### M3 · 完整流程（第 3 周）
**目标**：拿一个真实数据集，独立走完一次端到端流程。

- 数据集建议：房价回归（回归线）或 泰坦尼克/鸢尾花（分类线）
- 内容：清洗 → 特征工程 → 训练/验证/测试切分 → 训练 → 评估 → 调参 → 可视化
- 评估指标：回归 `MSE / RMSE / MAE / R²`；分类 `混淆矩阵 / Precision / Recall / F1 / ROC-AUC`；交叉验证；L1/L2 正则化
- 交付物：项目脚本（或多文件小项目）+ 1 篇流程复盘笔记（站点卡片候选）
- **验收标准**：
  - [ ] 能说清「为什么汇报 R² 而不是只汇报 MSE」
  - [ ] 能演示正则化强度 λ 变大时系数如何变化，并解释偏差-方差权衡
  - [ ] 能画 ROC 曲线并解释阈值选择对 P/R 的影响

### M4 · 回到课程主线（第 4 周起）
**目标**：把课程剩余章节逐章推进，每章配一次 30 分钟级的 sklearn 实现练习。

- 顺序：5-神经网络 → 6-模型评估与调优 → 7-决策树 → 8-非监督学习 → 9-推荐系统 → 10-强化学习
- 每章交付：练习脚本 + 笔记校对（已有成稿，补上「代码验证」小节）
- **验收标准**：每章能用一句话说清「它解决什么问题、代价是什么」，并跑出对应 sklearn 最小示例
