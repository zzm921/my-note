# 机器学习 · 学习计划

> 用吴恩达《机器学习》课程打地基，配「从零实现 → 完整流程 → 课程推进」三段实战。

### M3 · 端到端流程（第 3 周）· **全手写 numpy，不使用 sklearn**
**目标**：一个真实数据集端到端跑通，并且**所有环节都自己实现**（sklearn 另立课题，见 [[学习总览]] 的「待学课题」）。

- 数据集：课程数据集 + 自有 CSV（`02_pandas/data.csv`）或公开 CSV；不依赖 sklearn 的 `datasets`
